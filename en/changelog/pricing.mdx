---
title: "Pricing Updates"
---

<Note>
Pricing changes apply only to calls made **after** the change takes effect; historical calls are unaffected. Each model's live unit price is shown in the [Models overview](/en/docs/models) and the console "Model Market"; the cost of each call is authoritative as returned in `cost` / `usage.cost`.
</Note>

<Update label="2026-09-02" description="Pricing change">
**Text-model prices re-aligned to vendors' official list prices; long-context tiers added**

While onboarding new text models we cross-checked existing text groups against each vendor's official pricing page:

| Model | Change |
|---|---|
| `glm-5.1` / `glm-4.6` | Reference prices had been taken from an upstream conversion that was too low; now priced from Z.ai's official USD list (**raised**) |
| `minimax-m2.1` | Aligned to MiniMax's official legacy tier (slight increase) |
| `kimi-k2` | Input price had been above the official reference; **lowered** to 0.9 × reference |
| `deepseek-r1-0528` / `deepseek-v3.2` / `deepseek-v3.2-exp` | Output prices unified at 0.9 × reference (r1-0528 **lowered**; the two v3.2 tiers slightly raised) |
| GPT-5.6 Sol / Terra / Luna, GPT-5.5, GPT-5.4, GPT-5.4 Pro | **Long-context tier added above 272K input** (matching OpenAI; previously such requests were billed at the standard rate) |
| Gemini 3.1 Pro / 3 Pro / 2.5 Pro | **Long-context tier added above 200K input** (matching Google) |
| `kimi-k3` / `claude-sonnet-5` | Cached-input price added (cache hits billed at the lower rate) |

Changes take effect **immediately** and apply only to calls made afterwards. Live unit prices are shown on [Explore](https://qingbo.dev/explore) and in the console "Model Market".
</Update>

<Update label="2026-09-02" description="Pricing change">
**Existing models re-aligned to vendors' official list prices (both up and down)**

While onboarding new models we cross-checked existing ones against each vendor's official pricing page. The following unit prices have been synced:

| Model | Change |
|---|---|
| `kimi-k3` | Output price **lowered** to Moonshot's official list price |
| `gpt-image-2` | Requests without `quality` are now billed at the `high` tier (previously a lower tier; now matches OpenAI's default) |
| `seedream-5.0` / `seedream-5.0-lite` | All tiers synced to Volcengine's list price; `1.5K` tier added for 5.0-lite |
| `seedance-2.0` / `2.0-fast` / `2.0-face` / `2.0-fast-face` / `2.0-mini` / `2.5` / `1.5-pro` | Image-to-video now **same price** as text-to-video (lowered); reference-video requests billed at 2× (raised); tiers previously set from promotional prices moved back to list price |
| `wan2.6` / `wan2.7` / `wan2.7-r2v` / `wan2.7-videoedit` / `wan2.5-preview` | All tiers synced to Alibaba Cloud Model Studio list prices; video edit / reference-to-video billed at 2× |
| `minimax-h3` | All tiers synced to MiniMax's official price list |

Changes take effect **immediately** and apply only to calls made afterwards. Live unit prices are shown in the [Models overview](/en/docs/models) and the console "Model Market".
</Update>
