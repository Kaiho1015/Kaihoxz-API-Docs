Kuaishou's Kling video line currently has seven models: `kling-3.0-turbo`, `kling-v2-6` and `kling-v3` for general generation, `kling-v3-omni` and `kling-video-o1` for video references and video editing, and `kling-v2-6-motion-control` and `kling-v3-motion-control` for motion transfer. They share the task endpoint `POST /v1/tasks` — switching models means changing `model` — but their actions, parameters and durations differ; see Available models for the per-model breakdown.

## Quick start

<CodeGroup>

```bash Text to video
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: kling-demo-001" \
  -d '{
    "model": "kling-3.0-turbo",
    "action": "generate",
    "prompt": "A city street after rain, neon reflected in the puddles, slow dolly in",
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "n": 1
  }'
```

A successful submission returns a `task_id`. Retrieve the result with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status), wait inline with [`Prefer: wait`](/en/api-reference/task/submit#in-request-waiting-prefer-wait), or configure a webhook.

## Request parameters

<ParamField body="model" type="string" required>
  Model ID; see Available models.
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate` — generate a video; supported by all seven models
  - `edit` — edit a source video; only `kling-v3-omni` and `kling-video-o1` support it, and `video_urls` is required
</ParamField>

<ParamField body="prompt" type="string" required>
  Video description or edit instruction. On `kling-v3-omni` and `kling-video-o1` the prompt can reference the first and second entries of `image_urls` as `<<<image_1>>>` and `<<<image_2>>>`; with `element_list` on `kling-v3` and `kling-v3-omni`, reference a subject as `@name`.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Number of videos. Value: `1`. Each task returns one video.
</ParamField>

<ParamField body="duration" type="integer" required>
  Output duration in seconds, per model:

  - `kling-3.0-turbo`, `kling-v3`, `kling-v3-omni` — an integer from `3` to `15`
  - `kling-v2-6`, `kling-video-o1` — `5` or `10`
  - `kling-v2-6-motion-control`, `kling-v3-motion-control` — `0`, meaning the reference video's length
  - `action: "edit"` on `kling-v3-omni` / `kling-video-o1` — `0`, meaning the source video's length
</ParamField>

<ParamField body="resolution" type="string" default="720p">
  Output resolution tier: `720p` or `1080p`. All seven models offer both.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Frame ratio: `16:9`, `9:16` or `1:1`. The two `*-motion-control` models do not take this parameter. With reference images, the output follows the input image's ratio.
</ParamField>

<ParamField body="image_urls" type="string[]">
  Reference image URLs:

  - `kling-3.0-turbo` — up to 1, used as the first frame
  - `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1` — up to 2; two images act as first and last frame
  - The two `*-motion-control` models — required, one character reference image
  - With `video_urls` on `kling-v3-omni` / `kling-video-o1` — at most 1; `action: "edit"` takes no reference image
</ParamField>

<ParamField body="video_urls" type="string[]">
  Reference video URLs, at most one entry:

  - `kling-v3-omni`, `kling-video-o1` — a camera/feature reference under `action: "generate"`, the source clip under `action: "edit"`; 3 to 10 seconds
  - The two `*-motion-control` models — required, the motion source clip; up to 30 seconds
</ParamField>

<ParamField body="negative_prompt" type="string">
  Negative prompt. Supported by `kling-v2-6`, `kling-v3` and `kling-v3-omni`.
</ParamField>

<ParamField body="generate_audio" type="boolean" default="false">
  Generate native audio. Supported by `kling-v2-6`, `kling-v3` and `kling-v3-omni`; on `kling-v2-6` it requires `resolution: "1080p"`, and on `kling-v3-omni` it cannot be combined with `video_urls`.
</ParamField>

<ParamField body="watermark" type="boolean">
  Whether to watermark the output video. Supported by every model except `kling-video-o1`.
</ParamField>

### Multi-shot and reference subjects (`kling-v3` / `kling-v3-omni`)

<ParamField body="multi_shot" type="boolean" default="false">
  Enable multi-shot storyboard mode.
</ParamField>

<ParamField body="shot_type" type="string">
  Shot split method: `customize` / `intelligence`; required when `multi_shot=true`.
</ParamField>

<ParamField body="multi_prompt" type="array">
  Multi-shot list (1-6 items) of `{index, prompt, duration}`; index starts at 1 and is contiguous; shot durations must sum to `duration`; requires `multi_shot=true`.
</ParamField>

<ParamField body="element_list" type="array">
  Reference subjects (up to 3) of `{name, description, element_input_urls}`; 2-4 images per subject, first one frontal; reference a subject in the prompt as `@name`.
</ParamField>

### Role-tagged images (`kling-v3-omni` / `kling-video-o1`)

<ParamField body="image_with_roles" type="array">
  Role-tagged image array of `{url, role}` (`first_frame` / `last_frame` / `reference`); merged with `first_frame_image` / `last_frame_image`.
</ParamField>

### Motion control (`kling-v2-6-motion-control` / `kling-v3-motion-control`)

<ParamField body="character_orientation" type="string" required>
  Use the reference image or video for character orientation: `image` or `video`. The two values imply different reference-video lengths; see Limits.
</ParamField>

<ParamField body="keep_original_sound" type="string" default="yes">
  Whether to keep the motion reference video's original audio: `yes` or `no`.
</ParamField>

See [Submit a task](/en/api-reference/task/submit) for `callback_url`, `callback_events`, `Prefer: wait`, `Idempotency-Key`, and the maximum-cost header.

The Kling series does not support `seed`, `quality` or `size`. Any other parameter returns `400` and is not billed.

## Limits

| Models | Condition | Limit |
|---|---|---|
| All | Every request | Each task returns one video. |
| `kling-3.0-turbo` | Every request | A prompt is required and at most one first-frame image is accepted. |
| `kling-3.0-turbo` | `image_urls` provided | Image-to-video follows the input image and does not accept aspect_ratio. |
| `kling-3.0-turbo`, `kling-v2-6`, `kling-v3` | Every request | An explicit output duration is required. |
| `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1` | Every request | A prompt is required. |
| `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1` | Every request | At most two reference images are accepted. |
| `kling-v2-6` | `generate_audio: true` | Native audio requires the 1080p pro tier. |
| `kling-v2-6` | `generate_audio: true` | Native audio cannot be combined with two-image first/last-frame control. |
| `kling-v2-6` | Two `image_urls` provided | Two-image first/last-frame control requires the 1080p pro tier. |
| `kling-v3-omni`, `kling-video-o1` | `video_urls` provided | A video reference accepts at most one image and must be one 3 to 10 second video. |
| `kling-v3-omni`, `kling-video-o1` | `action: "edit"` | Initial video editing accepts one source video and preserves its duration. |
| `kling-v3-omni`, `kling-video-o1` | `action: "generate"` | Video generation requires an explicit output duration. |
| `kling-v3-omni` | `generate_audio: true` with `video_urls` | Video reference cannot be combined with native-audio generation. |
| `kling-v2-6-motion-control`, `kling-v3-motion-control` | Every request | Motion control requires one image and one video; output duration follows the reference video. |
| `kling-v2-6-motion-control`, `kling-v3-motion-control` | `character_orientation: "image"` | Image-orientation reference video must be 3 to 10 seconds. |
| `kling-v2-6-motion-control`, `kling-v3-motion-control` | `character_orientation: "video"` | Video-orientation reference video must be 3 to 30 seconds. |

| Item | Models | Maximum |
|---|---|---|
| Videos per task | All | 1 |
| Reference images | `kling-3.0-turbo`, both `*-motion-control` | 1 |
| Reference images | `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1` | 2 |
| Reference video length | `kling-v3-omni`, `kling-video-o1` | 10 seconds |
| Reference video length | `kling-v2-6-motion-control`, `kling-v3-motion-control` | 30 seconds |
| Storyboard shots | `kling-v3`, `kling-v3-omni` | 6 |
| Reference subjects | `kling-v3`, `kling-v3-omni` | 3, with 2-4 images each |

Requests whose duration follows a reference video (both `*-motion-control` models, and `action: "edit"`) need a video link whose duration can be read. If it cannot, the request returns `400` and is not billed; ordinary MP4 and WebM links work.

## Pricing

Billing is **resolution tier × output seconds**. `resolution` picks the tier (`720p` or `1080p`), and the seconds are the clip's actual output length.

Two situations switch to a different per-second rate while still multiplying by output seconds only:

- **Native audio** — `generate_audio: true` uses the audio tier. `kling-v3` and `kling-v3-omni` have one at both resolutions; `kling-v2-6` has one at 1080p only.
- **Video reference** — on `kling-v3-omni` and `kling-video-o1`, supplying `video_urls` uses the video-reference tier, under both `action: "generate"` and `action: "edit"`. The reference video's own length is not billed.

Where the output seconds come from:

- Requests that carry a concrete `duration` are billed on that `duration`.
- Requests with `duration: 0` (both `*-motion-control` models, and `action: "edit"`) follow the reference or source video, and are billed on the duration read from that video.

<Note>
Per-model rates are in `price_config` on `GET /v1/models`, and in the console's Model Market.

What a single call actually cost is the `cost` field on the task response — an integer quota at 500,000 quota = 1 USD.
</Note>

You are only billed for a successfully generated video. Failed and cancelled tasks, and tasks that return no usable video, are refunded in full. The final charge is the `cost` field on the task response — an integer quota, not dollars.

## Available models

| Model ID | Actions | Duration | Resolution | Reference material |
|---|---|---|---|---|
| `kling-3.0-turbo` | `generate` | 3-15s | `720p` `1080p` | 1 first-frame image |
| `kling-v2-6` | `generate` | 5s or 10s | `720p` `1080p` | Up to 2 reference images |
| `kling-v3` | `generate` | 3-15s | `720p` `1080p` | Up to 2 reference images |
| `kling-v3-omni` | `generate` `edit` | 3-15s; `edit` follows the source | `720p` `1080p` | Up to 2 images, 1 reference video |
| `kling-video-o1` | `generate` `edit` | 5s or 10s; `edit` follows the source | `720p` `1080p` | Up to 2 images, 1 reference video |
| `kling-v2-6-motion-control` | `generate` | Follows the reference video | `720p` `1080p` | 1 image + 1 reference video |
| `kling-v3-motion-control` | `generate` | Follows the reference video | `720p` `1080p` | 1 image + 1 reference video |

Picking by capability:

- **Native audio** (`generate_audio`) — `kling-v2-6` (`1080p` only), `kling-v3`, `kling-v3-omni`
- **Multi-shot storyboards and reference subjects** (`multi_shot` / `shot_type` / `multi_prompt` / `element_list`) — `kling-v3`, `kling-v3-omni`
- **Role-tagged images** (`image_with_roles`) — `kling-v3-omni`, `kling-video-o1`
- **Video editing and video references** (`action: "edit"` / `video_urls`) — `kling-v3-omni`, `kling-video-o1`
- **Motion transfer** (`character_orientation` / `keep_original_sound`) — `kling-v2-6-motion-control`, `kling-v3-motion-control`
- **Negative prompts** (`negative_prompt`) — `kling-v2-6`, `kling-v3`, `kling-v3-omni`
