Omni-Flash-Ext is a single video model covering **text-to-video** and **video extension** — pass one source clip in `video_urls` and the model builds on it, carrying its motion and style while the prompt steers the look. Three resolutions (720p / 1080p / 4k) and fixed durations of `4` / `6` / `8` / `10` seconds. A good fit for **creative shorts, style transfer and extending existing footage**. Generation is async.

**Without a reference video**, billing is a whole-clip price by **resolution × duration**.

**With a reference video** (`video_urls`) the shape changes: you are billed **on reference-video seconds only**, and the clip price is **not** charged — one per-second rate for 720p / 1080p and a higher one for 4K. A reference video may be at most **10 seconds**.

## Examples

<CodeGroup>

```bash Text to video
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "omni-flash-ext",
    "prompt": "sunset over the sea, gulls skimming the water, cinematic light",
    "duration": 6,
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'
```

```bash 4K short clip
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{

    "duration": 4,
    "resolution": "4k",
```


## Common Parameters

<ParamField body="model" type="string" required>
  Model ID; always `omni-flash-ext`
</ParamField>

<ParamField body="prompt" type="string" required>
  Video description text. Describe the **scene / subject / action / setting / camera movement / visual style / sound** in detail
</ParamField>

<ParamField body="duration" type="integer" default="6">
  Video duration in seconds. Fixed steps only: `4` / `6` / `8` / `10`.

  <Note>When you pass `video_urls` (video extension), **do not send `duration` as well**. The two are mutually exclusive — the source video determines the length.</Note>
</ParamField>

<ParamField body="resolution" type="string" default="720p">
  Output resolution: `720p` / `1080p` / `4k` (case-insensitive)
</ParamField>

<ParamField body="aspect_ratio" type="string" default="16:9">
  Frame aspect ratio. Allowed values:
  - `16:9` — landscape widescreen
  - `9:16` — portrait
  - `1:1` — square
</ParamField>

<ParamField body="seed" type="integer">
  Random seed. The same prompt + seed reproduces a similar result
</ParamField>

<ParamField body="video_urls" type="string[]">
  Source video URL array, for video extension. **At most 1 clip**, and it must be a publicly downloadable link. Do not send `duration` alongside it
</ParamField>

<ParamField body="callback_url" type="string">
  Webhook callback URL, invoked when the task reaches a terminal state. See [Callback Mechanism](/en/docs/sync-async#async-task-webhook)
</ParamField>

<ParamField body="callback_events" type="string[]">
  Subscribed callback events; defaults to the terminal states (`succeeded` / `failed` / `cancelled`)
</ParamField>

## Model-Specific Parameters

Omni-Flash-Ext has no model-specific parameters; every option lives in [Common Parameters](#common-parameters).

## Resource Limits

| Item | Limit |
|---|---|
| Source video | Up to 1, publicly downloadable link (MP4); cannot be sent together with `duration` |
| Prompt length | ≤ 2000 characters recommended |
| Video duration | Fixed steps: 4 / 6 / 8 / 10 sec |
| Resolution | 720p / 1080p / 4k |
| Output | MP4, link valid for 24 hours |
