Alibaba Tongyi Wanxiang (Wan) video generation series, covering **text-to-video / image-to-video / reference-to-video / video editing** through a single async task endpoint.

Seven tiers:

- **`wan2.7`** — the current flagship; one entry point for text- and image-to-video (pass `image_urls` to switch to image mode: first frame, or first + last frame), 720P / 1080P, any integer 2-15 sec, negative prompt and smart prompt expansion
- **`wan2.6`** — the stable classic tier, text- and image-to-video, 720p / 1080p, 5 / 10 / 15 sec
- **`wan2.6-i2v`** — 2.6 image-to-video, standard tier; driven by a reference image with synchronized audio, 720p / 1080p, 5 / 10 / 15 sec, requires `image_urls`
- **`wan2.6-i2v-flash`** — 2.6 image-to-video, fast tier at roughly half the price of the standard I2V tier, 720p / 1080p, 5 / 10 / 15 sec, requires `image_urls`
- **`wan2.5-preview`** — the 2.5 preview tier, text- and image-to-video (pass `image_urls` for image mode), 480p / 720p / 1080p, 5 / 10 sec, the most affordable price point
- **`wan2.7-r2v`** — reference-to-video (R2V): one or more reference images drive subject / style, for character consistency and style continuity; requires `image_urls`
- **`wan2.7-videoedit`** — video editing: a source video plus a text instruction for style transfer / content replacement / full rewrite; requires `video_urls`

The whole series is **billed per second**: cost = the per-second price for the chosen resolution × duration in seconds.

## Pricing

<Note>
No unit prices on this page — prices track upstream changes, and anything written here will drift out of date.

**Live prices:** the console's Model Market, or the `GET /v1/models` endpoint (see [Model list](/en/docs/models)).
**Actual cost of one call:** every response carries `cost` / `usage.cost` — that is the number to trust.
</Note>

**Video editing and reference-to-video count the input video too.** `wan2.7-r2v` and `wan2.7-videoedit` are billed **(source-video seconds + output seconds) × the video-reference unit price**, which is lower than the text-to-video tier. The source video may be at most **15 seconds** (`wan2.7-r2v`) or **10 seconds** (`wan2.7-videoedit`).

## Examples

<CodeGroup>

```bash Text-to-video (wan2.7)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan2.7",
    "prompt": "A coastal road at sunset, slow push-in, cinematic look",
    "duration": 8,
    "resolution": "1080P",
    "aspect_ratio": "16:9"
  }'
```

```bash Image-to-video (wan2.7, first frame)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \

    "prompt": "The person slowly stands up and walks toward the camera",
    "image_urls": ["https://cdn.example.com/person.jpg"],
    "duration": 8,
    "resolution": "1080P"
  }'
```

## Available models

| Model ID | Resolution | Duration | Aspect ratio | Required | Notes |
|---|---|---|---|---|---|
| `wan2.7` | 720P / 1080P | any integer 2-15 sec | 16:9 / 9:16 / 1:1 / 4:3 / 3:4 | `prompt` | One entry for text / image mode; pass `image_urls` for image mode |
| `wan2.6` | 720p / 1080p | 5 / 10 / 15 sec | 16:9 / 9:16 / 1:1 | `prompt` | Stable classic tier, text / image |
| `wan2.6-i2v` | 720p / 1080p | 5 / 10 / 15 sec | 16:9 / 9:16 / 1:1 | `prompt` + `image_urls` | 2.6 image-to-video standard tier, synchronized audio |
| `wan2.6-i2v-flash` | 720p / 1080p | 5 / 10 / 15 sec | 16:9 / 9:16 / 1:1 | `prompt` + `image_urls` | 2.6 image-to-video fast tier, about half price; billed as audio when `audio` is omitted |
| `wan2.5-preview` | 480p / 720p / 1080p | 5 / 10 sec | 16:9 / 9:16 / 1:1 | `prompt` | 2.5 preview tier, text / image; pass `image_urls` for image mode |
| `wan2.7-r2v` | 720P / 1080P | any integer 2-15 sec | 16:9 / 9:16 / 1:1 | `prompt` + `image_urls` | Reference-to-video, character / style consistency |
| `wan2.7-videoedit` | 720P / 1080P | any integer 2-15 sec | 16:9 / 9:16 / 1:1 | `prompt` + `video_urls` | Video editing, style transfer / content replacement |

<Note>
Resolution casing differs by model: `wan2.7` / `wan2.7-r2v` / `wan2.7-videoedit` take upper-case `720P` / `1080P`; `wan2.6` / `wan2.6-i2v` / `wan2.6-i2v-flash` / `wan2.5-preview` take lower-case `720p` / `1080p` (`wan2.5-preview` also has `480p`).
</Note>

## Common parameters

<ParamField body="model" type="string" required>
  Model ID — see the [Available models](#available-models) table
</ParamField>

<ParamField body="prompt" type="string" required>
  Description of the video. Required in text mode; optional in image / reference / edit mode but recommended to guide camera and motion. Up to 5000 characters
</ParamField>

<ParamField body="image_urls" type="string[]">
  Reference / input image URLs:
  - `wan2.7`: passing it switches to image mode — 1 image = first frame, 2 images = first + last frame
  - `wan2.6`: 1 image only; passing it switches to image mode
  - `wan2.6-i2v` / `wan2.6-i2v-flash`: **required**, 1 image as the driving first frame
  - `wan2.5-preview`: passing it switches to image mode (image-to-video)
  - `wan2.7-r2v`: **required**, as subject / style reference (R2V)
  - `wan2.7-videoedit`: optional style / content reference images, **up to 4**

  For the tiers marked **required** (`wan2.6-i2v` / `wan2.6-i2v-flash` / `wan2.7-r2v`): If it is missing, the request is rejected at submission and nothing is held.
</ParamField>

<ParamField body="video_urls" type="string[]">
  Source video URL (single element). **Required** for `wan2.7-videoedit` — If it is missing, the request is rejected at submission and nothing is held. At most 10 seconds; base64 is not accepted — must be a publicly downloadable link
</ParamField>

<ParamField body="resolution" type="string">
  Output resolution, per the [Available models](#available-models) table:
  - `wan2.7` / `wan2.7-r2v` / `wan2.7-videoedit`: `720P` / `1080P` (default `1080P`)
  - `wan2.6` / `wan2.6-i2v` / `wan2.6-i2v-flash`: `720p` / `1080p` (default `720p`)
  - `wan2.5-preview`: `480p` / `720p` / `1080p` (default `720p`)
</ParamField>

<ParamField body="duration" type="integer">
  Video length in seconds:
  - `wan2.7` / `wan2.7-r2v` / `wan2.7-videoedit`: any integer `2`-`15` (default `5`)
  - `wan2.6` / `wan2.6-i2v` / `wan2.6-i2v-flash`: `5` / `10` / `15` only (default `5`)
  - `wan2.5-preview`: `5` / `10` only (default `5`)

  `wan2.7-videoedit` is settled on the output duration you specify; `0` keeps the source video's duration and is settled on the probed source duration (see [Input video duration and billing](/en/api-reference/video/overview#input-video-duration-and-billing)).
</ParamField>

<ParamField body="aspect_ratio" type="string" default="16:9">
  Aspect ratio (ignored in image mode — the input image decides):
  - `wan2.7`: `16:9` / `9:16` / `1:1` / `4:3` / `3:4`
  - `wan2.6` / `wan2.6-i2v` / `wan2.6-i2v-flash` / `wan2.5-preview` / `wan2.7-r2v` / `wan2.7-videoedit`: `16:9` / `9:16` / `1:1`
</ParamField>

<ParamField body="seed" type="integer">
  Random seed (≥ 0). The same request with the same seed produces similar results; omit for a different result each time
</ParamField>

<ParamField body="callback_url" type="string">
  Webhook URL, called when the task reaches a terminal state. See [Callbacks](/en/docs/sync-async#async-task-webhook)
</ParamField>

<ParamField body="callback_events" type="string[]">
  Callback events to subscribe to. Defaults to terminal states (`succeeded` / `failed` / `cancelled`)
</ParamField>

## Model-specific parameters

<Tabs>
  <Tab title="wan2.7">
    <ParamField body="prompt_extend" type="boolean" default="true">
      Smart prompt expansion — a clear improvement for short prompts, at the cost of extra latency
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      Content to avoid. Example: `"blurry, distorted, low quality"`
    </ParamField>
  </Tab>

  <Tab title="wan2.6">
    Wan 2.6 has no extra parameters — everything available is in [Common parameters](#common-parameters). Text vs image mode is decided by whether `image_urls` is passed.
  </Tab>

  <Tab title="wan2.6-i2v / wan2.6-i2v-flash">
    Both tiers require `image_urls` (1 image, used as the first frame). Optional:

    <ParamField body="audio" type="boolean" default="true">
      Generate video with audio. `wan2.6-i2v` is always with audio; for `wan2.6-i2v-flash` the upstream charges half price for silent output, but **we currently bill as audio whether the flag is omitted or set to `false`** — this will be split once the billing chain supports it
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      Content to avoid
    </ParamField>
  </Tab>

  <Tab title="wan2.5-preview">
    The 2.5 preview tier has no extra parameters — everything available is in [Common parameters](#common-parameters). Text vs image mode is decided by whether `image_urls` is passed.
  </Tab>

  <Tab title="wan2.7-r2v">
    The R2V tier has no extra parameters. `image_urls` is required as the character / style reference; the prompt describes motion and camera.
  </Tab>

  <Tab title="wan2.7-videoedit">
    The VideoEdit tier has no extra parameters. `video_urls` (source video) is required; `image_urls` can add style / content references (≤ 4); `duration` sets the output length.
  </Tab>
</Tabs>

## Limits

| Item | Limit |
|---|---|
| Source video (videoedit) | MP4 / MOV, ≤ 100MB, publicly downloadable |
| Reference images | JPG / PNG / WEBP, publicly downloadable URLs (videoedit: up to 4) |
| Prompt | ≤ 5000 characters |
| Output | MP4, link valid for 24 hours — download promptly |
