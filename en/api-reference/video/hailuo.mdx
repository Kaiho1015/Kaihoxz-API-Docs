MiniMax's Hailuo video line. This page covers `minimax-hailuo-02`, `minimax-hailuo-2.3` and `minimax-hailuo-2.3-fast`: all three go through the same task endpoint, all three have `generate` as their only action, and each turns text or a first-frame image into one clip of a fixed length — switching tiers means changing `model` and nothing else. For reference video, reference audio or a native soundtrack, use [MiniMax H3](/en/api-reference/video/minimax-h3).

## Quick start

<CodeGroup>

```bash Text to video
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: hailuo-demo-001" \
  -d '{
    "model": "minimax-hailuo-2.3",
    "action": "generate",
    "prompt": "Mist clears over a mountain temple at dawn, camera slowly pushing in",
    "duration": 6,
    "resolution": "1080p"
  }'
```

```bash First frame
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-hailuo-02",
    "action": "generate",
    "prompt": "The subject slowly looks up, hair moving in the wind",
    "first_frame_image": "https://cdn.example.com/portrait.jpg",
    "duration": 10,
    "resolution": "768p"
  }'
```

```bash First and last frame
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-hailuo-02",
    "action": "generate",
    "prompt": "Day turns into night, street lights coming on one by one",
    "first_frame_image": "https://cdn.example.com/day.jpg",
    "last_frame_image": "https://cdn.example.com/night.jpg",
    "duration": 10,
    "resolution": "768p"
  }'
```

```bash Fast tier
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-hailuo-2.3-fast",
    "action": "generate",
    "prompt": "City at night, neon signs along the street, camera panning right",
    "first_frame_image": "https://cdn.example.com/city-night.jpg",
    "duration": 6,
    "resolution": "768p",
    "prompt_optimizer": true
  }'
```

</CodeGroup>

A successful submission returns a `task_id`. Retrieve the result with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status), wait inline with [`Prefer: wait`](/en/api-reference/task/submit#in-request-waiting-prefer-wait), or configure a webhook.

## Request parameters

<ParamField body="model" type="string" required>
  One of `minimax-hailuo-02`, `minimax-hailuo-2.3` or `minimax-hailuo-2.3-fast`.
</ParamField>

<ParamField body="action" type="string" default="generate">
  `generate` is the only action of all three models. The mode is not selected by `action`: prompt only is text-to-video, adding `first_frame_image` is first-frame video, and a first frame plus `last_frame_image` is first-and-last-frame video.
</ParamField>

<ParamField body="prompt" type="string" required>
  Description of the video: scene, subject, motion, style. `minimax-hailuo-2.3` and `minimax-hailuo-2.3-fast` also accept camera-movement tags inside the prompt, see [Examples](#examples).
</ParamField>

<ParamField body="duration" type="integer">
  Clip length in seconds.

  - `minimax-hailuo-02`: `5` or `10`, default `5`
  - `minimax-hailuo-2.3` and `minimax-hailuo-2.3-fast`: `6` or `10`
</ParamField>

<ParamField body="resolution" type="string">
  Output resolution.

  - `minimax-hailuo-02`: `512p`, `768p` or `1080p`, default `768p`
  - `minimax-hailuo-2.3` and `minimax-hailuo-2.3-fast`: `768p` or `1080p`
</ParamField>

<ParamField body="first_frame_image" type="string">
  URL of the first frame, used as the opening image of the clip. Required by `minimax-hailuo-2.3-fast`.
</ParamField>

<ParamField body="last_frame_image" type="string">
  URL of the last frame; combine with `first_frame_image` for an A-to-B transition. Supported by `minimax-hailuo-02` only.
</ParamField>

<ParamField body="seed" type="integer">
  Random seed. The same parameters with the same seed produce similar results. Supported by `minimax-hailuo-2.3` and `minimax-hailuo-2.3-fast` only.
</ParamField>

<ParamField body="prompt_optimizer" type="boolean" default="true">
  Auto-optimize the prompt.
</ParamField>

<ParamField body="fast_pretreatment" type="boolean" default="false">
  Shorten prompt-optimization time; faster, with slightly weaker optimization.
</ParamField>

<ParamField body="watermark" type="boolean" default="false">
  Add a watermark to the output.
</ParamField>

The shared `callback_url`, `callback_events`, `Prefer: wait`, `Idempotency-Key` and cost-cap headers are documented in [Submit Task](/en/api-reference/task/submit).

None of the three models accepts `image_urls`, `video_urls`, `audio_urls`, `aspect_ratio`, `n` or `negative_prompt`. `minimax-hailuo-02` additionally does not accept `seed`, and `minimax-hailuo-2.3` / `minimax-hailuo-2.3-fast` do not accept `last_frame_image`. Anything beyond the parameters above returns `400` and is not billed.

## Limits

| Model | Condition | Limit |
|---|---|---|
| `minimax-hailuo-02` | Per request | Each task returns one video. |
| `minimax-hailuo-02` | `resolution: "512p"` | 512p is only available with a first frame image (image-to-video). |
| `minimax-hailuo-02` | `resolution: "1080p"` | 1080p supports 5 seconds only. |
| `minimax-hailuo-02` | `last_frame_image` sent | A last frame requires a first frame. |
| `minimax-hailuo-2.3` `minimax-hailuo-2.3-fast` | Per request | This model produces one result per task; n is not supported |
| `minimax-hailuo-2.3` `minimax-hailuo-2.3-fast` | `resolution: "1080p"` | 1080p only supports 6-second duration |
| `minimax-hailuo-2.3-fast` | Per request | `first_frame_image` is required |

`minimax-hailuo-02` takes at most 2 images per request: one first frame and one last frame.

## Pricing

Billed by **resolution tier times seconds**: the resolution sets the per-second rate, `duration` sets the number of seconds, and their product is the cost of the call — known before you submit. The three models have different per-second rates; within a model, `1080p` costs more than `768p`, which costs more than `512p`.

`prompt_optimizer`, `fast_pretreatment`, `watermark`, `seed` and the first / last frame images do not affect the price.

<Note>
**This page does not list unit prices** — rates change upstream, so this section covers billing dimensions and how they are applied.

Current rates are in `price_config` on `GET /v1/models` and in the console's Model Market. What a single call actually cost is the `cost` field on the task response: an integer quota, **500,000 quota = 1 USD**.
</Note>

You are only billed for a video that is produced. Failed and cancelled tasks, and tasks that return no usable video, are refunded in full.

## Available models

| Model ID | Resolutions | Duration (s) | Modes | Notes |
|---|---|---|---|---|
| `minimax-hailuo-02` | `512p` `768p` `1080p` | 5 / 10 | Text, first frame, first and last frame | `512p` needs a first frame; `1080p` is 5 s only |
| `minimax-hailuo-2.3` | `768p` `1080p` | 6 / 10 | Text, first frame | Camera-movement tags and `seed` |

## Examples

`minimax-hailuo-2.3` and `minimax-hailuo-2.3-fast` take camera-movement tags written as `[tag]` inside `prompt`. The tag labels are Chinese and must be written exactly as below; they can be mixed into the description and several can be used in one prompt:

| Category | Tags |
|---|---|
| Pan | `[左移]` (left) `[右移]` (right) |
| Rise / descend | `[上升]` (rise) `[下降]` (descend) |
| Push / pull | `[推进]` (push in) `[拉远]` (pull out) |
| Rotate | `[左摇]` `[右摇]` `[上摇]` `[下摇]` (left, right, up, down) |
| Zoom | `[变焦推近]` (zoom in) `[变焦拉远]` (zoom out) |
| Other | `[晃动]` (shake) `[跟随]` (follow) `[固定]` (static) |

```json Request body with camera tags
{
  "model": "minimax-hailuo-2.3",
  "action": "generate",
  "prompt": "[推进] A cobbled street in an old town, [变焦推近] rain dripping from the eaves",
  "duration": 6,
  "resolution": "1080p"
}
```
