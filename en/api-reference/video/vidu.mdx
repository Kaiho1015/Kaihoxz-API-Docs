ShengShu Vidu Q3 video generation series. **Reference-to-video (R2V)** is what it does best — it takes public image URLs as subject / style references, the prompt describes motion and camera work, and character appearance comes from the reference images. Best suited to **character consistency / style continuity / multi-shot transitions**.

**Two tiers:**

- **`vidu-q3`** — standard tier, the everyday default, smarter shot transitions, 540p / 720p / 1080p, 1-16 sec. Aspect ratio follows the reference image; **does not accept `aspect_ratio`**
- **`vidu-q3-mix`** — remix tier, blends multiple stills into one coherent clip, 540p / 720p / 1080p, 1-16 sec, accepts `aspect_ratio`, ideal for short-drama re-cutting and ad creative remixes

Billed by **resolution × duration**, **per second**, any integer from 1 to 16 seconds.

## Examples

<CodeGroup>

```bash Text-to-video (standard)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vidu-q3",
    "prompt": "A girl running toward the sunset on a beach at dusk, hair flying, cinematic lighting",
    "duration": 5,
    "resolution": "1080p"
  }'
```

```bash Image-to-video (standard, single image)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vidu-q3",
    "prompt": "The subject slowly turns around, camera pushes in",
    "image_urls": ["https://cdn.example.com/portrait.jpg"],
    "duration": 5,
    "resolution": "1080p"
  }'
```

```bash Multi-image reference (standard, R2V)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vidu-q3",
    "prompt": "Keep the character consistent, running through a forest, camera follows",
    "image_urls": [
      "https://cdn.example.com/char-1.jpg",
      "https://cdn.example.com/style-ref.jpg"
    ],
    "duration": 6,
    "resolution": "1080p"
  }'
```

```bash Multi-image remix (Mix tier)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vidu-q3-mix",
    "prompt": "Camera cuts smoothly between scenes, consistent mood throughout",
    "image_urls": [
      "https://cdn.example.com/scene-1.jpg",
      "https://cdn.example.com/scene-2.jpg",
      "https://cdn.example.com/scene-3.jpg"
    ],
    "duration": 8,
    "resolution": "1080p",
    "aspect_ratio": "16:9"
  }'
```

## Available models

| Model ID | Resolution | Duration (sec) | Actions | aspect_ratio | Notes |
|---|---|---|---|---|---|
| `vidu-q3` | 540p / 720p / 1080p | 1-16 | generate | not supported | Standard tier, everyday default, ratio follows the reference image |
| `vidu-q3-mix` | 540p / 720p / 1080p | 1-16 | generate | supported | Remix tier, coherent output from multiple stills |

## Common parameters

<ParamField body="model" type="string" required>
  Model ID. Accepted values:
  - `vidu-q3`
  - `vidu-q3-mix`
</ParamField>

<ParamField body="action" type="string" default="generate">
  `generate` — the only action for this model.

  **Mode is not selected by `action`, it follows what you send:** `prompt` alone is text-to-video; adding `image_urls` makes it image-to-video; `first_frame_image` + `last_frame_image` makes it first/last frame; `video_urls` / `audio_urls` make it reference-to-video.
</ParamField>

<ParamField body="prompt" type="string" required>
  Text description of the video. Describe **motion / camera / mood** — character appearance comes from `image_urls`.
</ParamField>

<ParamField body="resolution" type="string" default="720p">
  Output resolution. Accepted values:
  - `540p`
  - `720p`
  - `1080p`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Video length in seconds — any integer from **1 to 16**
</ParamField>

<ParamField body="image_urls" type="string[]" required>
  Array of reference image URLs, used as subject / style reference (R2V), as the first frame, or as remix material. **Required** for both `vidu-q3` and `vidu-q3-mix`. If it is missing, the request is rejected at submission and nothing is held.
</ParamField>

<ParamField body="callback_url" type="string">
  Webhook URL, called when the task reaches a terminal state. See [Callbacks](/en/docs/sync-async#async-task-webhook)
</ParamField>

<ParamField body="callback_events" type="string[]">
  Callback events to subscribe to. Defaults to terminal states (`succeeded` / `failed` / `cancelled`)
</ParamField>

## Model-specific parameters

<Tabs>
  <Tab title="vidu-q3">
    The standard tier has no model-specific parameters — everything available is in [Common parameters](#common-parameters).

    <Note>
    `vidu-q3` **does not accept `aspect_ratio`** — the output ratio is decided by the reference image / model. Use `vidu-q3-mix` if you need to set the ratio.
    </Note>
  </Tab>

  <Tab title="vidu-q3-mix">
    <ParamField body="aspect_ratio" type="string" default="16:9">
      Aspect ratio (Mix tier only). Accepted values:
      - `16:9` — landscape
      - `9:16` — portrait
      - `1:1` — square
    </ParamField>

    The Mix tier blends multiple reference images with automatic transitions — ideal for short-drama re-cutting and ad creative remixes.
  </Tab>
</Tabs>

## Limits

| Item | Limit |
|---|---|
| Reference images (`image_urls`) | JPG / PNG / WEBP, must be publicly downloadable URLs |
| Prompt length | ≤ 2000 characters recommended |
| Video length | any integer 1-16 sec |
| Output | MP4, link valid for 24 hours |
