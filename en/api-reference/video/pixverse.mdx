PixVerse V6 is a unified video generation model: **text-to-video and image-to-video** in one endpoint, **any integer duration from 1 to 15 seconds**, four resolutions (360p / 540p / 720p / 1080p), and optional **native audio** (`generate_audio`). A good fit for **short-form content, creative ads and bulk asset production**. Generation is async.

Billed by **resolution × duration** at a **per-second rate**. Setting `generate_audio` moves the request into the more expensive audio tier (`<resolution>_sound`).

## Examples

<CodeGroup>

```bash Text to video (silent)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pixverse-v6",
    "prompt": "golden hour, a corgi running through a field of sunflowers, cinematic camera",
    "resolution": "540p",
    "duration": 5,
    "aspect_ratio": "16:9"
  }'
```

```bash Text to video (with audio)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pixverse-v6",
    "prompt": "a neon alley in Tokyo, light rain at night, anamorphic lens flare",
    "resolution": "720p",
    "duration": 8,
    "generate_audio": true
  }'
```

```bash Image to video (single image)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pixverse-v6",
    "prompt": "slow push in, a light breeze moving through the leaves",
    "image_urls": ["https://cdn.example.com/first-frame.jpg"],
    "resolution": "540p",
    "duration": 5
  }'
```

</CodeGroup>

<ResponseExample>
```json Submission accepted
{

  "model": "pixverse-v6",
  "action": "generate",
```

## Common Parameters

<ParamField body="model" type="string" required>
  Model ID, always `pixverse-v6`
</ParamField>

<ParamField body="prompt" type="string" required>
  Video description text. Describe the **scene / subject / action / camera / mood**
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Video duration in seconds. Any integer from **1 to 15**
</ParamField>

<ParamField body="resolution" type="string" default="540p">
  Output resolution. `360p` / `540p` / `720p` / `1080p`. Determines the pricing tier
</ParamField>

<ParamField body="aspect_ratio" type="string" default="16:9">
  Frame aspect ratio. Allowed values: `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `2:3` / `3:2` / `21:9`
</ParamField>

<ParamField body="seed" type="integer">
  Random seed. The same prompt + seed reproduces a similar result
</ParamField>

<ParamField body="image_urls" type="string[]">
  Reference image URL array, for image to video. Only the first image is used. Must be a publicly downloadable link
</ParamField>

<ParamField body="callback_url" type="string">
  Webhook callback URL, invoked when the task reaches a terminal state. See [Callback Mechanism](/en/docs/sync-async#async-task-webhook)
</ParamField>

<ParamField body="callback_events" type="string[]">
  Subscribed callback events; defaults to the terminal states (`succeeded` / `failed` / `cancelled`)
</ParamField>

## Model-Specific Parameters

<ParamField body="generate_audio" type="boolean" default="false">
  Whether to generate the video with sound.
  - `false` (default) — silent output, billed at the silent tier
  - `true` — native audio, billed at the more expensive audio tier (`<resolution>_sound`); see [Pricing](#pricing)
</ParamField>

## Resource Limits

| Item | Limit |
|---|---|
| Reference image | Image to video uses the first image only; must be a publicly downloadable link (JPG / PNG / WEBP) |
| Prompt length | ≤ 5000 characters recommended |
| Video duration | Any integer from 1 to 15 sec |
| Resolution | 360p / 540p / 720p / 1080p |
| Output | MP4, link valid for 24 hours |
