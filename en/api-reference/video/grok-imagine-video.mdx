The xAI Grok Imagine video line currently offers four model IDs. All of them are submitted through the unified task endpoint `POST /v1/tasks`, all of them expose the single action `generate`, and all of them are billed by the output resolution tier multiplied by the generated seconds. On the official route, `grok-imagine-video-1.5` reaches 1080p and starts at 1 second, and `grok-imagine-video` also accepts a reference video. The economy models `grok-imagine-video-1.5-rev` and `grok-imagine-1.0-video-rev` offer 480p / 720p only, start at 6 seconds, and add no fee for reference images. For images, see [Grok Imagine Series](/en/api-reference/image/grok-imagine).

## Quick start

<CodeGroup>

```bash Text to video
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: grok-video-001" \
  -d '{
    "model": "grok-imagine-video-1.5",
    "action": "generate",
    "prompt": "Aurora over a snowfield, slow lateral camera move, no text",
    "duration": 8,
    "resolution": "1080p",
    "aspect_ratio": "16:9"
  }'
```

```bash Image to video
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \

  -H "Idempotency-Key: grok-video-i2v-001" \
  -d '{
    "model": "grok-imagine-video-1.5",
    "action": "generate",
    "prompt": "The subject slowly turns toward the camera, lighting unchanged",
    "image_urls": ["https://cdn.example.com/portrait.jpg"],
    "duration": 6,
    "resolution": "720p",
    "aspect_ratio": "9:16"
  }'
```

```bash Economy multi-reference

```


</CodeGroup>

A successful submission returns a `task_id`. Retrieve the result with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status), wait inline with [`Prefer: wait`](/en/api-reference/task/submit#in-request-waiting-prefer-wait), or configure a webhook. Video tasks take a while, so production traffic is best served by `callback_url`.

## Request parameters

<ParamField body="model" type="string" required>
  One of four IDs; see [Available models](#available-models).
</ParamField>

<ParamField body="action" type="string" default="generate">
  `generate` is the only action these four models support. Text-to-video and image-to-video both use it; the only difference is whether `image_urls` is present.
</ParamField>

<ParamField body="prompt" type="string" required>
  Description of the video, in English or Chinese. With reference images it guides motion and style.
</ParamField>

<ParamField body="duration" type="integer" required>
  Output length in whole seconds. `grok-imagine-video` and `grok-imagine-video-1.5` accept `1`–`15`; `grok-imagine-video-1.5-rev` and `grok-imagine-1.0-video-rev` accept `6`–`15`. Duration is a billing dimension, so a request without it cannot be priced.
</ParamField>

<ParamField body="resolution" type="string" default="480p">
  Output resolution. `grok-imagine-video-1.5` supports `480p`, `720p` and `1080p`; the other three models support `480p` and `720p`.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Frame ratio; the accepted set differs by model, see [Available models](#available-models). `grok-imagine-video-1.5` defaults to `auto`, letting the model choose the framing; `grok-imagine-video` and `grok-imagine-video-1.5-rev` default to `16:9`.
</ParamField>

<ParamField body="image_urls" type="string[]">
  Reference image URLs, publicly reachable. Supplying them makes the request image-to-video. `grok-imagine-video-1.5` takes up to 1, `grok-imagine-video-1.5-rev` up to 7.
</ParamField>

<ParamField body="video_urls" type="string[]">
  Reference video URLs. Only `grok-imagine-video` accepts them.
</ParamField>

<ParamField body="seed" type="integer">
  Random seed. Only `grok-imagine-1.0-video-rev` accepts it; the same prompt with the same seed yields a similar result.
</ParamField>

See [Submit Task](/en/api-reference/task/submit) for `callback_url`, `callback_events`, `Prefer: wait`, `Idempotency-Key` and the maximum-cost header.

`n` is not supported — a task produces one result. `generate_audio` and `audio_urls` are not supported. Any other parameter returns `400` and is not billed.

## Pricing

All four models are billed by **resolution tier × seconds**: each resolution has its own per-second rate, multiplied by the `duration` in the request. Resolution and duration are the only base dimensions, so the cost of a call is known before it is sent.

| Model | Billing dimensions |
|---|---|
| `grok-imagine-video` | Per-second rate for `480p` / `720p` × `duration`; sending `video_urls` does not change how the task is priced |
| `grok-imagine-video-1.5` | Per-second rate for `480p` / `720p` / `1080p` × `duration`; reference images add a separate per-image charge, independent of duration |
| `grok-imagine-video-1.5-rev` | Per-second rate for `480p` / `720p` × `duration`; reference images add no fee |
| `grok-imagine-1.0-video-rev` | Per-second rate for `480p` / `720p` × `duration`; reference images add no fee |

A `resolution` outside the tiers a model supports settles at the base per-second rate, equal to the `480p` tier.

Rates are in `price_config` on `GET /v1/models` and in the console's Model Market. What a single call actually cost is the `cost` field on the task response — an integer quota at **500,000 quota = 1 USD**, not dollars.

You are only billed for a successfully generated video. Failed and cancelled tasks, and tasks that return no usable video, are refunded in full.

## Available models

| Model ID | Resolution | Duration (s) | Aspect ratios | Reference images |
|---|---|---|---|---|
| `grok-imagine-video` | `480p` `720p` | 1–15 | 7 | Accepted, no extra fee |
| `grok-imagine-video-1.5` | `480p` `720p` `1080p` | 1–15 | 8 | Up to 1, charged per image |
| `grok-imagine-video-1.5-rev` | `480p` `720p` | 6–15 | 5 | Up to 7, no extra fee |
| `grok-imagine-1.0-video-rev` | `480p` `720p` | 6–15 | 3 | Accepted, no extra fee |

Only `grok-imagine-video` accepts a reference video (`video_urls`), and only `grok-imagine-1.0-video-rev` accepts `seed`.

Aspect ratio sets:

- **8** (`grok-imagine-video-1.5`): `auto`, `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`
- **7** (`grok-imagine-video`): `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`
- **5** (`grok-imagine-video-1.5-rev`): `16:9`, `9:16`, `1:1`, `3:2`, `2:3`
- **3** (`grok-imagine-1.0-video-rev`): `16:9`, `9:16`, `1:1`

## Official vs reverse

The economy models share the task endpoint and the parameter names with the official ones. Four things differ:

- **Resolution** — `1080p` exists only on `grok-imagine-video-1.5`; the economy models top out at `720p`.
- **Duration** — the two official models start at 1 second, the two economy models at 6 seconds; both cap at 15.
- **Reference images** — `grok-imagine-video-1.5` takes up to 1 and charges per image; `grok-imagine-video-1.5-rev` takes up to 7 with no extra fee.
- **Reference video** — only `grok-imagine-video` accepts `video_urls`.
