`suno` is an action-based model: the model ID is fixed and the `action` field decides what a call does. Start a song from scratch with `generate`, then keep working on the same track — extend it, cover it, split its stems, edit it, export it — across 32 actions in total. Every action is submitted through the unified task endpoint `POST /v1/tasks`.

## Quick start

<CodeGroup>

```bash Inspiration mode
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "suno",
    "action": "generate",
    "prompt": "A gentle city folk song, rainy night, female vocal, guitar and piano",
    "version": "v5.5"
  }'
```

```bash Custom mode (your own lyrics)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "suno",
    "action": "generate",
    "custom": true,
    "prompt": "[Verse]\nStreetlights turn the rain to golden thread\nI left my umbrella with yesterday",
    "title": "Rainy Night Southside",
    "style": "indie folk, female vocal, acoustic guitar",
    "vocal_gender": "Female",
    "version": "v5.5"
  }'
```

```bash Instrumental
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "suno",
    "action": "generate",
    "prompt": "Upbeat lo-fi study background music",
    "instrumental": true
  }'
```

```bash Lyrics only
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "suno",
    "action": "lyrics",
    "prompt": "A short song about lighthouses and patience"
  }'
```

</CodeGroup>

A successful submission returns a `task_id`. Retrieve the result with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status), wait inline with [`Prefer: wait`](/en/api-reference/task/submit#in-request-waiting-prefer-wait), or configure a webhook.

## Request parameters

### Actions

**Create from scratch** — no source track involved.

| Action | What it does |
|---|---|
| `generate` | A complete song: inspiration mode takes a description, custom mode takes your lyrics |
| `inspo` | Build a new song from a reference recording |
| `lyrics` | Write lyrics only, no audio |
| `sounds` | Generate a sound effect, optionally with type, BPM and key |
| `upsample_tags` | Expand a rough style description into fuller style tags |
| `upload` | Import your own audio so later actions can use it as a source track |

**Work on an existing track** — the source is given by `ref_task_id`.

| Action | What it does |
|---|---|
| `extend` | Continue the source track from second `continue_at` |
| `cover` | Re-perform the song in a different style |
| `remaster` | Remaster for better fidelity and overall polish |
| `sample` | Take `start_s`–`end_s` as a sample and develop it into a new song |
| `replace_section` | Replace `start_s`–`end_s`, optionally with new words in `infill_lyrics` |
| `mashup` | Mash songs up into a new arrangement |
| `concat` | Join segments into one finished track |
| `midi` | Produce MIDI from the song |

**Vocals and stems**

| Action | What it does |
|---|---|
| `stems` | Separate one stem, chosen with `stem_type` |
| `stems_all` | Separate every stem at once |
| `add_vocals` | Add vocals to an instrumental; the source must be audio imported with `upload` |
| `add_instrumental` | Add instrumentation to a vocal; the source must be audio imported with `upload` |
| `add_stem` | Layer an extra stem onto the source track |
| `vox` | Extract the vocal segment between `vocal_start_s` and `vocal_end_s` |
| `create_voice` | Build a reusable voice from the audio at `audio_url` |
| `persona` | Create a singer persona, reused later through `persona_id` |

**Audio editing**

| Action | What it does |
|---|---|
| `crop` | Keep only `start_s`–`end_s` |
| `remove_section` | Delete `start_s`–`end_s` |
| `fade_in` / `fade_out` | Fade in at the start or out at the end over `duration_s` seconds |
| `adjust_speed` | Change speed by `speed`; `keep_pitch` preserves the original pitch |

**Export and analysis**

| Action | What it does |
|---|---|
| `wav` | Export the source track as a WAV file |
| `download` | Export the source track as an audio file |
| `generate_video` | Produce a music video for the song |
| `aligned_lyrics` | Return line-by-line lyric timings |
| `bpm` | Analyse the song's BPM |

### Common parameters

<ParamField body="model" type="string" required>
  Always `suno`.
</ParamField>

<ParamField body="action" type="string" default="generate">
  What this call does; see Actions for the full set.
</ParamField>

<ParamField body="prompt" type="string">
  A content description in inspiration mode, the lyrics themselves when `custom: true`, and the subject to write about for `lyrics` and `sounds`.
</ParamField>

<ParamField body="callback_url" type="string">
  Completion callback URL; see [Submit Task](/en/api-reference/task/submit).
</ParamField>

### Creative parameters

These apply to the creative actions: `generate`, `inspo`, `extend`, `cover`, `remaster`, `mashup`, `sample`, `replace_section`, `add_vocals`, `add_instrumental`, `add_stem`, `sounds`. Parameters with a narrower range say so in the description.

| Parameter | Type | Description |
|---|---|---|
| `version` | string | `v3.5`, `v4`, `v4.5`, `v4.5+`, `v4.5-all`, `v5`, `v5.5`; default `v5.5`. Affects audio quality |
| `custom` | boolean | Default `false`, `prompt` is a description; `true` makes `prompt` the lyrics |
| `title` | string | Song title. Also available on `fade_in`, `fade_out`, `adjust_speed` |
| `style` | string | Style tags, `generate` only |
| `tags` | string | Style tags, for `extend`, `cover`, `inspo`, `mashup`, `sample`, `add_vocals`, `add_instrumental`, `add_stem`, `replace_section`, `upsample_tags` |
| `negative_tags` | string | Styles to avoid |
| `instrumental` | boolean | Instrumental only, no vocals. `generate`, `mashup`, `sample` only; default `false` |
| `gpt_description` | string | Inspiration prompt, required when `custom: false`. For `extend`, `cover`, `mashup`, `sample`, `add_vocals`, `add_instrumental`, `add_stem` |
| `auto_lyrics` | boolean | Let the model write the lyrics. For `generate`, `extend`, `cover`, `inspo`, `mashup`, `sample` |
| `persona_id` | string | Reuse a voice created by the `persona` action. For `generate`, `extend`, `cover`, `mashup` |
| `vocal_gender` | string | `Male` or `Female` |
| `style_weight` | number | `0`–`1`, style weight |
| `weirdness_constraint` | number | `0`–`1`, creativity |
| `audio_weight` | number | `0`–`1`, audio weight |

<Note>
`style` and `tags` are two field names for the same thing: `generate` uses `style`, every other action uses `tags`.
</Note>

### Referencing a source track

<ParamField body="ref_task_id" type="string">
  The `task_id` of the task that produced the source track.
</ParamField>

<ParamField body="audio_index" type="integer" default="1">
  Which track from the source task's result to use, starting at `1`.
</ParamField>

Two exceptions: `create_voice` takes a publicly reachable `audio_url`, and `upload` takes `audioFilePath` for the file being imported.

### Action-specific parameters

| Parameter | Type | Actions | Description |
|---|---|---|---|
| `continue_at` | integer | `extend` | Second of the source track to continue from. Required |
| `start_s` / `end_s` | number | `crop`, `remove_section`, `replace_section`, `sample` | Range start and end in seconds. Required |
| `duration_s` | integer | `fade_in`, `fade_out` | Fade length in seconds, minimum `1`. Required |
| `speed` | number | `adjust_speed` | Playback speed multiplier. Required |
| `keep_pitch` | boolean | `adjust_speed` | Keep the original pitch while changing speed |
| `stem_type` | string | `stems` | Which stem to extract; default `lead_vocal` |
| `infill_lyrics` | string | `replace_section` | Lyrics to fill the replaced section with |
| `variation_category` | string | `remaster` | Remaster variation category |
| `type` | string | `sounds` | Sound-effect type |
| `bpm` | integer | `sounds` | Target BPM |
| `key` | string | `sounds` | Musical key |
| `lyrics_model` | string | `lyrics` | Model used for lyric writing |
| `audio_url` | string | `create_voice` | Audio URL to build the voice from. Required |
| `audioFilePath` | string | `upload` | Path of the audio file to import. Required |
| `name` | string | `persona` | Persona name. Required |
| `describe` | string | `persona` | Persona description |
| `styles` | string | `persona` | Persona styles |
| `vox_audio_id` | string | `persona` | Which vox track to build the persona from |
| `vocal_start_s` / `vocal_end_s` | integer | `vox`, `persona` | Vocal segment start and end in seconds |

Parameters are validated per action: sending an action-specific parameter with a different action, or sending anything beyond the fields above, returns `400` and is not billed.

## Limits

This model produces one result per task; `n` is not supported.

| Action | Required parameters |
|---|---|
| `extend` | `continue_at` |
| `crop`, `remove_section`, `replace_section`, `sample` | `start_s` and `end_s` |
| `fade_in`, `fade_out` | `duration_s` |
| `adjust_speed` | `speed` |
| `create_voice` | `audio_url` |
| `upload` | `audioFilePath` |
| `persona` | `name` |

## Pricing

**Billed per call, with a different price per action.** Each action has its own flat rate, and that rate does not change with `version`, track length or prompt length. Full-generation actions (`generate`, `extend`, `cover`, `remaster` and similar) and full stem separation (`stems_all`) sit at the top; light actions such as `lyrics`, `bpm` and `wav` cost far less.

Rates are in `price_config.audio_prices` on `GET /v1/models`, keyed by action, and in the console's Model Market. What a single call actually cost is the `cost` field on the task response — an integer quota at **500,000 quota = 1 USD**, not dollars.

Only a successful result is billed. Failed and cancelled tasks, and tasks that return nothing deliverable, are refunded in full.

Audio-producing actions return their output in `result.audios[]`: `url` is an array of audio links and `expires_at` is when those links stop working. `generate` returns two candidate tracks, addressed later as `audio_index` `1` or `2`.

The `lyrics` action returns no audio: the lyric text sits in the `prompt` field of each `result.audios.lyrics[]` entry, alongside `title` and `tags`.

## Examples

To keep working on the same song, take the `task_id` from `generate` and pass it as `ref_task_id` to the next action. Each follow-up action produces a new `task_id` of its own, which can be chained further.

<CodeGroup>

```bash Extend
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "suno",
    "action": "extend",
    "ref_task_id": "taski_example",
    "audio_index": 1,
    "continue_at": 118
  }'
```

```bash Cover in another style
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "suno",
    "action": "cover",
    "ref_task_id": "taski_example",
    "audio_index": 1,
    "tags": "city pop, 80s synth, male vocal"
  }'
```

```bash Separate the lead vocal
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "suno",
    "action": "stems",
    "ref_task_id": "taski_example",
    "audio_index": 1,
    "stem_type": "lead_vocal"
  }'
```

```bash Export WAV
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "suno",
    "action": "wav",
    "ref_task_id": "taski_example",
    "audio_index": 1
  }'
```
