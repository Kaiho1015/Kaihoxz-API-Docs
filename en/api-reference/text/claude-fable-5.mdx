`claude-fable-5` · `POST /v1/chat/completions`

Verified text, streaming and auto function calls. JSON Schema returned Markdown-wrapped content; structured output is disabled and rejected before reserving quota.

The nine local Kimi/Fable requests settled for 7,499 quota ($0.014998), matching responses, wallet, key, logs and ledger. Two initial capability failures remain recorded. This is not a production deployment.

## Example

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-fable-5","messages":[{"role":"user","content":"Reply with the single word OK."}],"max_tokens":512,"stream":false}'
```

For streaming, set `stream: true` and `stream_options: {"include_usage": true}`; read the usage tail and `[DONE]`. Use `tool_choice: "auto"`; the client executes the generated function call.

## Limits

Provider-declared input/output limits: 1,000,000/128,000 tokens, not stress-tested. Images, native protocols, streaming/multi-turn tools and hosted tools are unverified. Cache rates are configured, but cache hits/writes have not been live-tested.
