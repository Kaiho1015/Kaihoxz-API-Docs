Use `gpt-6-astra` with `POST /v1/chat/completions`. Local tests verified text, streaming and JSON Schema. Three requests settled for 768 quota ($0.001536), matching response usage, wallet, key, logs and ledger. This is local acceptance, not a production deployment.

## Pricing

Checked September 5, 2026. USD per million tokens, at 90% of [official Standard rates](https://developers.openai.com/api/docs/models/gpt-6-astra).

| Total input tokens | Uncached input | Output | Cache read | Cache write |
|---|---:|---:|---:|---:|
| ≤272,000 | 9 | 45 | 0.9 | 11.25 |
| >272,000 | 18 | 67.5 | 1.8 | 22.5 |

Total input includes cached tokens. Crossing the threshold changes the entire request's rates. Cache reads/writes replace corresponding ordinary input charges. Reasoning is included in output. Sum components before converting to integer quota; 500,000 quota equals $1. `usage.cost` is quota. The settled ledger is authoritative; an unresolved request is not free and should not be resubmitted to check its cost.

## Example

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-6-astra","messages":[{"role":"user","content":"Reply with the single word OK."}],"reasoning_effort":"low","max_completion_tokens":128}'
```

For streaming, add `stream: true` and `stream_options: {"include_usage": true}` and read the final usage event and `[DONE]`. See [Chat integration](/en/api-reference/text/general-chat) for JSON Schema. Replace localhost with your deployed gateway address after deployment.

## Limits and verified scope

- The provider declares 922,000 input and 12,800 output tokens. These limits have not been stress-tested or verified simultaneously.
- Tests used `reasoning_effort: "low"`. Do not use `none`, custom `temperature`, `top_p` or `logprobs`.
- Chat tools are disabled. The [official changelog](https://developers.openai.com/api/docs/changelog) requires Responses for Astra tools; this gateway has not validated Astra Responses.
- Cache and long-context prices are configured, but actual hits, writes and long-context requests remain unverified. Image input and other reasoning efforts are also unverified.
- Hosted tools, built-in search and extra-cost service tiers are outside this integration's scope.
