Choose a public model with `model`. Non-streaming, streaming, and function calls use one endpoint; callers do not need provider or Profile IDs. Supported parameters depend on the model's verified route capabilities, not a blanket promise of every OpenAI option.

Local integration uses `http://localhost:40081`. Replace it with your gateway address after deployment. Authenticate with a WaveAPI Bearer Key, not an ecosystem login token.

## Minimal request

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-luna","messages":[{"role":"user","content":"Reply with the single word OK."}],"reasoning_effort":"none","max_completion_tokens":128,"stream":false}'
```

`model` and `messages` are required. The GPT example uses verified `reasoning_effort: "none"` and `max_completion_tokens`; Claude examples use `max_tokens`. Do not copy model-specific controls across every model. Temperature, reasoning levels, and multimodal input also depend on the model guide.

## Streaming

Add `stream: true` and `stream_options: {"include_usage": true}` to the same request. Accumulate SSE `choices[].delta.content`, read final usage, then process `[DONE]`. A usage-only tail can have no choices; do not discard it after text stops. A disconnected response does not mean the request was free. Check existing billing records before resubmitting.

## Structured output

This request passed on GPT-5.6 Luna. Use it only with models declaring support. The current Claude route rejects JSON Schema / JSON mode before quota reservation.

```json
{
  "model": "gpt-5.6-luna",
  "messages": [{"role": "user", "content": "Return an object whose answer is OK."}],
  "reasoning_effort": "none",
  "max_completion_tokens": 128,
  "response_format": {
    "type": "json_schema",
    "json_schema": {
      "name": "answer",
      "strict": true,
      "schema": {"type": "object", "properties": {"answer": {"type": "string", "enum": ["OK"]}}, "required": ["answer"], "additionalProperties": false}
    }
  }
}
```

## Function calling

Tools share the ordinary Chat URL. Your application validates and executes returned `tool_calls` names and JSON arguments; generated arguments do not mean a tool has run. Multi-turn tool workflows require separate model-specific verification.

```json
{
  "model": "gpt-5.6-luna",
  "messages": [{"role": "user", "content": "Call record_result with answer OK."}],
  "reasoning_effort": "none",
  "max_completion_tokens": 128,
  "tools": [{"type": "function", "function": {"name": "record_result", "description": "Return a result to the caller.", "parameters": {"type": "object", "properties": {"answer": {"type": "string"}}, "required": ["answer"], "additionalProperties": false}}}],
  "tool_choice": {"type": "function", "function": {"name": "record_result"}}
}
```

## Usage and charges

`prompt_tokens` includes uncached and cached input. Cache reads and writes replace their corresponding input charges rather than adding the same tokens twice. `completion_tokens` already includes reasoning. `usage.cost` is integer quota, not USD; the current conversion is 500,000 quota per USD. Final charges come from your text billing records. `pricing_pending` means reconciliation is outstanding, not a zero charge.

## Currently unavailable extras

Built-in search, hosted execution tools, and non-standard `service_tier` requests are rejected before quota reservation because their extra charges are not fully configured. Client-executed functions remain available. Explicit Gemini cache storage is also unavailable. Native envelopes are documented under [Gemini](/en/api-reference/text/gemini-native) and [Claude Messages](/en/api-reference/text/claude-messages); no per-provider endpoint is required.
