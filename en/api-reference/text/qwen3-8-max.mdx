## Example

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-max","messages":[{"role":"user","content":"Reply with the single word OK."}],"stream":false,"max_tokens":512}'
```

For streaming, use `stream: true` and `stream_options: {"include_usage": true}`, then read final usage and `[DONE]`. Function calls use `tool_choice: "auto"`; the client executes the generated arguments.

## Scope

Only ordinary text and automatic caching are exposed. **Explicit cache creation/reads are unavailable**: `cache_control` is rejected before reservation because explicit reads have a distinct rate. Built-in search and hosted tools are also rejected. Responses, images/PDF, streaming tools and multi-turn tools are unverified.

Provider-declared input/output limits are 983,616/131,072 tokens, not stress-tested. Reasoning consumes output budget; disabling it is not promised. These are local acceptance results, not a production deployment.
