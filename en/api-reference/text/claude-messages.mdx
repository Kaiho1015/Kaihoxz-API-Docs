Native envelope for Anthropic Messages clients. Sonnet 5 and Opus 5 passed non-streaming and streaming text checks. Function-call arguments were verified on Chat; native multi-turn tools and image input remain unverified.

See model pricing and limits in [Claude 5](/en/api-reference/text/claude-5).

## Request

```bash
curl http://localhost:40081/v1/messages \
  -H "x-api-key: $WAVE_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-sonnet-5","max_tokens":128,"stream":false,"messages":[{"role":"user","content":"Reply with the single word OK."}]}'
```

Replace the gateway URL after deployment. Set Anthropic SDK base URLs to the gateway root (`http://localhost:40081` locally); the SDK adds `/v1/messages`. Do not duplicate `/v1`. Ecosystem login tokens do not replace model Keys.

## Streaming and usage

Use the same URL with `stream: true`. Consume `message_start` and content-block events, then authoritative usage and stop reason from final `message_delta`, followed by `message_stop`. Initial message-start usage is not the final bill.

Native `input_tokens` excludes cache reads and writes; total input is the sum of all three. This differs from Chat total `prompt_tokens`. Output includes reasoning. Native responses do not add `usage.cost`; consult your billing records for the final charge.

Structured-output configuration is rejected before quota reservation. Not every Claude parameter is guaranteed compatible. Cache TTL, maximum context, native tool workflows, and multimodal capabilities remain subject to the verification scope in the model guide.
