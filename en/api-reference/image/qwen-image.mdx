Qwen Image is the image foundation model line from Alibaba's Qwen team. It unifies text-to-image generation and image editing behind one interface and is strongest at bilingual (Chinese and English) typography, infographics and text inside posters. This page covers the four models available today, in two generations: the 2.0 generation returns up to six images per request at a single per-image price, while the 3.0 generation adds multi-reference editing and prompt expansion and prices reference images separately.

## Quick start

<CodeGroup>

```bash Text to image
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: qwen-image-demo-001" \
  -d '{
    "model": "qwen-image-3.0",
    "action": "generate",
    "prompt": "A cafe menu poster, bilingual, serif headings, two-column body text",
    "aspect_ratio": "3:4",
    "resolution": "2k",
    "n": 1
  }'
```

```bash Edit with multiple references
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: qwen-image-edit-001" \
  -d '{
    "model": "qwen-image-3.0-pro",
    "action": "edit",
    "prompt": "Place the product from the first image on the display stand in the second, matching the lighting",
    "image_urls": [
      "https://cdn.example.com/product.png",
      "https://cdn.example.com/scene.png"
    ],
    "aspect_ratio": "1:1",
    "resolution": "1k"
  }'
```

```bash Several images in one request
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-image-2.0",
    "action": "generate",
    "prompt": "A flat-illustration city skyline in four colour variants",
    "negative_prompt": "text, watermark",
    "aspect_ratio": "16:9",
    "resolution": "2k",
    "n": 4
  }'
```

</CodeGroup>

A successful submission returns a `task_id`. Retrieve the result with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status), wait inline with [`Prefer: wait`](/en/api-reference/task/submit#in-request-waiting-prefer-wait), or configure a webhook.

## Request parameters

<ParamField body="model" type="string" required>
  One of `qwen-image-2.0`, `qwen-image-2.0-pro`, `qwen-image-3.0` or `qwen-image-3.0-pro`.
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`: create an image from text
  - `edit`: rewrite reference images; requires `image_urls`
</ParamField>

<ParamField body="prompt" type="string" required>
  The image description or editing instruction, in Chinese or English.
</ParamField>

<ParamField body="image_urls" type="string[]">
  Reference image URLs. `qwen-image-3.0` and `qwen-image-3.0-pro` require one to three of them on `edit` and accept none on `generate`.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Framing: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`. `qwen-image-3.0` and `qwen-image-3.0-pro` default to `1:1`.
</ParamField>

<ParamField body="resolution" type="string">
  Output resolution, `1k` or `2k`. `qwen-image-3.0` and `qwen-image-3.0-pro` default to `1k`.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Number of images to generate. `qwen-image-2.0` and `qwen-image-2.0-pro` accept `1`–`6`; `qwen-image-3.0` and `qwen-image-3.0-pro` accept `1`.
</ParamField>

<ParamField body="negative_prompt" type="string">
  Content to avoid in the generated result, up to 500 characters.
</ParamField>

<ParamField body="prompt_extend" type="boolean" default="false">
  Let the model expand the prompt; disabled by default. Supported by `qwen-image-3.0` and `qwen-image-3.0-pro` only.
</ParamField>

<ParamField body="prompt_extend_mode" type="string">
  Prompt expansion mode, `direct` or `agent`. Supported by `qwen-image-3.0` and `qwen-image-3.0-pro` only, requires `prompt_extend: true`, and `edit` accepts `direct` only.
</ParamField>

See [Submit a task](/en/api-reference/task/submit) for `callback_url`, `callback_events`, `Prefer: wait`, `Idempotency-Key` and the maximum-cost header.

This series does not accept `seed`, `quality`, `watermark` or `mask_url`. Any other parameter returns `400` and is not billed.

## Limits

| Condition | Limit |
|---|---|
| `qwen-image-2.0` / `qwen-image-2.0-pro` | Up to 6 images per request |
| `qwen-image-3.0` / `qwen-image-3.0-pro` | A prompt is required and each request generates one image |
| `action: "generate"` (both 3.0 models) | Text-to-image does not take reference images; use `edit` |
| `action: "edit"` (both 3.0 models) | Image editing requires 1 to 3 reference images |
| `prompt_extend_mode` | Requires `prompt_extend=true` |
| `prompt_extend_mode` on `edit` | Image editing accepts `direct` prompt extension only |

## Pricing

Billed at a **fixed price per successfully generated image**.

Rates are in `price_config` on `GET /v1/models` and in the console's Model Market. What a single call actually cost is the `cost` field on the task response — an integer quota at **500,000 quota = 1 USD**, not dollars.

The billing dimensions differ by generation:

- **`qwen-image-2.0` / `qwen-image-2.0-pro`** — one per-image price; `1k` and `2k` cost the same, and neither aspect ratio nor prompt length affects it. The total is that price times `n`.
- **`qwen-image-3.0`** — `1k` and `2k` cost the same.
- **`qwen-image-3.0-pro`** — `2k` costs more than `1k`.
- **Reference images on both 3.0 models** — each reference image in the request adds its own per-image fee on top of the output image. `generate` carries no reference images and no such fee.

A `resolution` outside the tiers a model supports settles at its fallback price, equal to that model's base tier.

You are only billed for a successfully generated image. Failed and cancelled tasks, and tasks that return no usable image, are refunded in full.

## Response

```json Completed task
{
  "task_id": "taski_example",
  "model": "qwen-image-3.0",
  "action": "edit",
  "status": "completed",
  "progress": "100%",
  "created_at": 1788754231,
  "completed_at": 1788754266,
  "result": {
    "images": [
      {
        "expires_at": 1789089508,
        "url": ["https://cdn.example.com/result.png"]
      }
    ]
  },
  "urls": {
    "get": "https://www.qingbo.dev/v1/tasks/taski_example",
    "cancel": "https://www.qingbo.dev/v1/tasks/taski_example/cancel"
  },
  "billing_status": "settled",
  "cost": 12377
}
```

Generated images come back in `result.images`, and `expires_at` is when that link stops working. With `n` greater than 1 the `images` array holds several entries. See [Query Task Status](/en/api-reference/task/status) for the full field list.

## Available models

| Model ID | Resolutions | `n` | Reference images | Line-specific parameters |
|---|---|---|---|---|
| `qwen-image-2.0` | `1k` `2k` (same price) | 1–6 | Supplied on `edit` | `negative_prompt` |
| `qwen-image-2.0-pro` | `1k` `2k` (same price) | 1–6 | Supplied on `edit` | `negative_prompt` |
| `qwen-image-3.0` | `1k` `2k` (same price) | `1` | 1–3, billed separately | `negative_prompt` `prompt_extend` `prompt_extend_mode` |
| `qwen-image-3.0-pro` | `1k` `2k` (`2k` costs more) | `1` | 1–3, billed separately | `negative_prompt` `prompt_extend` `prompt_extend_mode` |

All four support `generate` and `edit` and share the same aspect ratios: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`.
