Black Forest Labs' FLUX image model series, **5 models** in two families:

- **FLUX.1 Kontext (image editing)** — `flux-kontext-pro` / `flux-kontext-max`. Edits an existing image; good at local edits, style transfer, element replacement, and character consistency. **A reference image in `image_urls` is required** — a text-only prompt will not produce an image.
- **FLUX.2 (text-to-image / reference-guided)** — `flux-2-pro` / `flux-2-max` / `flux-2-flex`. Generates images from text, optionally guided by up to **8 reference images** (`image_urls`) for image-to-image and multi-image fusion, at `1K` or `2K` resolution; `2K` is billed separately. `max` is the top quality tier. Reference images carry a per-image surcharge.

Per-image pricing, async tasks — submit, then poll task status for the result.

<Warning>
`flux-kontext-pro` and `flux-kontext-max` are **image editing models**. A call must provide reference images in `image_urls` (together with an edit instruction in `prompt`), or the task fails. For text-only generation, use `flux-2-pro` / `flux-2-flex` instead.
</Warning>

## Common Parameters

<ParamField body="model" type="string" required>
  Choose one from the [Available Models](#available-models) list
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate` — text to image (default)
  - `edit` — image editing; pair with `image_urls`

  **The mode is decided by what you send, not by the action:** `prompt` alone is text-to-image; one `image_urls` entry is image-to-image; several are multi-image reference; add `mask_url` for inpainting.
</ParamField>

<ParamField body="prompt" type="string" required>
  Image description or edit instruction. Supports Chinese and English. For Kontext models, write what to do to the reference image
</ParamField>

<ParamField body="seed" type="integer" default="-1">
  Random seed. `-1` for random; a fixed value reproduces similar results. Supported by both FLUX.2 and Kontext
</ParamField>

<ParamField body="aspect_ratio" type="string" default="1:1">
  Aspect ratio. All four models support the same 7 options:
  - `1:1` — Square
  - `16:9` / `9:16` — Widescreen landscape / portrait
  - `4:3` / `3:4` — Standard landscape / portrait
  - `3:2` / `2:3` — Camera ratio landscape / portrait
</ParamField>

<ParamField body="resolution" type="string" default="1K">
  Output resolution, **FLUX.2 (`flux-2-pro` / `flux-2-flex`) only**:
  - `1K` — 1K tier (default, base rate)
  - `2K` — 2K tier (billed separately, see [Pricing](#pricing))

  Kontext models (`flux-kontext-pro` / `flux-kontext-max`) do not accept this field.
</ParamField>

<ParamField body="image_urls" type="string[]">
  Array of reference image URLs. **Required for Kontext models (`flux-kontext-pro` / `flux-kontext-max`)**; optional for the three FLUX.2 models, up to 8 images (output plus all reference images must not exceed 9MP in total), used for image-to-image and multi-image reference fusion. FLUX.2 reference images are **billed per image** — see the model page on [Explore](https://qingbo.dev/explore) for the unit price
</ParamField>

<ParamField body="callback_url" type="string">
  Webhook callback URL, invoked when the task reaches a terminal state. See [Callback Mechanism](/en/docs/sync-async#async-task-webhook)
</ParamField>

<ParamField body="callback_events" type="string[]">
  Subscribed callback event types. See [Callback Mechanism](/en/docs/sync-async#async-task-webhook)
</ParamField>

## Resource Limits

| Item | Limit |
|---|---|
| Reference images (Kontext) | Required — `flux-kontext-pro` / `flux-kontext-max` take `image_urls` |
| Reference images (FLUX.2) | Not supported — `flux-2-pro` / `flux-2-flex` are text-to-image only |
| Output resolution | FLUX.2 supports `1K` / `2K`; Kontext uses the model default |
| Single image size | ≤ 30MB, supports JPG/PNG/WEBP |
| Aspect ratio | 7 options: `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3` |
| Output file | Image URL, valid for 24 hours |
