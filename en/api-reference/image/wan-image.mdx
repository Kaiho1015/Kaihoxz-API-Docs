Wan 2.7 Image puts generation and editing in the same request: text-to-image takes only a `prompt`, while image-to-image, local rewrites and multi-image blending all go through `edit` with `image_urls`. This page covers the standard and pro models. Their parameter sets are identical; they differ only in the top text-to-image resolution and unit price — switching tiers means changing `model` and nothing else.

## Quick start

<CodeGroup>

```bash Text to image
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: wan-image-demo-001" \
  -d '{
    "model": "wan2.7-image-pro",
    "action": "generate",
    "prompt": "A summer beach under a blue sky with white clouds and a distant white sailboat",
    "aspect_ratio": "16:9",
    "resolution": "4k",
    "thinking_mode": true,
    "n": 1
  }'
```

```bash Sequential set
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan2.7-image",
    "action": "generate",
    "prompt": "a small fox exploring a snowy forest, storybook illustration, three scenes of the same fox",
    "enable_sequential": true,
    "n": 3,
    "resolution": "1k",
    "aspect_ratio": "1:1"
  }'
```

```bash Edit with multiple references
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: wan-image-edit-001" \
  -d '{
    "model": "wan2.7-image",
    "action": "edit",
    "prompt": "Put the person from the first image into the scene from the second, matching the lighting",
    "image_urls": [
      "https://cdn.example.com/person.png",
      "https://cdn.example.com/scene.png"
    ],
    "aspect_ratio": "3:2",
    "resolution": "2k"
  }'
```

```bash Edit inside a bounding box
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan2.7-image",
    "action": "edit",
    "prompt": "Replace the signage inside the box with a Chinese shop name",
    "image_urls": ["https://cdn.example.com/street.png"],
    "bbox_list": [
      [[120, 80, 540, 460]]
    ],
    "resolution": "2k"
  }'
```

</CodeGroup>

A successful submission returns a `task_id`. Retrieve the result with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status), wait inline with [`Prefer: wait`](/en/api-reference/task/submit#in-request-waiting-prefer-wait), or configure a webhook.

## Request parameters

<ParamField body="model" type="string" required>
  Either `wan2.7-image` or `wan2.7-image-pro`.
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`: create an image from text; takes no input images
  - `edit`: rewrite input images; requires `image_urls`

  Image-to-image, local rewrites and multi-image blending all use `edit`; they differ only in how many `image_urls` you send and whether you add `bbox_list`.
</ParamField>

<ParamField body="prompt" type="string" required>
  The image description or editing instruction, in Chinese or English.
</ParamField>

<ParamField body="negative_prompt" type="string">
  Content to avoid in the generated result.
</ParamField>

<ParamField body="image_urls" type="string[]">
  Input image URLs. Required for `edit`; up to nine images.
</ParamField>

<ParamField body="aspect_ratio" type="string" default="1:1">
  Framing: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`.
</ParamField>

<ParamField body="resolution" type="string" default="2k">
  Output resolution. `wan2.7-image` supports `1k` and `2k`; `wan2.7-image-pro` adds `4k` for text-to-image. On both models, `edit` tops out at `2k`.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Number of images to generate. `1`–`4` in standard mode; `1`–`12` with `enable_sequential`. Billed per image, so `n` multiplies the unit price.
</ParamField>

<ParamField body="seed" type="integer">
  Random seed. The same seed with the same parameters keeps results consistent.
</ParamField>

<ParamField body="watermark" type="boolean">
  Add a watermark to the output image.
</ParamField>

<ParamField body="thinking_mode" type="boolean" default="true">
  Reasoning mode: the model thinks before generating, improving quality at the cost of longer generation time. Effective on `generate` only.
</ParamField>

<ParamField body="enable_sequential" type="boolean" default="false">
  Sequential (multi-image) mode, for storyboards and series: one request returns `n` thematically coherent images (`n` up to 12). `thinking_mode` and `color_palette` have no effect when it is on; `wan2.7-image-pro` tops out at `2k` in this mode.
</ParamField>

<ParamField body="bbox_list" type="array">
  Per-input-image boxes, `[[[x1, y1, x2, y2], …], …]`, in absolute pixel coordinates. The outer length must equal the length of `image_urls`, and each image takes at most two boxes.
</ParamField>

<ParamField body="color_palette" type="array">
  A custom palette of 3 to 10 entries (8 recommended), each shaped like `{"hex": "#1B4D3E", "ratio": 12.5}`, with all `ratio` values summing to 100.00%. Standard mode only; it has no effect in sequential mode.
</ParamField>

See [Submit a task](/en/api-reference/task/submit) for `callback_url`, `callback_events`, `Prefer: wait`, `Idempotency-Key` and the maximum-cost header.

This series does not accept `quality` or `mask_url`. Any other parameter returns `400` and is not billed.

## Limits

| Condition | Limit |
|---|---|
| `n` | Up to 4 images per request in standard mode; up to 12 with `enable_sequential` |
| `enable_sequential: true` (`wan2.7-image-pro`) | Sequential mode tops out at `2k` |
| `action: "generate"` | Requires a prompt and accepts no input images |
| `action: "edit"` | Requires input images and is limited to `2k` |
| Input images | Up to nine |
| Resolution | `1k` / `2k` on `wan2.7-image`; `wan2.7-image-pro` adds `4k` for text-to-image |
| `bbox_list` | Outer length equals the length of `image_urls`, at most two boxes per image |
| `color_palette` | 3–10 entries with `ratio` summing to 100.00%; no effect in sequential mode |

## Pricing

Billed at a **fixed price per successfully generated image**, with one price per model; a request for `n` images is charged `n` times the unit price, and the hold at submission is sized by `n`.

Rates are in `price_config` on `GET /v1/models` and in the console's Model Market. What a single call actually cost is the `cost` field on the task response — an integer quota at **500,000 quota = 1 USD**, not dollars.

Within a model, `generate` and `edit` cost the same, and resolution, aspect ratio, input image count, `thinking_mode` and `color_palette` do not affect the price — the unit price times `n` is the whole cost of a call, known before it is sent.

You are only billed for a successfully generated image. Failed and cancelled tasks, and tasks that return no usable image, are refunded in full.

Generated images come back in `result.images`, and `expires_at` is when that link stops working. See [Query Task Status](/en/api-reference/task/status) for the full field list.

## Available models

| Model ID | Text-to-image resolutions | Editing resolutions |
|---|---|---|
| `wan2.7-image` | `1k` `2k` | `1k` `2k` |
| `wan2.7-image-pro` | `1k` `2k` `4k` | `1k` `2k` |

Both support `generate` and `edit`, return up to 4 images per request (12 in sequential mode), accept up to nine input images, and share the same aspect ratios: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`.
