The xAI Grok Imagine image generation and editing series, in an **official** line and an **economy** line:

**Official** (xAI's official API, billed per image):

- **grok-imagine-image** — standard tier, same price at 1K and 2K, the most affordable official Grok image model; text-to-image + reference-image editing
- **grok-imagine-image-quality** — quality tier, 1K and 2K priced separately; text-to-image + reference-image editing
- **grok-imagine-image-2.0** — generation 2.0, 1K / 2K × low / medium tiers; text-to-image + reference-image editing

**Economy** (alternate channel, cheaper, slightly fewer capabilities):

- **grok-imagine-image-2.0-rev** — generation 2.0 at fixed quality, 7 aspect ratios, text-to-image only
- **grok-imagine-1.0-rev** / **grok-imagine-1.5-rev** — text-to-image (`generate`)
- **grok-imagine-1.0-edit-rev** / **grok-imagine-1.5-edit-rev** — image editing (requires `image_urls`)

## Available Models

| Model ID | Line | action | Notes |
|---|---|---|---|
| `grok-imagine-image` | Official · standard | `generate` / `edit` | Same price at 1K / 2K, cheapest official tier, 5 aspect ratios |
| `grok-imagine-image-quality` | Official · quality | `generate` / `edit` | Higher fidelity, 1K and 2K priced separately |
| `grok-imagine-image-2.0` | Official · 2.0 | `generate` / `edit` | 1K / 2K × `quality` low / medium, 7 aspect ratios |
| `grok-imagine-image-2.0-rev` | Economy · 2.0 | `generate` | Fixed quality, 7 aspect ratios, text-to-image only |
| `grok-imagine-1.0-rev` / `grok-imagine-1.5-rev` | Economy | `generate` | Text-to-image from a prompt alone, 5 aspect ratios |
| `grok-imagine-1.0-edit-rev` / `grok-imagine-1.5-edit-rev` | Economy | `edit` | Image editing, requires reference images in `image_urls` |

## Common Parameters

<ParamField body="model" type="string" required>
  Pick one from the [Available Models](#available-models) list. The official line (`grok-imagine-image` / `-quality` / `grok-imagine-image-2.0`) supports both `generate` and `edit`; on the economy line use `grok-imagine-1.0-rev` / `1.5-rev` / `grok-imagine-image-2.0-rev` for text-to-image and `grok-imagine-1.0-edit-rev` / `1.5-edit-rev` for editing
</ParamField>

<ParamField body="prompt" type="string" required>
  Prompt text. Supports Chinese and English. For text-to-image it describes the image; for image editing it is the edit instruction applied to the reference image
</ParamField>

<ParamField body="n" type="integer" default="1">
  Number of images to generate, up to the upstream service limit
</ParamField>

<ParamField body="callback_url" type="string">
  Webhook callback URL, invoked when the task reaches a terminal state. See [Callback Mechanism](/en/docs/sync-async#async-task-webhook)
</ParamField>

<ParamField body="callback_events" type="string[]">
  Event types to receive callbacks for. See [Callback Mechanism](/en/docs/sync-async#async-task-webhook)
</ParamField>

## Model-Specific Parameters

### Text-to-image (grok-imagine-1.0-rev / grok-imagine-1.5-rev)

<ParamField body="aspect_ratio" type="string" default="1:1">
  Aspect ratio. 5 options:
  - `1:1` — Square
  - `16:9` / `9:16` — Widescreen landscape / portrait
  - `3:2` / `2:3` — Camera ratio landscape / portrait
</ParamField>

### Image editing (grok-imagine-1.0-edit-rev / grok-imagine-1.5-edit-rev)

<ParamField body="image_urls" type="string[]" required>
  URLs of the reference images to edit. The image editing models require this field
</ParamField>

<Note>
The image editing models (`*-edit`) do not support `aspect_ratio` — the output ratio follows the reference image.
</Note>

## Resource Limits

| Item | Limit |
|---|---|
| Reference images (`*-edit`) | Supplied via `image_urls` |
| Size per image | ≤ 30MB, JPG / PNG / WEBP |
| Aspect ratio (text-to-image) | `1:1` / `16:9` / `9:16` / `3:2` / `2:3` |
| Output file | Image URL, valid for 24 hours |
