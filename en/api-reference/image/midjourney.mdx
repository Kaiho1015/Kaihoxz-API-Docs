---
title: "Midjourney"
description: "An image model whose results can be upscaled, varied, expanded and repainted"
api: "POST https://www.qingbo.dev/v1/tasks"
---

Midjourney is known for highly aesthetic, artistic output, renders 2K images by default, and covers anime styles through its `niji` versions. There is a single model ID, `midjourney`, and `action` decides what a call does: `imagine` turns a prompt into a grid of four images, and every other action continues from the result of a previous task. All actions are submitted through the unified `POST /v1/tasks` endpoint.

## Quick start

| Action | What it does | Required parameters | Images |
|---|---|---|---|
| `imagine` | Turns a prompt into a grid of four; add `image_urls` for image-guided generation | `prompt` | 4 |
| `upscale` | Takes one image out of the grid as a single image | `ref_task_id`, `index` | 1 |
| `variation` | Small variation of one image in the grid | `ref_task_id`, `index` | 4 |
| `high-variation` | Large variation of a single image; composition and style may both change | `ref_task_id`, `index` | 4 |
| `low-variation` | Small variation of a single image, keeping subject and tone | `ref_task_id`, `index` | 4 |
| `reroll` | Draws a new grid from the source task's prompt | `ref_task_id` | 4 |
| `zoom` | Zooms out, keeping the original and filling in more background | `ref_task_id`, `index` | 4 |
| `pan` | Extends the image in one direction; repeat to build a panorama | `ref_task_id`, `index`, `direction` | 4 |
| `inpaint` | First step of inpainting: picks the single image to repaint | `ref_task_id`, `index` | via `modal` |
| `modal` | Adds the mask and prompt to an `inpaint` task and finishes the repaint | `ref_task_id`, `mask_url` | 4 |
| `edit` | Rewrites a whole image from a prompt | `ref_task_id`, `index`, `prompt`, `image_urls` | 1–4 |
| `remix-strong` | Strong reshape with a new prompt; `v8.1` / `v8.2` only | `ref_task_id`, `index` | 4 |
| `remix-subtle` | Subtle reshape with a new prompt; `v8.1` / `v8.2` only | `ref_task_id`, `index` | 4 |

The number of images is whatever `result.images` contains once the task completes.

Every action except `imagine` takes a `ref_task_id` — the `task_id` of the previous task. See [Examples](#examples) for how the chain fits together.

<CodeGroup>

```bash Generate an image
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "imagine",
    "prompt": "a lighthouse on a cliff at dawn, painterly, no text",
    "aspect_ratio": "16:9",
    "version": "v7",
    "speed": "fast"
  }'
```

```bash Upscale one image from the grid
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "upscale",
    "ref_task_id": "taski_example",
    "index": 2
  }'
```

```bash Create a variation
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "variation",
    "ref_task_id": "taski_example",
    "index": 3,
    "speed": "fast"
  }'
```

</CodeGroup>

A successful submission returns a `task_id`. Retrieve the result with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status), wait inline with [`Prefer: wait`](/en/api-reference/task/submit#in-request-waiting-prefer-wait), or configure a webhook.

## Request parameters

<ParamField body="model" type="string" required>
  Must be `midjourney`.
</ParamField>

<ParamField body="action" type="string" default="imagine">
  What the call does; see the table above for the values.
</ParamField>

<ParamField body="prompt" type="string">
  The prompt. Required for `imagine` and `edit`; optional for `modal`, `remix-strong` and `remix-subtle`, which fall back to the source task's prompt when it is empty. Native Midjourney flags can be written into the prompt (for example `--ar 16:9`); a structured parameter of the same name wins.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Output aspect ratio: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `21:9` or `9:21`.
</ParamField>

<ParamField body="image_urls" type="string[]">
  Reference image URLs. On `imagine` they make the generation image-guided; on `edit` they are required and hold the image being rewritten.
</ParamField>

<ParamField body="seed" type="integer">
  Random seed. `imagine` only.
</ParamField>

<ParamField body="negative_prompt" type="string">
  Elements to exclude. `imagine` only.
</ParamField>

<ParamField body="speed" type="string" default="relax">
  Generation speed tier: `relax`, `fast` or `turbo`. It directly changes the price and applies to every action.
</ParamField>

<ParamField body="version" type="string">
  Midjourney model version: `v5.1`, `v5.2`, `v6.1`, `v7`, `v8.1`, `v8.2`, `niji6` or `niji7`. Chained actions inherit the version of their source task.
</ParamField>

<ParamField body="ref_task_id" type="string">
  The `task_id` of the source task, meaning the previous step. Required for every action except `imagine`.
</ParamField>

<ParamField body="index" type="integer">
  Which image of the source grid to act on, `1`–`4` (top-left, top-right, bottom-left, bottom-right). Required for `upscale`, `variation`, `high-variation`, `low-variation`, `zoom`, `pan`, `inpaint`, `edit`, `remix-strong` and `remix-subtle`.
</ParamField>

<ParamField body="custom_id" type="string">
  Names the button on the source task directly; it wins over `index` when both are present. Available on `upscale`, `variation`, `high-variation`, `low-variation`, `reroll`, `zoom`, `pan` and `inpaint`.
</ParamField>

<ParamField body="zoom_ratio" type="number">
  `zoom` only. Zoom-out factor: below `2` zooms out 1.5×, `2` and above zooms out 2×.
</ParamField>

<ParamField body="direction" type="string">
  `pan` only. Direction to extend the image: `left`, `right`, `up` or `down`.
</ParamField>

<ParamField body="mask_url" type="string">
  `modal` only. URL of the mask image: transparent areas are repainted, white areas are kept. Required to repaint a region; without it the task is treated as an outpaint.
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata object, passed upstream as given.
</ParamField>

<ParamField body="style" type="string">
  `imagine` only. Style switch (`--style`), for example `raw`.
</ParamField>

<ParamField body="stylize" type="integer">
  `imagine` only. Stylization strength (`--s`), `0`–`1000`.
</ParamField>

<ParamField body="chaos" type="integer">
  `imagine` only. How different the four results are from each other (`--c`), `0`–`100`.
</ParamField>

<ParamField body="weird" type="integer">
  `imagine` only. Weirdness (`--w`), `0`–`3000`.
</ParamField>

<ParamField body="tile" type="boolean">
  `imagine` only. Produces a seamlessly tileable pattern (`--tile`).
</ParamField>

<ParamField body="iw" type="number">
  `imagine` only. Image weight (`--iw`), `0`–`3`. Higher values stay closer to `image_urls`.
</ParamField>

<ParamField body="cref" type="string">
  `imagine` only. Character reference image URL (`--cref`).
</ParamField>

<ParamField body="cw" type="integer">
  `imagine` only. How closely the character reference is followed (`--cw`), `0`–`100`. Used with `cref`.
</ParamField>

<ParamField body="sref" type="string">
  `imagine` only. Style reference image URL (`--sref`).
</ParamField>

<ParamField body="sw" type="integer">
  `imagine` only. How closely the style reference is followed (`--sw`), `0`–`1000`. Used with `sref`.
</ParamField>

<ParamField body="dref" type="string">
  `imagine` only. Depth reference image URL (`--dref`).
</ParamField>

<ParamField body="dw" type="number">
  `imagine` only. How closely the depth reference is followed (`--dw`), `0`–`100`. Used with `dref`.
</ParamField>

<ParamField body="raw" type="boolean">
  `imagine` only. Raw style (`--raw`), available from `v5.1`.
</ParamField>

<ParamField body="draft" type="boolean">
  `imagine` only. Draft mode (`--draft`), available from `v7`.
</ParamField>

<ParamField body="hd" type="boolean">
  `imagine` only. HD output (`--hd`), `v8.1` and `v8.2` only.
</ParamField>

<ParamField body="stop" type="integer">
  `imagine` only. Stop early (`--stop`), `10`–`100`, on `v5.1`, `v5.2`, `v6.1` and `niji6` only.
</ParamField>

<ParamField body="extra" type="string">
  `imagine` only. Native Midjourney flags appended to the end of the prompt as given.
</ParamField>

See [Submit Task](/en/api-reference/task/submit) for `callback_url`, `callback_events`, `Prefer: wait`, `Idempotency-Key`, and the maximum-cost header.

This model does not support `n`, `resolution` or `quality`. Any other parameter returns `400` and is not billed.

## Limits

| Condition | Limit |
|---|---|
| Per task | Midjourney returns one fixed image set per task; n is not supported |
| Any action other than `imagine` | `ref_task_id` is required |
| `ref_task_id` | Must be your own Midjourney task in status `completed`, otherwise the request returns `400` |
| `index` | `1`–`4` |
| Source task of `zoom`, `pan` and `inpaint` | Must be the single image produced by `upscale`; upscale a grid first |
| `pan` | Supported on `v6.1`, `v7`, `v8.1`, `v8.2` and `niji6` |
| `remix-strong` and `remix-subtle` | The source task must be `v8.1` or `v8.2` |
| `inpaint` | Produces no image on its own; call `modal` with a mask to finish it |

## Pricing

Billed at a **fixed price per call** across two dimensions: the **action** and the **`speed` tier**. Every action has its own price, and `relax`, `fast` and `turbo` price differently within one action. An `imagine` call returns four images and is billed once, not per image.

Rates are in `price_config` on `GET /v1/models` and in the console's Model Market. What a single call actually cost is the `cost` field on the task response — an integer quota at **500,000 quota = 1 USD**, not dollars.

`version`, aspect ratio and prompt length have no effect on the price, and reference images add no fee, so the cost of a call is known before it is sent. An action with no price key of its own settles at the fallback price.

You are only billed for a successfully generated image. Failed and cancelled tasks, and tasks that return no usable image, are refunded in full.

## Examples

Chained actions are linked by `ref_task_id`, which carries the `task_id` of your own previous task — not an image URL, and not an upstream ID.

<Steps>
  <Step title="Generate a grid">
    Call `imagine` and keep the `task_id` from the response. This step returns four entries in `result.images`.
  </Step>
  <Step title="Pick one and continue">
    Pass that `task_id` as `ref_task_id` and choose the image with `index`. `upscale` gives a single image; `variation` gives a new grid of four.
  </Step>
  <Step title="Keep going on the single image">
    The task ID from `upscale` becomes the `ref_task_id` of the next step: `zoom` to expand, `pan` to extend sideways, or `inpaint` plus `modal` to repaint a region. The chain can continue as long as you need.
  </Step>
</Steps>

<CodeGroup>

```bash Zoom out
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "zoom",
    "ref_task_id": "taski_example_upscale",
    "index": 1,
    "zoom_ratio": 1.5
  }'
```

```bash Extend to the right
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "pan",
    "ref_task_id": "taski_example_upscale",
    "index": 1,
    "direction": "right"
  }'
```

```bash Inpaint (two steps)
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "inpaint",
    "ref_task_id": "taski_example_upscale",
    "index": 1
  }'

curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "modal",
    "ref_task_id": "taski_example_inpaint",
    "prompt": "replace the selected area with a red leather sofa",
    "mask_url": "https://cdn.example.com/mask.png"
  }'
```

</CodeGroup>
