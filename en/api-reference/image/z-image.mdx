Z-Image Turbo is a 6B-parameter text-to-image model from Tongyi Lab. Its distilled few-step (S3-DiT) architecture generates in near real time, it excels at photorealistic portraits, and it renders both Chinese and English text — a good fit for batch drafts, marketing assets and quick previews. It does text-to-image only: no reference images, one image per request. For reference-based editing use the [Seedream Series](/en/api-reference/image/seedream) or the [Qwen Image Series](/en/api-reference/image/qwen-image).

## Quick start

<CodeGroup>

```bash Text to image
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: z-image-demo-001" \
  -d '{
    "model": "z-image-turbo",
    "action": "generate",
    "prompt": "A coastal observatory at sunrise, photorealistic, soft natural light",
    "aspect_ratio": "16:9",
    "resolution": "2k"
  }'
```

```bash With prompt rewriting
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "z-image-turbo",
    "action": "generate",
    "prompt": "A traditional Chinese teahouse poster",
    "aspect_ratio": "3:4",
    "resolution": "1k",
    "prompt_extend": true
  }'
```

</CodeGroup>

A successful submission returns a `task_id`. Retrieve the result with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status), wait inline with [`Prefer: wait`](/en/api-reference/task/submit#in-request-waiting-prefer-wait), or configure a webhook.

## Request parameters

<ParamField body="model" type="string" required>
  Must be `z-image-turbo`.
</ParamField>

<ParamField body="action" type="string" default="generate">
  Value: `generate`. This model does text-to-image only.
</ParamField>

<ParamField body="prompt" type="string" required>
  The image description, in Chinese or English.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Framing: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`.
</ParamField>

<ParamField body="resolution" type="string">
  Output resolution, `1k` or `2k`.
</ParamField>

<ParamField body="prompt_extend" type="boolean" default="false">
  Automatic prompt rewriting: the model expands the prompt into something more specific before generating.
</ParamField>

See [Submit a task](/en/api-reference/task/submit) for `callback_url`, `callback_events`, `Prefer: wait`, `Idempotency-Key` and the maximum-cost header.

This model does not accept `image_urls`, `n`, `seed`, `quality`, `negative_prompt` or `mask_url`. Any other parameter returns `400` and is not billed.

## Limits

| Condition | Limit |
|---|---|
| Per request | One image returned |
| Actions | `generate` only; takes no reference images |
| Resolution | `1k` / `2k` |

## Pricing

Billed at a **fixed price per successfully generated image**, with a single unit price.

Rates are in `price_config` on `GET /v1/models` and in the console's Model Market. What a single call actually cost is the `cost` field on the task response — an integer quota at **500,000 quota = 1 USD**, not dollars.

Resolution, aspect ratio and prompt length do not affect the price, so the cost of a call is known before it is sent.

You are only billed for a successfully generated image. Failed and cancelled tasks, and tasks that return no usable image, are refunded in full.

```json Completed task
  "model": "z-image-turbo",
  "action": "generate",
  "status": "completed",

  "completed_at": 1788766187,
  "result": {
    "images": [
      {
        "expires_at": 1789089508,
        "url": ["https://cdn.example.com/result.png"]
      }
    ]
  },
  "urls": {
    "get": "https://www.qingbo.dev/v1/tasks/taski_example",
    "cancel": "https://www.qingbo.dev/v1/tasks/taski_example/cancel"
  },
  "billing_status": "settled",
  "cost": 5625

```

Generated images come back in `result.images`, and `expires_at` is when that link stops working. See [Query Task Status](/en/api-reference/task/status) for the full field list.
