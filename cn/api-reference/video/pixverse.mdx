PixVerse V6 是 PixVerse 的统一视频生成模型：一个模型同时覆盖文生视频、图生视频、首尾帧转场和多图参考融合，支持多镜头连续叙事、原生同步音频（对白、音效与背景音乐）以及电影镜头控制，输出 360p 到 1080p、1–15 秒的片段。生成模式不靠动作区分，靠传哪些媒体字段决定。请求统一走 `POST /v1/tasks` 异步提交。

## 快速开始

<CodeGroup>

```bash 文生视频
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: pixverse-demo-001" \
  -d '{
    "model": "pixverse-v6",
    "action": "generate",
    "prompt": "金色黄昏，一只柯基穿过向日葵花田，镜头跟随",
    "resolution": "540p",
    "duration": 5,
    "aspect_ratio": "16:9"
  }'
```

```bash 带音频
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pixverse-v6",
    "action": "generate",
    "prompt": "东京霓虹小巷，细雨夜景，远处传来街声",
    "resolution": "720p",
    "duration": 8,
    "generate_audio": true
  }'
```

```bash 图生视频
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pixverse-v6",
    "action": "generate",
    "prompt": "镜头缓缓推近，微风拂动树叶",
    "image_urls": ["https://cdn.example.com/first-frame.jpg"],
    "resolution": "540p",
    "duration": 5
  }'
```

```bash 首尾帧
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pixverse-v6",
    "action": "generate",
    "prompt": "从清晨过渡到黄昏，光线逐渐变暖",
    "first_frame_image": "https://cdn.example.com/first.jpg",
    "last_frame_image": "https://cdn.example.com/last.jpg",
    "resolution": "720p",
    "duration": 5
  }'
```

```bash 多图融合
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pixverse-v6",
    "action": "generate",
    "prompt": "把人物放进第二张的场景，光线统一，镜头缓慢环绕",
    "img_references": [
      "https://cdn.example.com/person.jpg",
      "https://cdn.example.com/scene.jpg"
    ],
    "resolution": "720p",
    "duration": 8,
    "aspect_ratio": "16:9"
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  固定为 `pixverse-v6`。
</ParamField>

<ParamField body="action" type="string" default="generate">
  `generate` 是本模型唯一的动作。生成模式由传入的媒体字段决定：只给 `prompt` 是文生视频，带 `image_urls` 是图生视频，`first_frame_image` 与 `last_frame_image` 成对是首尾帧转场，带 `img_references` 是多图参考融合。
</ParamField>

<ParamField body="prompt" type="string" required>
  视频描述，最多 5000 字符。
</ParamField>

<ParamField body="negative_prompt" type="string">
  负向提示词，用于排除不想要的内容，最多 2048 字符。
</ParamField>

<ParamField body="duration" type="integer">
  视频时长（秒），`1`–`15` 的整数。首尾帧模式只支持 `5` 或 `8`。
</ParamField>

<ParamField body="resolution" type="string">
  输出分辨率：`360p`、`540p`、`720p` 或 `1080p`。分辨率决定计费档位。
</ParamField>

<ParamField body="aspect_ratio" type="string">
  画面比例：`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`2:3`、`3:2`、`21:9`。只在文生视频与多图融合模式下生效，其余模式跟随输入图。
</ParamField>

<ParamField body="seed" type="integer">
  随机种子，范围 `0`–`2147483647`。相同提示词与相同种子可复现相近结果。
</ParamField>

<ParamField body="image_urls" type="string[]">
  图生视频的输入图 URL 数组，只取第一张。
</ParamField>

<ParamField body="first_frame_image" type="string">
  首尾帧转场的起始帧图片 URL，必须与 `last_frame_image` 一起提供。
</ParamField>

<ParamField body="last_frame_image" type="string">
  首尾帧转场的结束帧图片 URL，必须与 `first_frame_image` 一起提供。
</ParamField>

<ParamField body="watermark" type="boolean" default="false">
  是否在视频右下角加水印。
</ParamField>

<ParamField body="generate_audio" type="boolean" default="false">
  是否生成带声音的视频。开启后走带声计价档，比静音档贵。
</ParamField>

<ParamField body="motion_mode" type="string">
  运动模式。`pixverse-v6` 只支持 `normal`。
</ParamField>

<ParamField body="generate_multi_clip_switch" type="boolean" default="false">
  是否生成多镜头连续视频。只在文生视频与图生视频模式下有效。
</ParamField>

<ParamField body="img_references" type="string[]">
  多图参考融合的图片 URL 数组，1–7 张。传入即进入多图融合模式。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

以上之外的参数会返回 `400`，不计费。

## 限制

- 首尾帧模式只支持 5 或 8 秒
- 本模型一次任务只产出一个结果，不支持用 n 批量生成

| 项目 | 上限 |
|---|---|
| 输入图 `image_urls` | 只取第一张 |
| 首尾帧 | `first_frame_image` 与 `last_frame_image` 必须成对提供 |
| 多图融合 `img_references` | 1–7 张 |
| 提示词 | `prompt` ≤ 5000 字符，`negative_prompt` ≤ 2048 字符 |
| 时长 `duration` | 1–15 秒整数；首尾帧模式为 5 或 8 秒 |
| 分辨率 `resolution` | `360p` / `540p` / `720p` / `1080p` |

所有图片输入只接受公网可访问的 HTTP(S) 链接，不接受 base64 与 Data URI。

## 计费

按**输出分辨率档 × 输出秒数**计费，秒数取请求里的 `duration`。四档分辨率各有单独的单价，分辨率越高越贵。

`generate_audio` 是第二个计费维度：开启后按同一分辨率的**带声档**结算，带声档高于静音档。参考图、首尾帧、负向提示词与画面比例都不单独计费。

<Note>
单价会随上游调整，本节只讲计费维度与口径，不列具体金额。

看实时单价：`GET /v1/models` 的 `price_config`，或控制台「模型市场」。
看单次实际费用：任务响应里的 `cost`（整数 quota，500,000 quota = 1 USD）。
</Note>

只有成功出片才计费。任务失败、取消，或上游返回成功但没有可交付视频时，全额退款。最终费用以任务响应里的 `cost` 为准，`cost` 是整数 quota 不是美元（500,000 quota = 1 USD）。
