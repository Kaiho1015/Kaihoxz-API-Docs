字节跳动豆包(Doubao)Seedance 视频生成系列,覆盖 **文生视频 / 图生视频** 场景,统一走异步任务入口,**按秒计费**。

<Note>
这是 **视频** 模型 Seedance(动态视频),请勿与豆包的图像模型 **Seedream**(静态图像)混淆,两者是不同产品线。
</Note>

五个档位:

- **`seedance-1.5-pro`** — 1.5 代有声档,音视频联合生成,支持多语言对白 + 口型同步,可用首帧 / 尾帧约束镜头,480p / 720p / 1080p,5 / 10 秒
- **`seedance-2.0`** — 2.0 标准档,文生 / 图生,480p / 720p / 1080p,4-15 秒任意整数
- **`seedance-2.0-fast`** — 2.0 加速档,更快更便宜,480p / 720p(无 1080p),4-15 秒
- **`seedance-2.0-face`** — 2.0 人脸档,面向人脸 / 数字人场景,480p / 720p / 1080p,4-15 秒
- **`seedance-2.0-fast-face`** — 2.0 人脸加速档,人脸场景的快速 / 低价版,480p / 720p,4-15 秒

## 计费档位:按输出分辨率,参考视频另算

Seedance 全家族按**输出分辨率 × 输出秒数**计费。**文生与图生同价** —— 传不传 `image_urls` 不影响单价(上游对输入图片不计费)。

唯一的例外是**参考视频**(`video_urls`):上游按「输入视频时长 + 输出时长」收费,我们目前按输出秒数的 **2 倍**单价折算。参考视频明显长于输出时,实际成本可能高于这个折算;这是过渡口径,后续会改为按输入时长精确计费。

各档实时单价见控制台「模型市场」;单次实际花费以响应里的 `cost` 为准。

## 媒体字段路由

Seedance 全系仅支持 `generate` 一种 action,后端按传入的媒体字段自动决定生成模式,**无需显式传 `action`**。

<Warning>
**`image_urls` 语义变更(2026-07-09 起,上游生效)**

`seedance-2.0`、`seedance-2.0-fast`、`seedance-2.0-mini` 三个模型:

- **变更前** — `image_urls` 的第 1 张作首帧、第 2 张作尾帧,其余作参考图。
- **变更后** — `image_urls` 中的**所有图片一律作为参考图**,不再有首帧 / 尾帧含义。

如果你依赖首尾帧约束,请改用 **`image_with_roles`** 字段显式指定(该字段不受此次变更影响)。`seedance-1.5-pro` 与 `face` 系列不受影响。
</Warning>

| 传入字段 | 用途 | 计费档 |
|---|---|---|
| 不传媒体字段 | 文生视频,画面比例由 `aspect_ratio` 控制 | 文生档 |
| `image_urls` | 图生视频。**2.0 / fast / mini**:全部作参考图(2026-07-09 起);**1.5 Pro / face 系列**:1 张作首帧、2 张作首尾帧 | 与文生同价 |
| `image_with_roles` | 显式指定首帧 / 尾帧,不受上述语义变更影响。**推荐用于首尾帧约束** | 图生档 |
| `video_urls` | 参考视频(仅 `seedance-2.0`) | 图生档 |

<Note>
`video_urls`(参考视频)仅 `seedance-2.0` 标准档支持;`fast` / `face` / `fast-face` 仅支持图像输入。
</Note>

## 通用参数

<ParamField body="model" type="string" required>
  模型 ID,见 [可用模型](#可用模型) 表
</ParamField>

<ParamField body="prompt" type="string" required>
  视频描述文本。建议详细描述场景 / 动作 / 风格 / 对白,以获得更好的生成效果
</ParamField>

<ParamField body="duration" type="integer" default="5">
  视频时长(秒):
  - `seedance-1.5-pro`:`5` / `10`
  - 2.0 家族:`4`-`15` 任意整数
</ParamField>

<ParamField body="resolution" type="string" default="720p">
  输出分辨率,各模型档位见 [可用模型](#可用模型) 表:
  - `1.5-pro` / `2.0` / `2.0-face`:`480p` / `720p` / `1080p`
  - `2.0-fast` / `2.0-fast-face`:`480p` / `720p`
</ParamField>

<ParamField body="aspect_ratio" type="string" default="16:9">
  画面宽高比,**仅文生视频生效**;带 `image_urls` 时跟随首帧比例。可选值:
  - `16:9` — 横版宽屏
  - `9:16` — 竖版长屏
  - `1:1` — 正方形
</ParamField>

<ParamField body="image_urls" type="string[]">
  参考图片 URL 数组(传入即走 **图生档** 计费):
  - 1 张 = 首帧驱动(图生视频)
  - 2 张 = 首帧 + 尾帧约束插值(`1.5-pro` / `2.0` 标准档)
</ParamField>

<ParamField body="video_urls" type="string[]">
  参考视频 URL 数组,**仅 `seedance-2.0` 标准档支持**。需公网可下载链接
</ParamField>

<ParamField body="seed" type="integer">
  随机种子。相同请求 + 相同 seed 会生成类似结果(不保证完全一致);省略或传 `-1` 则随机
</ParamField>

<ParamField body="callback_url" type="string">
  Webhook 回调地址,任务终态时调用。详见 [回调机制](/cn/docs/sync-async#异步任务-webhook)
</ParamField>

<ParamField body="callback_events" type="string[]">
  订阅的回调事件,默认订阅终态(`succeeded` / `failed` / `cancelled`)
</ParamField>

## 资源限制

| 项目 | 限制 |
|---|---|
| 参考图(`image_urls`) | 最多 2 张(首帧 + 尾帧),JPG / PNG / WEBP,需公网可下载 |
| 参考视频(`video_urls`) | 仅 `2.0` 标准档,MP4 / MOV,需公网可下载 |
| Prompt 长度 | 建议详细描述场景 / 动作 / 对白 |
| 视频时长 | `1.5-pro`:5 / 10 秒;2.0 家族:4-15 秒 |
| 输出 | MP4,链接 24 小时有效 |
