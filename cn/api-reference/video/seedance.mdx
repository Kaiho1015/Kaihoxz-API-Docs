字节跳动 Seedance 视频生成系列：1.0 两档做文生视频与首尾帧控制，1.5 Pro 加上多图参考与原生音频，2.0 三档把参考素材扩展到图片、视频和音频，2.5 在此之上多出视频编辑与视频延长两个动作。本页覆盖已上架的七个模型，它们共用同一个任务接口和同一套通用参数，差异集中在可选分辨率、时长范围、可接收的参考素材种类与数量上，换档只改 `model`。

<Note>
Seedance 是视频模型；同名的图像模型是 [Seedream 系列](/cn/api-reference/image/seedream)，两者的参数与计费方式都不同。
</Note>

## 快速开始

<CodeGroup>

```bash 文生视频
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: seedance-demo-001" \
  -d '{
    "model": "seedance-2.0",
    "action": "generate",
    "prompt": "一只小猫对着镜头打哈欠，慢镜头特写",
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'
```

```bash 首尾帧
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-1.0-pro",
    "action": "generate",
    "prompt": "人物从窗前转身走向门口，光线由冷转暖",
    "first_frame_image": "https://cdn.example.com/first.jpg",
    "last_frame_image": "https://cdn.example.com/last.jpg",
    "duration": 6,
    "resolution": "1080p"
  }'
```

```bash 多图参考
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.0",
    "action": "generate",
    "prompt": "把人物放进第二张的场景里，镜头缓慢环绕",
    "image_urls": [
      "https://cdn.example.com/person.jpg",
      "https://cdn.example.com/scene.jpg"
    ],
    "duration": 8,
    "resolution": "720p",
    "aspect_ratio": "adaptive"
  }'
```

```bash 参考视频
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "action": "generate",
    "prompt": "沿用参考视频的运镜，把场景换成雨夜的城市街道",
    "video_urls": ["https://cdn.example.com/reference.mp4"],
    "duration": 8,
    "resolution": "720p",
    "aspect_ratio": "adaptive"
  }'
```

```bash 视频编辑
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "action": "edit",
    "prompt": "去掉画面里的路人，只保留主角，其余保持不变",
    "video_urls": ["https://cdn.example.com/source.mp4"],
    "duration": 0,
    "resolution": "720p",
    "aspect_ratio": "adaptive"
  }'
```

```bash 视频延长
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "action": "extend",
    "prompt": "接着往后拍：人物走出画面，镜头留在空荡的街道上",
    "video_urls": ["https://cdn.example.com/source.mp4"],
    "duration": 8,
    "resolution": "720p",
    "aspect_ratio": "adaptive"
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

`edit` 与 `extend` 接的是**视频链接**，不是上一步的 `task_id`：先用 `generate` 出片，从任务结果的 `result.videos[].url` 取到视频地址，再把它放进 `video_urls` 提交下一步。想接着做同一条片子的续集，也可以在上一步带 `return_last_frame`，用返回的尾帧图当下一次的 `first_frame_image`。

## 请求参数

<ParamField body="model" type="string" required>
  模型 ID，取值见「可用模型」。
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`：生成视频，所有模型都支持
  - `edit`：编辑源视频，仅 `seedance-2.5`
  - `extend`：延长源视频，仅 `seedance-2.5`

  `edit` 与 `extend` 都必须提供 `video_urls`，并使用 `adaptive` 画幅。
</ParamField>

<ParamField body="prompt" type="string" required>
  视频描述或编辑指令。`seedance-2.0`、`seedance-2.0-fast`、`seedance-2.0-mini` 在带参考素材时提示词可选，其余情况必填。
</ParamField>

<ParamField body="duration" type="integer">
  输出时长（秒），整数。取值范围按模型不同：`seedance-1.0-pro` 与 `seedance-1.0-pro-fast` 为 `2`–`12`，`seedance-1.5-pro` 为 `4`–`12`，2.0 三档为 `4`–`15`，`seedance-2.5` 为 `4`–`30`。

  `seedance-2.5` 的 `edit` 传 `0`，表示输出沿用源视频时长。
</ParamField>

<ParamField body="resolution" type="string">
  输出分辨率，各模型可选档位见「可用模型」。默认值：`seedance-1.0-pro` 与 `seedance-1.0-pro-fast` 为 `1080p`，其余模型为 `720p`。
</ParamField>

<ParamField body="aspect_ratio" type="string">
  画面比例：`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`21:9`。2.x 四个模型另支持 `adaptive`（跟随输入素材）。

  默认值：`seedance-2.5` 为 `adaptive`，其余模型为 `16:9`。2.x 的首帧、首尾帧任务以及 `edit`、`extend` 都只能用 `adaptive`。
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成数量，取值 `1`。每次任务返回一个视频。
</ParamField>

<ParamField body="seed" type="integer">
  随机种子。相同请求与相同种子生成相近结果。
</ParamField>

<ParamField body="first_frame_image" type="string">
  首帧图片 URL。所有模型都支持。
</ParamField>

<ParamField body="last_frame_image" type="string">
  尾帧图片 URL，必须与 `first_frame_image` 一起提供。`seedance-1.0-pro-fast` 不支持。
</ParamField>

<ParamField body="image_urls" type="string[]">
  参考图 URL 数组。`seedance-1.5-pro` 最多 2 张，2.0 三档最多 9 张，`seedance-2.5` 最多 30 张；`seedance-1.0-pro` 与 `seedance-1.0-pro-fast` 不接受该字段。传首帧或尾帧时不能同时传参考图。
</ParamField>

<ParamField body="video_urls" type="string[]">
  参考视频 URL 数组。2.0 三档最多 3 段、总时长 2–15 秒，`seedance-2.5` 最多 10 段、总时长 2–30 秒；1.0 与 1.5 不接受该字段。`seedance-2.5` 的 `edit` 与 `extend` 用它传源视频。
</ParamField>

<ParamField body="audio_urls" type="string[]">
  参考音频 URL 数组。2.0 三档最多 3 段、总时长不超过 15 秒，`seedance-2.5` 最多 10 段、总时长不超过 30 秒、单段 2–30 秒；1.0 与 1.5 不接受该字段。
</ParamField>

<ParamField body="generate_audio" type="boolean" default="true">
  是否生成带声音的视频。`seedance-1.5-pro` 与 2.x 四个模型支持；`seedance-1.0-pro` 与 `seedance-1.0-pro-fast` 不支持。
</ParamField>

<ParamField body="watermark" type="boolean">
  是否给输出视频加水印。仅 `seedance-2.5` 支持。
</ParamField>

<ParamField body="image_with_roles" type="object[]">
  带角色的图片数组，与 `first_frame_image`、`last_frame_image` 合并发送。每项包含 `url` 和 `role`，`role` 取 `first_frame` 或 `last_frame`。所有模型都支持。
</ParamField>

<ParamField body="camerafixed" type="boolean" default="false">
  固定镜头，减少相机运动。仅 `seedance-1.5-pro` 的 `generate` 支持。
</ParamField>

<ParamField body="return_last_frame" type="boolean" default="false">
  额外返回尾帧图，便于连续生成。2.x 四个模型支持。
</ParamField>

<ParamField body="tools" type="object[]">
  增强工具列表，目前仅支持 `[{"type": "web_search"}]`，生成时参考联网信息。2.x 四个模型支持。
</ParamField>

<ParamField body="output_format" type="string" default="mp4">
  输出视频封装格式，`mp4` 或 `mov`。仅 `seedance-2.5` 支持。
</ParamField>

<ParamField body="omni_reference_task_type" type="string" default="auto">
  `generate` 时的参考模式提示，`auto` 或 `reference`。传 `reference` 会在提交时按参考生视频的约束校验，不合法直接返回 `400`，不建任务也不计费。`edit` 与 `extend` 由 `action` 决定，不需要这个字段。仅 `seedance-2.5` 支持。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

以上之外的参数会返回 `400`，不计费。

## 限制

- 每次任务只生成一个视频。
- 该模型必须提供提示词。（`seedance-1.0-pro`、`seedance-1.0-pro-fast`、`seedance-1.5-pro`、`seedance-2.5`）
- 纯文生视频必须提供提示词；有参考素材时提示词可选。（`seedance-2.0`、`seedance-2.0-fast`、`seedance-2.0-mini`）
- generate/extend 必须明确传入 2–12 秒时长。（`seedance-1.0-pro`、`seedance-1.0-pro-fast`）
- generate/extend 必须明确传入 4–12 秒时长。（`seedance-1.5-pro`）
- generate/extend 必须明确传入 4–15 秒时长。（`seedance-2.0`、`seedance-2.0-fast`、`seedance-2.0-mini`）
- generate/extend 必须明确传入 4–30 秒时长。（`seedance-2.5`）
- 尾帧必须与首帧一起提供。（`seedance-1.0-pro-fast` 之外的模型）
- 首尾帧不能与一般图片引用混用。
- 2.x 首帧任务必须使用 adaptive 画幅。
- 2.x 首尾帧任务必须使用 adaptive 画幅。
- 最多提供两张参考图。（`seedance-1.5-pro`）
- 参考视频必须是可读取时长的 HTTP(S) MP4/MOV/WebM，首发不支持 asset://；总时长须为 2–15 秒。（`seedance-2.0`、`seedance-2.0-fast`、`seedance-2.0-mini`）
- 参考视频必须是可读取时长的 HTTP(S) MP4/MOV/WebM，首发不支持 asset://；总时长须为 2–30 秒。（`seedance-2.5`）
- Seedance 2.0 系列不接受纯音频参考。
- 视频编辑需要源视频、adaptive 画幅，输出时长沿用源视频。（`seedance-2.5` · `edit`）
- 待编辑源视频必须为 4–30 秒。（`seedance-2.5` · `edit`）
- 视频延长需要源视频并使用 adaptive 画幅。（`seedance-2.5` · `extend`）

| 项目 | 1.0 Pro / Pro Fast | 1.5 Pro | 2.0 / Fast / Mini | 2.5 |
|---|---|---|---|---|
| 参考图 `image_urls` | 不支持 | 2 张 | 9 张 | 30 张 |
| 参考视频 `video_urls` | 不支持 | 不支持 | 3 段，总时长 2–15 秒 | 10 段，总时长 2–30 秒 |
| 参考音频 `audio_urls` | 不支持 | 不支持 | 3 段，总时长 ≤ 15 秒 | 10 段，总时长 ≤ 30 秒 |
| 时长 `duration` | 2–12 秒 | 4–12 秒 | 4–15 秒 | 4–30 秒 |
| 传首帧 / 尾帧时不能同时传 | 该档不接受参考素材 | `image_urls` | `image_urls` / `video_urls` / `audio_urls` | `image_urls` |

2.5 的子任务类型上游还会从提示词判断一次：`edit` 的提示词写成删除、替换、修改一类的编辑指令，`extend` 的提示词写成继续、往后接一类的续拍指令，与 `action` 保持一致。

## 计费

按**输出分辨率档 × 输出秒数**计费，秒数取请求里的 `duration`。同一模型下分辨率越高越贵；同一分辨率下，`seedance-2.0-mini` 最便宜、`seedance-2.0-fast` 居中、`seedance-2.0` 最贵。

带参考视频（`video_urls`）时换一套档位，费用由两项相加：

- **输出秒数**改按该分辨率的**参考视频档**单价结算
- **参考视频自身的时长**按**输入秒**单价再计一笔

参考视频时长在提交时探测，探测不到时按该模型声明的参考视频时长上限计入。参考图与参考音频不单独计费。

`seedance-1.5-pro` 有独立的带声档，开启 `generate_audio` 时按对应分辨率的带声档结算；其余模型没有独立带声档，音频不改变计费档位。

`seedance-2.5` 的 `edit` 传 `duration: 0`，输出时长由源视频决定：提交时按该模型的时长上限冻结额度，任务完成后按源视频的实际时长结算，差额退回。

<Note>
单价会随上游调整，本节只讲计费维度与口径，不列具体金额。

看实时单价：`GET /v1/models` 的 `price_config`，或控制台「模型市场」。
看单次实际费用：任务响应里的 `cost`（整数 quota，500,000 quota = 1 USD）。
</Note>

只有成功出片才计费。任务失败、取消，或上游返回成功但没有可交付视频时，全额退款。最终费用以任务响应里的 `cost` 为准，`cost` 是整数 quota 不是美元（500,000 quota = 1 USD）。

## 响应

```json 任务完成
{
  "task_id": "task-wave1775285160b950328499",
  "model": "seedance-2.0",
  "action": "generate",
  "status": "completed",
  "progress": "100%",
  "created_at": 1775285160,
  "completed_at": 1775285300,
  "result": {
    "videos": [
      {
        "expires_at": 1775371560,
        "url": ["https://cdn.example.com/result.mp4"]
      }
    ]
  },
  "billing_status": "settled",
  "cost": 75000,
  "urls": {
    "get": "https://www.qingbo.dev/v1/tasks/task-wave1775285160b950328499",
    "cancel": "https://www.qingbo.dev/v1/tasks/task-wave1775285160b950328499/cancel"
  }
}
```

`result.videos` 返回生成的视频，`url` 是数组，`expires_at` 是链接过期时间（Unix 秒），过期前请自行转存。提交时带了 `return_last_frame` 的任务，结果里还会附带尾帧图。完整字段说明见[查询任务状态](/cn/api-reference/task/status)。

## 可用模型

| 模型 ID | 分辨率 | 时长（秒） | 可接收的参考素材 | 动作 |
|---|---|---|---|---|
| `seedance-1.0-pro` | `480p` / `720p` / `1080p` | 2–12 | 首帧、尾帧 | `generate` |
| `seedance-1.0-pro-fast` | `480p` / `720p` / `1080p` | 2–12 | 首帧 | `generate` |
| `seedance-1.5-pro` | `480p` / `720p` / `1080p` | 4–12 | 首尾帧、参考图 ×2 | `generate` |
| `seedance-2.0` | `480p` / `720p` / `1080p` / `4k` | 4–15 | 首尾帧、图 ×9、视频 ×3、音频 ×3 | `generate` |
| `seedance-2.0-fast` | `480p` / `720p` | 4–15 | 首尾帧、图 ×9、视频 ×3、音频 ×3 | `generate` |
| `seedance-2.0-mini` | `480p` / `720p` | 4–15 | 首尾帧、图 ×9、视频 ×3、音频 ×3 | `generate` |
| `seedance-2.5` | `480p` / `720p` / `1080p` | 4–30 | 首尾帧、图 ×30、视频 ×10、音频 ×10 | `generate` / `edit` / `extend` |
