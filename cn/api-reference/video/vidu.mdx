生数科技 Vidu Q3 系列。本页覆盖 `vidu-q3`、`vidu-q3-mix`、`vidu-q3-pro` 和 `vidu-q3-turbo`：四个模型走同一个任务接口，都只有 `generate` 一个动作，都按分辨率档与秒数计费，区别在于要不要参考图、支持哪些分辨率档，以及能不能生成音频。前两个是参考生视频（`image_urls` 必填，人物与风格由参考图决定），后两个既能文生视频也能用首帧或首尾帧，并且默认带原生音频。

## 快速开始

<CodeGroup>

```bash 参考图生视频
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: vidu-demo-001" \
  -d '{
    "model": "vidu-q3",
    "action": "generate",
    "prompt": "保持角色形象，在森林中奔跑，镜头跟随",
    "image_urls": ["https://cdn.example.com/character.jpg"],
    "duration": 5,
    "resolution": "1080p"
  }'
```

```bash 多参考融合
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vidu-q3-mix",
    "action": "generate",
    "prompt": "角色在这个场景里坐下，拿起桌上的杯子",
    "image_urls": [
      "https://cdn.example.com/character.jpg",
      "https://cdn.example.com/scene.jpg",
      "https://cdn.example.com/cup.jpg"
    ],
    "duration": 8,
    "resolution": "1080p",
    "aspect_ratio": "16:9"
  }'
```

```bash 文生视频
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vidu-q3-pro",
    "action": "generate",
    "prompt": "日出时分的海边天文台，镜头固定，海浪拍岸",
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "generate_audio": true
  }'
```

```bash 首尾帧
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vidu-q3-turbo",
    "action": "generate",
    "prompt": "镜头从室内缓缓推到窗外的街景",
    "image_urls": [
      "https://cdn.example.com/start.jpg",
      "https://cdn.example.com/end.jpg"
    ],
    "duration": 5,
    "resolution": "720p"
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  四选一：`vidu-q3`、`vidu-q3-mix`、`vidu-q3-pro` 或 `vidu-q3-turbo`。
</ParamField>

<ParamField body="action" type="string" default="generate">
  `generate` 是本页四个模型唯一的动作。生成模式不由 `action` 区分，而是看 `image_urls` 传了几张：`vidu-q3-pro` 与 `vidu-q3-turbo` 不传是文生视频，传 1 张是起始帧，传 2 张是首尾帧；`vidu-q3` 与 `vidu-q3-mix` 必须传参考图。
</ParamField>

<ParamField body="prompt" type="string">
  视频描述，写动作、镜头与氛围；带参考图时人物外观由参考图决定。`vidu-q3` 与 `vidu-q3-mix` 必填；`vidu-q3-pro` 与 `vidu-q3-turbo` 在不传 `image_urls` 时必填。
</ParamField>

<ParamField body="image_urls" type="string[]">
  图片 URL 数组。

  - `vidu-q3`、`vidu-q3-mix`：参考图，必填，决定主体、风格与场景
  - `vidu-q3-pro`、`vidu-q3-turbo`：可选，最多 2 张，1 张作起始帧、2 张作首尾帧
</ParamField>

<ParamField body="duration" type="integer">
  视频时长（秒），整数。

  - `vidu-q3`：`3` 到 `16`
  - `vidu-q3-mix`：`1` 到 `16`
  - `vidu-q3-pro`、`vidu-q3-turbo`：`1` 到 `16`，默认 `5`
</ParamField>

<ParamField body="resolution" type="string">
  输出分辨率。

  - `vidu-q3`：`540p`、`720p` 或 `1080p`
  - `vidu-q3-mix`：`720p` 或 `1080p`
  - `vidu-q3-pro`、`vidu-q3-turbo`：`540p`、`720p` 或 `1080p`，默认 `720p`
</ParamField>

<ParamField body="aspect_ratio" type="string">
  画面比例：`16:9`、`9:16`、`4:3`、`3:4`、`1:1`。`vidu-q3`、`vidu-q3-pro` 和 `vidu-q3-turbo` 不传时为 `16:9`。`vidu-q3-pro` 与 `vidu-q3-turbo` 带 `image_urls` 时不能传这个参数，画幅由输入图片决定。
</ParamField>

<ParamField body="generate_audio" type="boolean" default="true">
  是否生成音频（对白与音效）。只有 `vidu-q3-pro` 和 `vidu-q3-turbo` 接受，需要无声视频时设为 `false`。
</ParamField>

<ParamField body="seed" type="integer">
  随机种子。同一组参数配同一个种子会得到接近的结果，不保证完全一致。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

本页四个模型都不接受 `first_frame_image`、`last_frame_image`（首尾帧用 `image_urls` 表达）、`video_urls`、`audio_urls`、`n`、`negative_prompt` 和 `quality`；`generate_audio` 只有 `vidu-q3-pro` 与 `vidu-q3-turbo` 接受。以上之外的参数会返回 `400`，不计费。

## 限制

| 模型 | 条件 | 限制 |
|---|---|---|
| `vidu-q3` `vidu-q3-mix` | 每次请求 | 本模型一次任务只产出一个结果，不支持用 n 批量生成 |
| `vidu-q3` `vidu-q3-mix` | 每次请求 | 必须提供 `image_urls` |
| `vidu-q3-pro` `vidu-q3-turbo` | 每次请求 | 每次任务只生成一个视频；最多 2 张图片（1 张起始帧，2 张首尾帧）。 |
| `vidu-q3-pro` `vidu-q3-turbo` | 传 `image_urls` | 图生视频的画幅由输入图片决定，不能传 `aspect_ratio`。 |

## 计费

按**分辨率档 × 秒数**计费：分辨率决定每秒单价，`duration` 决定秒数，两者相乘就是这一单的费用，提交前即可确定。四个模型的每秒单价各不相同，同一个模型内分辨率越高越贵。

`generate_audio`、`seed`、画面比例、参考图张数都不影响价格。`vidu-q3-pro` 与 `vidu-q3-turbo` 没带 `resolution` 时按默认档 `720p` 计费。

<Note>
**本页不列具体单价**——单价会随上游调整，这里只讲计费维度与口径。

实时单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。单次调用的实际费用见任务响应里的 `cost`：整数 quota，**500,000 quota = 1 USD**。
</Note>

只有成功出片才计费。任务失败、取消，或没有返回可用视频时，全额退款。

## 可用模型

| 模型 ID | 分辨率 | 时长（秒） | 图片输入 | 备注 |
|---|---|---|---|---|
| `vidu-q3` | `540p` `720p` `1080p` | 3–16 | 参考图，必填 | 参考生视频，多镜头切换 |
| `vidu-q3-mix` | `720p` `1080p` | 1–16 | 参考图，必填 | 多张参考图融合成一段连贯视频 |
| `vidu-q3-pro` | `540p` `720p` `1080p` | 1–16 | 可选，最多 2 张 | 文生 / 起始帧 / 首尾帧，默认带音频 |
| `vidu-q3-turbo` | `540p` `720p` `1080p` | 1–16 | 可选，最多 2 张 | 与 Pro 同能力的加速档，单价更低 |
