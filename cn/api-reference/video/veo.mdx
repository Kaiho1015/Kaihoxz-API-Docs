Google Veo 3.1 的视频模型线，分两条线路。官方版 `veo3.1-fast` 与 `veo3.1-quality` 支持 4 / 6 / 8 秒、首尾帧、原生音频和 `seed`，按秒计费；经济版 `veo3.1-lite`、`veo3.1-fast-rev`、`veo3.1-quality-rev` 通过聚合供应商接入，固定输出 8 秒、按整片固定价计费，两个 `-rev` 档还能把自己生成的视频接着往下续写。两条线路参数集合与计费方式都不同，不会自动互相切换。

## 快速开始

<CodeGroup>

```bash 文生视频（官方版）
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: veo-demo-001" \
  -d '{
    "model": "veo3.1-fast",
    "action": "generate",
    "prompt": "航拍雪山日出，云海翻涌，镜头缓缓推进",
    "duration": 8,
    "resolution": "1080p",
    "aspect_ratio": "16:9"
  }'
```

```bash 续写（经济版）
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo3.1-fast-rev",
    "action": "extend",

```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

**接着往下做**：续写分两步。先用 `veo3.1-fast-rev` 或 `veo3.1-quality-rev` 提交 `action: "generate"` 拿到 `task_id`；等这个任务 `completed` 之后，把它的 `task_id` 作为 `ref_task_id` 提交 `action: "extend"`。`ref_task_id` 用的是上一步任务返回的 `task_id`，不是上游 ID，且必须是同一个模型、同一个 API Key 下已完成的 `generate` 任务。

## 请求参数

### 两条线路共用

<ParamField body="model" type="string" required>
  模型 ID，取值见「可用模型」。
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`：生成视频，5 个模型都支持
  - `extend`：把已完成的视频接着往下续写，只有 `veo3.1-fast-rev` 与 `veo3.1-quality-rev` 支持；必须提供 `ref_task_id`
</ParamField>

<ParamField body="prompt" type="string" required>
  视频描述；`action: "extend"` 时描述续写部分的内容。
</ParamField>

<ParamField body="duration" type="integer">
  输出时长（秒），`action: "generate"` 时必填。官方版取 `4`、`6` 或 `8`，其中 `resolution: "1080p"` 只支持 `8`；经济版固定为 `8`。`action: "extend"` 不接受这个参数，续写时长由上游决定。
</ParamField>

<ParamField body="resolution" type="string" default="720p">
  输出分辨率：`720p` 或 `1080p`。
</ParamField>

<ParamField body="aspect_ratio" type="string" default="16:9">
  画面比例：`16:9` 或 `9:16`。
</ParamField>

### 官方版（`veo3.1-fast` / `veo3.1-quality`）

<ParamField body="first_frame_image" type="string">
  首帧图 URL。
</ParamField>

<ParamField body="last_frame_image" type="string">
  尾帧图 URL，必须与 `first_frame_image` 一起提供。
</ParamField>

<ParamField body="negative_prompt" type="string">
  负面提示词，描述不希望出现的内容。
</ParamField>

<ParamField body="seed" type="integer">
  随机种子，用于复现生成结果。
</ParamField>

<ParamField body="generate_audio" type="boolean" default="false">
  是否生成原生音频。开启后走带声档计费。
</ParamField>

<ParamField body="person_generation" type="string">
  人物生成策略：`allow_adult` 允许生成成年人物 / `disallow` 不生成人物。
</ParamField>

<ParamField body="resize_mode" type="string">
  首尾帧与输出比例不一致时的处理方式：`pad` 补边 / `crop` 裁切。
</ParamField>

### 经济版（`veo3.1-lite` / `veo3.1-fast-rev` / `veo3.1-quality-rev`）

<ParamField body="image_urls" type="string[]">
  参考图 URL 数组，`veo3.1-fast-rev` 与 `veo3.1-quality-rev` 支持，张数按 `generation_type` 而定。`veo3.1-lite` 是纯文生视频，不接受图片。
</ParamField>

<ParamField body="generation_type" type="string">
  图片的用法，提供 `image_urls` 时必填：

  - `frame`：把图片当首帧 / 尾帧用，接受 1–2 张
  - `reference`：把图片当参考素材用，接受 1–3 张；只有 `veo3.1-fast-rev` 支持
</ParamField>

<ParamField body="enable_gif" type="boolean" default="false">
  额外输出一份 GIF。不能与 `resolution: "1080p"` 同时使用。
</ParamField>

<ParamField body="ref_task_id" type="string" required>
  被续写的父任务 ID，`action: "extend"` 时必填。取上一步 `generate` 任务返回的 `task_id`。
</ParamField>

<ParamField body="raw" type="boolean" default="false">
  `action: "extend"` 时是否只返回续写出来的那一段。`false` 返回拼接后的完整视频。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

官方版不接受 `image_urls`、`generation_type`、`enable_gif`、`ref_task_id` 和 `raw`；经济版不接受 `first_frame_image`、`last_frame_image`、`negative_prompt`、`seed`、`generate_audio`、`person_generation` 和 `resize_mode`。以上之外的参数会返回 `400`，不计费。

## 限制

| 模型 | 条件 | 限制 |
|---|---|---|
| 全部 | `action: "generate"` | 视频生成必须提供提示词和时长。 |
| `veo3.1-fast`、`veo3.1-quality` | 提供了 `last_frame_image` | 尾帧必须与首帧一起提供。 |
| `veo3.1-fast`、`veo3.1-quality` | `resolution: "1080p"` | 1080p 仅支持 8 秒。 |
| `veo3.1-fast-rev`、`veo3.1-quality-rev` | `action: "generate"` | 经济版生成固定为 8 秒。 |
| `veo3.1-fast-rev`、`veo3.1-quality-rev` | `action: "extend"` | 续写只接受父任务、提示词和 raw。 |
| `veo3.1-fast-rev`、`veo3.1-quality-rev` | 提供了 `image_urls` | 提供图片时必须声明 generation_type。 |
| `veo3.1-fast-rev`、`veo3.1-quality-rev` | `generation_type: "frame"` | frame 模式接受一至两张图片。 |
| `veo3.1-fast-rev` | `generation_type: "reference"` | reference 模式最多接受三张图片。 |

| 项目 | 模型 | 上限 |
|---|---|---|
| 参考图张数 | `veo3.1-fast-rev` | 3 张 |
| 参考图张数 | `veo3.1-quality-rev` | 2 张 |
| 参考图张数 | `veo3.1-lite` | 不接受图片 |
| 首尾帧 | `veo3.1-fast`、`veo3.1-quality` | 首帧、尾帧各 1 张 |
| 时长 | `veo3.1-fast`、`veo3.1-quality` | 4 / 6 / 8 秒，最长 8 秒 |
| 时长 | `veo3.1-lite`、`veo3.1-fast-rev`、`veo3.1-quality-rev` | 固定 8 秒 |

`action: "extend"` 的 `ref_task_id` 必须指向同一个模型下、状态已经是完成的 `generate` 任务；指向别的模型、别的动作或尚未完成的任务会返回 `400`，不计费。

## 计费

两条线路的计费方式不同，选型时先看这一节。

### 官方版

`veo3.1-fast` 与 `veo3.1-quality` 按**分辨率档 × 秒数**计费：`resolution` 决定档位（`720p` / `1080p`），秒数取请求里的 `duration`（`4`、`6` 或 `8`）。

`generate_audio: true` 时换成带声档的每秒单价，仍然只乘 `duration`。两个分辨率都有带声档。首尾帧、`negative_prompt`、`seed` 不影响价格。

### 经济版

`veo3.1-lite`、`veo3.1-fast-rev`、`veo3.1-quality-rev` 按**整片固定价**计费：一次生成一次收费，与时长无关（输出固定 8 秒），分辨率是唯一的分档维度，参考图张数与 `generation_type` 不影响价格。

`action: "extend"` 同样按整片固定价计一次费用，与续写出来的长度无关；`raw` 取 `true` 或 `false` 不影响价格。

<Note>
各模型的单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。

看这一单实际花了多少：任务响应里的 `cost`（整数 quota，500,000 quota = 1 USD）。
</Note>

只有成功出片才计费。任务失败、取消，或没有返回可用视频时，全额退款。最终费用以任务响应里的 `cost` 为准，它是整数 quota 不是美元。

## 可用模型

**官方版** —— 按秒计费，支持首尾帧与原生音频。

| 模型 ID | 时长 | 分辨率 | 图片输入 | 原生音频 |
|---|---|---|---|---|
| `veo3.1-fast` | 4 / 6 / 8 秒 | `720p` `1080p`（1080p 仅 8 秒） | 首帧 + 尾帧 | 支持 |
| `veo3.1-quality` | 4 / 6 / 8 秒 | `720p` `1080p`（1080p 仅 8 秒） | 首帧 + 尾帧 | 支持 |

**经济版** —— 整片固定价，固定输出 8 秒，不支持原生音频。

| 模型 ID | 动作 | 分辨率 | 图片输入 | GIF |
|---|---|---|---|---|
| `veo3.1-lite` | `generate` | `720p` `1080p` | 不接受 | `enable_gif` |
| `veo3.1-fast-rev` | `generate` `extend` | `720p` `1080p` | `frame` 1–2 张 / `reference` 1–3 张 | `enable_gif` |
| `veo3.1-quality-rev` | `generate` `extend` | `720p` `1080p` | `frame` 1–2 张 | `enable_gif` |
