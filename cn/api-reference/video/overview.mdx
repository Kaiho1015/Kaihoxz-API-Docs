清波 API 支持多家视频生成模型,**统一通过异步任务接口** `/v1/tasks` 调用。视频生成通常耗时 10 秒到几分钟不等,提交后返回 `task_id`,通过轮询或 Webhook 回调获取结果。

## 请求端点

```
POST https://www.qingbo.dev/v1/tasks
```

异步流程详见 [任务系统](/cn/docs/task-system) — Submit → Status → Result + 可选 webhook。

## 通用参数(全系列共有)

> 各模型实际支持范围不同,**详见各 vendor 文档**。

<ParamField body="model" type="string" required>
  模型 ID(group_name),从上面的 vendor 文档选择
</ParamField>

<ParamField body="action" type="string" default="generate">
  `generate` — 本模型唯一动作。

  **模式不靠 action 区分,靠传什么:** 只给 `prompt` 是文生视频;带 `image_urls` 是图生视频;带 `first_frame_image` + `last_frame_image` 是首尾帧;带 `video_urls` / `audio_urls` 是参考生视频。
</ParamField>

<ParamField body="prompt" type="string">
  视频描述文本,T2V 必填;其他模式可选作引导
</ParamField>

<ParamField body="duration" type="integer">
  视频时长(秒),范围取决于模型
</ParamField>

<ParamField body="aspect_ratio" type="string">
  画面宽高比,如 `16:9` / `9:16` / `1:1` 等
</ParamField>

<ParamField body="resolution" type="string">
  输出分辨率,如 `720p` / `1080p` / `4K`
</ParamField>

<ParamField body="image_urls" type="string[]">
  参考图片 URL 数组(I2V / R2V 用)
</ParamField>

<ParamField body="first_frame_image" type="string">
  视频首帧图 URL(首尾帧模式用)
</ParamField>

<ParamField body="last_frame_image" type="string">
  视频尾帧图 URL,需配合 `first_frame_image`
</ParamField>

<ParamField body="video_urls" type="string[]">
  参考视频 URL 数组,**单元素即可**(视频续写 / R2V 视频参考 / 视频编辑用)

  <Note>
  **参考视频计费因厂商而异**,详见各模型页,以及下面的 [输入视频的时长与计费](#输入视频的时长与计费)。
  </Note>
</ParamField>

<ParamField body="audio_urls" type="string[]">
  参考音频 URL 数组,**单元素即可**(驱动音 / 自定义配音用)
</ParamField>

<ParamField body="callback_url" type="string">
  Webhook 回调地址,任务终态时调用。详见 [任务系统](/cn/docs/task-system#webhook)
</ParamField>

## 输入视频的时长与计费

传 `video_urls` 的请求(参考视频 / 视频编辑 / 运动控制)按下面三条处理。

**怎么算秒数** —— 网关会读取视频文件头得到真实时长,**按秒截断取整**(10.9 秒算 10 秒),不足 1 秒按 1 秒。与上游口径一致。

**算不出来会怎样** —— 若文件头无法解析(格式特殊、URL 不可达等),请求会被**拒绝**并返回 `400 input_video_duration_unknown`,**不会扣费**,而不是按上限估算收费。请改用常见容器格式(mp4 / webm)的可直接下载 URL。

**提交前可预估** —— `POST https://www.qingbo.dev/waveapi/quote` 传入 `video_urls` 会返回这一单的准确价格,含探测到的输入秒数。

这是**公开工具接口,不需要 API key**。返回走标准信封 `{code, message, data}`,`data` 里是:

| 字段 | 含义 |
|---|---|
| `total_usd` | 这一单的总价(美元) |
| `unit` | 计费单位(秒 / 张 / 字符 等) |
| `billed_quantity` | 实际计费数量,输入视频的探测秒数体现在这里 |
| `multipliers` | 生效的倍率(用户组倍率等) |

被拒时 `errorKey` 会带具体原因(如 `input_video_duration_unknown`),`message` 里是可直接展示给用户的说明。

参考视频具体怎么进价格(计入秒数、只换档、还是替代整片价),按厂商不同,见各模型页的计费段。

## 提交响应示例

```json
{
  "task_id": "task-wave1775285160b950328499",
  "model": "veo3.1-quality",
  "action": "generate",
  "status": "queued",
  "created_at": 1775285160040,
  "progress": 0
}
```

拿到 `task_id` 后调 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 轮询,直到 `status = completed` 取视频 URL。

## 生成模式速查

| 模式 | 触发字段 | 典型 vendor |
|---|---|---|
| **文生视频(T2V)** | 仅 `prompt` | 全部支持 generate action 的 vendor |
| **图生视频(I2V)** | `+ first_frame_image` 或 `image_urls`(单图) | Seedance / Kling / Hailuo / Vidu / Wan / Veo / SkyReels / Grok / HappyHorse / FLUX 3 Video / Omni |
| **首尾帧** | `first_frame_image + last_frame_image`(Kling 用 `image_urls` 传两张) | Seedance / Kling / Veo / Vidu / SkyReels / Hailuo 02 / Wan 3.0 / Gemini Omni 1.1 Flash |
| **参考生视频(R2V)** | `image_urls`(多图) | Seedance / Kling Omni / Vidu / SkyReels / HappyHorse / Wan 2.7 R2V / Omni |
| **视频参考(R2V 视频)** | `+ video_urls`(参考视频) | Seedance 2.x / Kling / SkyReels / Wan / MiniMax H3 / Omni |
| **视频续写** | `video_urls`(单段)或 `ref_task_id` | Omni / FLUX 3 Video / Veo 逆向版(`extend`)/ Seedance 2.5(`extend`) |
| **视频编辑(EDIT)** | `video_urls + prompt`(可加 `image_urls` 作风格参考) | Wan VideoEdit / HappyHorse 1.0 / Seedance 2.5 / Kling v3 Omni · Video O1 |
| **音频参考** | `+ audio_urls` | HappyHorse / Wan / SkyReels / Seedance 2.x / MiniMax H3 |

<Note>
并非所有模型都支持全部模式 — 各 vendor 实际支持的 `action` 列表 + 字段范围请查看对应文档。后端会校验请求字段是否在 vendor 声明的能力范围内,不在范围会返回错误。
</Note>

## 字段命名规范

- **媒体引用统一复数** — 一律 `image_urls` / `video_urls` / `audio_urls`,即使单视频也用单元素数组 `["one.mp4"]`
- **画面比例统一** `aspect_ratio` — vendor 内部用 `size` / `ratio` 等是实现细节,无需感知
- **分辨率统一** `resolution` — vendor 内部用 `mode` / `quality` 等是实现细节
- **首尾帧字段带 `_image` 后缀** — `first_frame_image` / `last_frame_image`(强调是图片资源)
