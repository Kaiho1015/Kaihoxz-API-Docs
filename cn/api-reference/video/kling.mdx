快手可灵（Kling）的视频模型线，当前有 7 个模型：通用生成的 `kling-3.0-turbo`、`kling-v2-6`、`kling-v3`，带参考视频与视频编辑能力的 `kling-v3-omni`、`kling-video-o1`，以及做动作迁移的 `kling-v2-6-motion-control`、`kling-v3-motion-control`。它们共用同一个任务接口 `POST /v1/tasks`，换模型只改 `model`，但支持的动作、参数与时长各不相同，逐项差异见「可用模型」。

## 快速开始

<CodeGroup>

```bash 文生视频
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: kling-demo-001" \
  -d '{
    "model": "kling-3.0-turbo",
    "action": "generate",
    "prompt": "雨后的城市街道，霓虹倒映在积水里，镜头缓缓推进",
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "n": 1
  }'
```

```bash 首尾帧图生视频
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-v2-6",
    "action": "generate",
    "prompt": "人物从侧身转向镜头，微风吹动头发",
    "image_urls": [
      "https://cdn.example.com/first.jpg",
      "https://cdn.example.com/last.jpg"
    ],
    "duration": 5,
    "resolution": "1080p"
  }'
```

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  模型 ID，取值见「可用模型」。
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`：生成视频，7 个模型都支持
  - `edit`：编辑源视频，只有 `kling-v3-omni` 和 `kling-video-o1` 支持；必须提供 `video_urls`
</ParamField>

<ParamField body="prompt" type="string" required>
  视频描述或编辑指令。`kling-v3-omni` 与 `kling-video-o1` 可以在提示词里用 `<<<image_1>>>`、`<<<image_2>>>` 引用 `image_urls` 中第 1、第 2 张图；`kling-v3` 与 `kling-v3-omni` 用 `element_list` 时用 `@主体名` 引用参考主体。
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成数量，取值 `1`。每次任务返回一个视频。
</ParamField>

<ParamField body="duration" type="integer" required>
  输出时长（秒），按模型取值：

  - `kling-3.0-turbo`、`kling-v3`、`kling-v3-omni`：`3`–`15` 的整数
  - `kling-v2-6`、`kling-video-o1`：`5` 或 `10`
  - `kling-v2-6-motion-control`、`kling-v3-motion-control`：传 `0`，表示跟随参考视频时长
  - `action: "edit"`（`kling-v3-omni` / `kling-video-o1`）：传 `0`，表示沿用源视频时长
</ParamField>

<ParamField body="resolution" type="string" default="720p">
  输出分辨率档：`720p` 或 `1080p`。7 个模型都支持这两档。
</ParamField>

<ParamField body="aspect_ratio" type="string">
  画面比例：`16:9`、`9:16` 或 `1:1`。两个 `*-motion-control` 不接受这个参数。传了参考图时输出比例跟随输入图。
</ParamField>

<ParamField body="image_urls" type="string[]">
  参考图 URL 数组：

  - `kling-3.0-turbo`：最多 1 张，作首帧
  - `kling-v2-6`、`kling-v3`、`kling-v3-omni`、`kling-video-o1`：最多 2 张；两张时为首帧与尾帧
  - 两个 `*-motion-control`：必填，1 张角色参考图
  - 带 `video_urls` 时（`kling-v3-omni` / `kling-video-o1`）最多 1 张；`action: "edit"` 不接受参考图
</ParamField>

<ParamField body="video_urls" type="string[]">
  参考视频 URL 数组，最多 1 个：

  - `kling-v3-omni`、`kling-video-o1`：`action: "generate"` 时作运镜与特征参考，`action: "edit"` 时作待编辑的源视频；长度 3–10 秒
  - 两个 `*-motion-control`：必填，动作来源视频；长度上限 30 秒
</ParamField>

<ParamField body="negative_prompt" type="string">
  负面提示词。`kling-v2-6`、`kling-v3`、`kling-v3-omni` 支持。
</ParamField>

<ParamField body="generate_audio" type="boolean" default="false">
  是否生成原生音频。`kling-v2-6`、`kling-v3`、`kling-v3-omni` 支持；`kling-v2-6` 只在 `resolution: "1080p"` 时可用，`kling-v3-omni` 不能与 `video_urls` 同时使用。
</ParamField>

<ParamField body="watermark" type="boolean">
  是否给输出视频加水印。除 `kling-video-o1` 外的 6 个模型支持。
</ParamField>

### 多镜头与参考主体（`kling-v3` / `kling-v3-omni`）

<ParamField body="multi_shot" type="boolean" default="false">
  开启多镜头分镜模式。
</ParamField>

<ParamField body="shot_type" type="string">
  分镜方式：`customize` 自定义镜头 / `intelligence` 智能分镜；`multi_shot: true` 时必填。
</ParamField>

<ParamField body="multi_prompt" type="array">
  多镜头分镜列表（1–6 项），每项 `{ index, prompt, duration }`；`index` 从 1 连续递增，各段 `duration` 之和须等于顶层 `duration`；需 `multi_shot: true`。
</ParamField>

<ParamField body="element_list" type="array">
  参考主体列表（最多 3 个），每项 `{ name, description, element_input_urls }`；`element_input_urls` 为 2–4 张图片，首张为正面照；提示词中用 `@name` 引用该主体。
</ParamField>

### 带角色图片（`kling-v3-omni` / `kling-video-o1`）

<ParamField body="image_with_roles" type="array">
  带角色的图片数组，每项 `{ url, role }`，`role` 取 `first_frame` / `last_frame` / `reference`；与 `first_frame_image` / `last_frame_image` 合并发送。
</ParamField>

### 动作控制（`kling-v2-6-motion-control` / `kling-v3-motion-control`）

<ParamField body="character_orientation" type="string" required>
  人物朝向以参考图或参考视频为准：`image` 或 `video`。两种取值对参考视频长度的要求不同，见「限制」。
</ParamField>

<ParamField body="keep_original_sound" type="string" default="yes">
  是否保留动作参考视频的原音轨：`yes` 或 `no`。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

Kling 系列不接受 `seed`、`quality` 和 `size`。以上之外的参数会返回 `400`，不计费。

## 限制

| 模型 | 条件 | 限制 |
|---|---|---|
| 全部 | 每次请求 | 每次任务只生成一个视频。 |
| `kling-3.0-turbo` | 每次请求 | 提示词必填且最多提供一张首帧图。 |
| `kling-3.0-turbo` | 提供了 `image_urls` | 图生视频跟随输入图比例，不接受 `aspect_ratio`。 |
| `kling-3.0-turbo`、`kling-v2-6`、`kling-v3` | 每次请求 | 必须明确提供输出时长。 |
| `kling-v2-6`、`kling-v3`、`kling-v3-omni`、`kling-video-o1` | 每次请求 | 提示词必填。 |
| `kling-v2-6`、`kling-v3`、`kling-v3-omni`、`kling-video-o1` | 每次请求 | 最多提供两张参考图。 |
| `kling-v2-6` | `generate_audio: true` | 原生音频只支持 1080p pro 档。 |
| `kling-v2-6` | `generate_audio: true` | 原生音频不能与双图首尾帧同时使用。 |
| `kling-v2-6` | 提供了两张 `image_urls` | 双图首尾帧只支持 1080p pro 档。 |
| `kling-v3-omni`、`kling-video-o1` | 提供了 `video_urls` | 视频参考最多搭配一张图片，参考视频必须为一个 3–10 秒视频。 |
| `kling-v3-omni`、`kling-video-o1` | `action: "edit"` | 首期视频编辑只接受一个源视频，输出时长沿用源视频。 |
| `kling-v3-omni`、`kling-video-o1` | `action: "generate"` | 视频生成必须明确提供输出时长。 |
| `kling-v3-omni` | `generate_audio: true` 且提供了 `video_urls` | 视频参考不能与原生音频开关同时使用。 |
| `kling-v2-6-motion-control`、`kling-v3-motion-control` | 每次请求 | 动作控制必须各提供一张参考图和一个参考视频，输出时长跟随参考视频。 |
| `kling-v2-6-motion-control`、`kling-v3-motion-control` | `character_orientation: "image"` | 图像朝向模式的参考视频必须为 3–10 秒。 |
| `kling-v2-6-motion-control`、`kling-v3-motion-control` | `character_orientation: "video"` | 视频朝向模式的参考视频必须为 3–30 秒。 |

| 项目 | 模型 | 上限 |
|---|---|---|
| 每次任务输出 | 全部 | 1 个视频 |
| 参考图张数 | `kling-3.0-turbo`、两个 `*-motion-control` | 1 张 |
| 参考图张数 | `kling-v2-6`、`kling-v3`、`kling-v3-omni`、`kling-video-o1` | 2 张 |
| 参考视频时长 | `kling-v3-omni`、`kling-video-o1` | 10 秒 |
| 参考视频时长 | `kling-v2-6-motion-control`、`kling-v3-motion-control` | 30 秒 |
| 分镜段数 | `kling-v3`、`kling-v3-omni` | 6 段 |
| 参考主体数 | `kling-v3`、`kling-v3-omni` | 3 个，每个 2–4 张图 |

时长跟随参考视频的请求（两个 `*-motion-control`，以及 `action: "edit"`）需要能从视频链接读出时长，读不到会返回 `400`，不计费；常见的 MP4 / WebM 链接都可以。

## 计费

按**分辨率档 × 输出秒数**计费。`resolution` 决定档位（`720p` / `1080p`），秒数取这一单实际的输出时长。

出现下面两种情况时，换一档每秒单价，仍然只乘输出秒数：

- **原生音频**：`generate_audio: true` 时走带声档。`kling-v3`、`kling-v3-omni` 两个分辨率都有带声档，`kling-v2-6` 只有 1080p 有。
- **参考视频**：`kling-v3-omni` 与 `kling-video-o1` 提供了 `video_urls` 时走参考视频档，`action: "generate"` 与 `action: "edit"` 都算。参考视频本身的秒数不另计费。

输出秒数怎么定：

- 传了具体 `duration` 的请求，按 `duration` 计费。
- `duration: 0` 的请求（两个 `*-motion-control`，以及 `action: "edit"`），输出时长跟随参考视频或源视频，按从该视频读到的时长计费。

<Note>
各模型的单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。

看这一单实际花了多少：任务响应里的 `cost`（整数 quota，500,000 quota = 1 USD）。
</Note>

只有成功出片才计费。任务失败、取消，或没有返回可用视频时，全额退款。最终费用以任务响应里的 `cost` 为准，它是整数 quota 不是美元。

## 可用模型

| 模型 ID | 动作 | 时长 | 分辨率 | 参考素材 |
|---|---|---|---|---|
| `kling-3.0-turbo` | `generate` | 3–15 秒 | `720p` `1080p` | 首帧图 1 张 |
| `kling-v2-6` | `generate` | 5 或 10 秒 | `720p` `1080p` | 参考图最多 2 张 |
| `kling-v3` | `generate` | 3–15 秒 | `720p` `1080p` | 参考图最多 2 张 |
| `kling-v3-omni` | `generate` `edit` | 3–15 秒；`edit` 沿用源视频 | `720p` `1080p` | 参考图最多 2 张、参考视频 1 个 |
| `kling-video-o1` | `generate` `edit` | 5 或 10 秒；`edit` 沿用源视频 | `720p` `1080p` | 参考图最多 2 张、参考视频 1 个 |
| `kling-v2-6-motion-control` | `generate` | 跟随参考视频 | `720p` `1080p` | 参考图 1 张 + 参考视频 1 个 |
| `kling-v3-motion-control` | `generate` | 跟随参考视频 | `720p` `1080p` | 参考图 1 张 + 参考视频 1 个 |

按能力挑模型：

- **原生音频**（`generate_audio`）：`kling-v2-6`（仅 `1080p`）、`kling-v3`、`kling-v3-omni`
- **多镜头分镜与参考主体**（`multi_shot` / `shot_type` / `multi_prompt` / `element_list`）：`kling-v3`、`kling-v3-omni`
- **带角色图片**（`image_with_roles`）：`kling-v3-omni`、`kling-video-o1`
- **视频编辑与参考视频**（`action: "edit"` / `video_urls`）：`kling-v3-omni`、`kling-video-o1`
- **动作迁移**（`character_orientation` / `keep_original_sound`）：`kling-v2-6-motion-control`、`kling-v3-motion-control`
- **负面提示词**（`negative_prompt`）：`kling-v2-6`、`kling-v3`、`kling-v3-omni`
