Qwen Image 是阿里巴巴 Qwen 团队的图像基础模型系列，把文生图和图像编辑统一在同一套接口里，强项是中英双语排版、信息图和海报里的文字渲染。本页覆盖当前可用的四个模型，分成两代：2.0 一代出图张数可达 6 张、按单一张价结算；3.0 一代支持多图参考与提示词扩写，参考图另行计费。

## 快速开始

<CodeGroup>

```bash 文生图
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: qwen-image-demo-001" \
  -d '{
    "model": "qwen-image-3.0",
    "action": "generate",
    "prompt": "咖啡馆菜单海报，中英双语，标题用衬线体，正文分两栏",
    "aspect_ratio": "3:4",
    "resolution": "2k",
    "n": 1
  }'
```

```bash 多图参考编辑
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: qwen-image-edit-001" \
  -d '{
    "model": "qwen-image-3.0-pro",
    "action": "edit",
    "prompt": "把第一张的商品放进第二张的展台，光线统一",
    "image_urls": [
      "https://cdn.example.com/product.png",
      "https://cdn.example.com/scene.png"
    ],
    "aspect_ratio": "1:1",
    "resolution": "1k"
  }'
```

```bash 一次出多张
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-image-2.0",
    "action": "generate",
    "prompt": "扁平插画风格的城市天际线，四种配色变体",
    "negative_prompt": "文字, 水印",
    "aspect_ratio": "16:9",
    "resolution": "2k",
    "n": 4
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  四选一：`qwen-image-2.0`、`qwen-image-2.0-pro`、`qwen-image-3.0` 或 `qwen-image-3.0-pro`。
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`：根据文字生成图片
  - `edit`：基于参考图改写；需要提供 `image_urls`
</ParamField>

<ParamField body="prompt" type="string" required>
  图片描述或编辑指令，中英文均可。
</ParamField>

<ParamField body="image_urls" type="string[]">
  参考图片 URL 数组。`qwen-image-2.0` 与 `qwen-image-2.0-pro` 在 `edit` 时至少需要 1 张。`qwen-image-3.0` 与 `qwen-image-3.0-pro` 在 `edit` 时需要 1 至 3 张，`generate` 不接受参考图。
</ParamField>

<ParamField body="aspect_ratio" type="string">
  画面比例：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`。`qwen-image-3.0` 与 `qwen-image-3.0-pro` 不传时为 `1:1`。
</ParamField>

<ParamField body="resolution" type="string">
  输出分辨率，`1k` 或 `2k`。`qwen-image-3.0` 与 `qwen-image-3.0-pro` 不传时为 `1k`。
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成数量。`qwen-image-2.0` 与 `qwen-image-2.0-pro` 取 `1`–`6`；`qwen-image-3.0` 与 `qwen-image-3.0-pro` 取值 `1`。
</ParamField>

<ParamField body="negative_prompt" type="string">
  不希望出现在结果中的内容，最多 500 字符。
</ParamField>

<ParamField body="prompt_extend" type="boolean" default="false">
  让模型扩写提示词，默认关闭。只有 `qwen-image-3.0` 与 `qwen-image-3.0-pro` 支持。
</ParamField>

<ParamField body="prompt_extend_mode" type="string">
  提示词扩写模式，`direct` 或 `agent`。只有 `qwen-image-3.0` 与 `qwen-image-3.0-pro` 支持，且必须同时设置 `prompt_extend: true`；`edit` 只接受 `direct`。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

本系列不接受 `seed`、`quality`、`watermark` 和 `mask_url`。以上之外的参数会返回 `400`，不计费。

## 限制

| 条件 | 限制 |
|---|---|
| `qwen-image-2.0` / `qwen-image-2.0-pro` | 一次最多出 6 张 |
| `action: "edit"`（2.0 两档） | 图片编辑需要至少 1 张参考图 |
| `qwen-image-3.0` / `qwen-image-3.0-pro` | 提示词必填，每次生成 1 张图片 |
| `action: "generate"`（3.0 两档） | 文生图不接收参考图，请改用 `edit` |
| `action: "edit"`（3.0 两档） | 图片编辑需要 1 至 3 张参考图 |
| `prompt_extend_mode` | 只有 `prompt_extend=true` 时才能设置 |
| `prompt_extend_mode` 在 `edit` 下 | 图片编辑的 `prompt_extend_mode` 只支持 `direct` |

## 计费

按成功出图的**固定张价**结算。

单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。单次调用的实际花费见任务响应里的 `cost`——整数 quota，**500,000 quota = 1 USD**，不是美元。

计费维度按代次不同：

- **`qwen-image-2.0` / `qwen-image-2.0-pro`**：单一张价，`1k` 与 `2k` 同价，画幅与提示词长度都不影响价格；总价 = 张价 × `n`。
- **`qwen-image-3.0`**：`1k` 与 `2k` 同价。
- **`qwen-image-3.0-pro`**：`2k` 比 `1k` 贵一档。
- **3.0 两档的参考图另计**：本次请求带的每张参考图按张各计一笔，加在输出图的价格上；`generate` 没有参考图，不产生这笔费用。

`resolution` 不在该模型支持的档位内时，按其兜底价结算（等于该模型的基础档价）。

只有成功出图才计费。任务失败、取消，或没有返回可用图片时，全额退款。

## 响应

```json 任务完成
{
  "task_id": "taski_example",
  "model": "qwen-image-3.0",
  "action": "edit",
  "status": "completed",
  "progress": "100%",
  "created_at": 1788754231,
  "completed_at": 1788754266,
  "result": {
    "images": [
      {
        "expires_at": 1789089508,
        "url": ["https://cdn.example.com/result.png"]
      }
    ]
  },
  "urls": {
    "get": "https://www.qingbo.dev/v1/tasks/taski_example",
    "cancel": "https://www.qingbo.dev/v1/tasks/taski_example/cancel"
  },
  "billing_status": "settled",
  "cost": 12377
}
```

`result.images` 返回生成的图片，`expires_at` 是该链接的失效时间戳。`n` 大于 1 时 `images` 数组里有多个元素。完整字段说明见[查询任务状态](/cn/api-reference/task/status)。

## 可用模型

| 模型 ID | 分辨率 | `n` | 参考图 | 专有参数 |
|---|---|---|---|---|
| `qwen-image-2.0` | `1k` `2k`（同价） | 1–6 | `edit` 时提供 | `negative_prompt` |
| `qwen-image-2.0-pro` | `1k` `2k`（同价） | 1–6 | `edit` 时提供 | `negative_prompt` |
| `qwen-image-3.0` | `1k` `2k`（同价） | `1` | 1–3 张，另计费 | `negative_prompt` `prompt_extend` `prompt_extend_mode` |
| `qwen-image-3.0-pro` | `1k` `2k`（`2k` 更贵） | `1` | 1–3 张，另计费 | `negative_prompt` `prompt_extend` `prompt_extend_mode` |

四个模型都支持 `generate` 与 `edit`，画幅集合相同：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`。
