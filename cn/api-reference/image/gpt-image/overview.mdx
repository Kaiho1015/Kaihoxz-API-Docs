GPT Image 2 有官方版和逆向版两条线路，都走 `POST /v1/tasks`，请求地址不随线路变化。两条线路的参数基本一致，主要差别在专有参数和计费方式，按需要选一个模型 ID 即可。

## 可用模型

<CardGroup cols={2}>
  <Card title="GPT Image 2 官方版" href="/cn/api-reference/image/gpt-image/gpt-image-2">

  </Card>

    `gpt-image-2-rev` · 文生图与最多 15 张参考图编辑；按 1K / 2K / 4K 固定张价结算
  </Card>
</CardGroup>

## 如何选择

| 需求 | 推荐模型 | 原因 |
|---|---|---|
| 掩码重绘、透明背景、画质档或输出格式控制 | `gpt-image-2` | 官方线路提供完整参数 |
| 提交前确定单张价格 | `gpt-image-2-rev` | 按输出分辨率固定计费 |
| 多图参考编辑 | 两者都支持 | 官方最多 16 张，逆向最多 15 张 |

<Note>
两条线路不会自动互相切换：模型 ID 决定走哪条线路，参数以该线路的页面为准。
</Note>

## 两条线路的共同点

以下部分两条线路完全一致：

| 项目 | 取值 |
|---|---|
| 端点 | `POST /v1/tasks`（异步任务，见[任务系统](/cn/docs/task-system)） |
| 动作 | `generate` 文生图 · `edit` 参考图编辑（必须带 `image_urls`） |
| 画面比例 | `1:1` `3:2` `2:3` `4:3` `3:4` `5:4` `4:5` `16:9` `9:16` `2:1` `1:2` `3:1` `1:3` `21:9` `9:21`，默认 `1:1` |
| 分辨率 | `1k` `2k` `4k`，默认 `1k` |
| 每次输出 | 1 张 |
| 不支持 | `seed` |

差异集中在**专有参数**和**计费方式**两处，见「如何选择」。

## 统一调用方式

```bash
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "action": "generate",
    "prompt": "一只蓝色陶瓷杯放在白色桌面上，柔和自然光",
    "aspect_ratio": "1:1",
    "resolution": "1k",
    "n": 1
  }'
```

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。
