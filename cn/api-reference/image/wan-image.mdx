Wan 2.7 Image 把图片生成与编辑放在同一套请求里：文生图只给 `prompt`，图生图、局部改写、多图融合都走 `edit` 并带上 `image_urls`。本页覆盖标准版与专业版两个模型，它们的参数集合完全相同，差别只在文生图的最高分辨率和单价——换档只改 `model`。

## 快速开始

<CodeGroup>

```bash 文生图
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: wan-image-demo-001" \
  -d '{
    "model": "wan2.7-image-pro",
    "action": "generate",
    "prompt": "夏日海滩，蓝天白云，远处有一艘白色帆船",
    "aspect_ratio": "16:9",
    "resolution": "4k",
    "thinking_mode": true,
    "n": 1
  }'
```

```bash 多图参考编辑
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: wan-image-edit-001" \
  -d '{
    "model": "wan2.7-image",
    "action": "edit",
    "prompt": "把第一张的人物放进第二张的场景，光线统一",
    "image_urls": [
      "https://cdn.example.com/person.png",
      "https://cdn.example.com/scene.png"
    ],
    "aspect_ratio": "3:2",
    "resolution": "2k"
  }'
```

```bash 框选区域编辑
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan2.7-image",
    "action": "edit",
    "prompt": "把框选区域里的招牌换成中文店名",
    "image_urls": ["https://cdn.example.com/street.png"],
    "bbox_list": [
      [[120, 80, 540, 460]]
    ],
    "resolution": "2k"
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  二选一：`wan2.7-image` 或 `wan2.7-image-pro`。
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`：根据文字生成图片，不接受输入图
  - `edit`：基于输入图改写；必须提供 `image_urls`

  图生图、局部改写、多图融合都走 `edit`，区别只在 `image_urls` 传几张、是否带 `bbox_list`。
</ParamField>

<ParamField body="prompt" type="string" required>
  图片描述或编辑指令，中英文均可。
</ParamField>

<ParamField body="negative_prompt" type="string">
  不希望出现在结果中的内容。
</ParamField>

<ParamField body="image_urls" type="string[]">
  输入图片 URL 数组。`edit` 时必填，最多 9 张。
</ParamField>

<ParamField body="aspect_ratio" type="string" default="1:1">
  画面比例：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`。
</ParamField>

<ParamField body="resolution" type="string" default="2k">
  输出分辨率。`wan2.7-image` 支持 `1k`、`2k`；`wan2.7-image-pro` 文生图还支持 `4k`。两个模型的 `edit` 最高 `2k`。
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成数量，取值 `1`。每次请求返回一张图。
</ParamField>

<ParamField body="seed" type="integer">
  随机种子。同一组参数配同一个种子，结果保持一致。
</ParamField>

<ParamField body="watermark" type="boolean">
  是否在输出图片中添加水印。
</ParamField>

<ParamField body="thinking_mode" type="boolean" default="true">
  思考模式：生成前先做一轮推理，画面质量更高、耗时更长。只在 `generate` 下有效。
</ParamField>

<ParamField body="enable_sequential" type="boolean" default="false">
  组图（连续多图）模式，用于分镜与系列图。开启后 `thinking_mode` 与 `color_palette` 不生效。
</ParamField>

<ParamField body="bbox_list" type="array">
  每张输入图的框选区域 `[[[x1, y1, x2, y2], …], …]`，绝对像素坐标。外层长度须等于 `image_urls` 的长度，每张图最多 2 个框。
</ParamField>

<ParamField body="color_palette" type="array">
  自定义配色，3–10 项（建议 8 项），每项为 `{"hex": "#1B4D3E", "ratio": 12.5}`，所有 `ratio` 之和须为 100.00%。仅标准模式可用，组图模式下不生效。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

本系列不接受 `quality` 和 `mask_url`。以上之外的参数会返回 `400`，不计费。

## 限制

| 条件 | 限制 |
|---|---|
| 每次请求 | 返回 1 张图 |
| `action: "generate"` | 需要提示词，不接受输入图 |
| `action: "edit"` | 需要输入图，且最高 `2k` |
| 输入图张数 | 最多 9 张 |
| 分辨率 | `wan2.7-image` 为 `1k` / `2k`；`wan2.7-image-pro` 文生图另有 `4k` |
| `bbox_list` | 外层长度等于 `image_urls` 长度，每张图最多 2 个框 |
| `color_palette` | 3–10 项，`ratio` 之和为 100.00%，组图模式下不生效 |

## 计费

按成功出图的**固定张价**结算，两个模型各有一个单价。

单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。单次调用的实际花费见任务响应里的 `cost`——整数 quota，**500,000 quota = 1 USD**，不是美元。

同一个模型下，`generate` 与 `edit` 同价，分辨率、画幅、输入图张数、`thinking_mode` 与 `color_palette` 都不影响价格——单价是唯一的计费维度，提交前即可确定单次费用。

只有成功出图才计费。任务失败、取消，或没有返回可用图片时，全额退款。

```json 任务完成
{
  "task_id": "taski_example",
  "model": "wan2.7-image",
  "action": "edit",
  "status": "completed",
  "progress": "100%",
  "created_at": 1788754231,
  "completed_at": 1788754279,
  "result": {
    "images": [
      {
        "expires_at": 1789089508,
        "url": ["https://cdn.example.com/result.jpg"]
      }
    ]
  },
  "urls": {
    "get": "https://www.qingbo.dev/v1/tasks/taski_example",
    "cancel": "https://www.qingbo.dev/v1/tasks/taski_example/cancel"

```

`result.images` 返回生成的图片，`expires_at` 是该链接的失效时间戳。完整字段说明见[查询任务状态](/cn/api-reference/task/status)。

## 可用模型

| 模型 ID | 文生图分辨率 | 参考图编辑分辨率 |
|---|---|---|
| `wan2.7-image` | `1k` `2k` | `1k` `2k` |
| `wan2.7-image-pro` | `1k` `2k` `4k` | `1k` `2k` |

两个模型都支持 `generate` 与 `edit`，每次请求出 1 张图，最多接受 9 张参考图，画幅集合相同：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`。
