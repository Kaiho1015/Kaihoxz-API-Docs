---
title: "Midjourney"
description: "出图之后还能放大、变体、扩图和局部重绘的图像模型"
api: "POST https://www.qingbo.dev/v1/tasks"
---

Midjourney 以高美学的艺术输出见长，默认渲染 2K 图像，`niji` 版本擅长动漫风格。这里只有 `midjourney` 一个模型 ID，一次调用做什么由 `action` 决定：`imagine` 从提示词出一组四宫格，其余动作都在上一步任务的结果上继续加工。所有动作都通过统一任务接口 `POST /v1/tasks` 提交。

## 快速开始

| 动作 | 做什么 | 必填参数 | 出图 |
|---|---|---|---|
| `imagine` | 从提示词出一组四宫格；带 `image_urls` 就是垫图生成 | `prompt` | 4 张 |
| `upscale` | 从四宫格里取一张，得到单图 | `ref_task_id`、`index` | 1 张 |
| `variation` | 对四宫格里的一张做小幅变体 | `ref_task_id`、`index` | 4 张 |
| `high-variation` | 对单图做大幅变体，构图与风格都可能变 | `ref_task_id`、`index` | 4 张 |
| `low-variation` | 对单图做小幅变体，保持主体与色调 | `ref_task_id`、`index` | 4 张 |
| `reroll` | 用来源任务的提示词重出一组 | `ref_task_id` | 4 张 |
| `zoom` | 画面外扩，原图保留、向外补背景 | `ref_task_id`、`index` | 4 张 |
| `pan` | 朝一个方向接图扩展，可连续平移拼长图 | `ref_task_id`、`index`、`direction` | 4 张 |
| `inpaint` | 局部重绘的第一步，选定要重绘的来源单图 | `ref_task_id`、`index` | 由 `modal` 出图 |
| `modal` | 给 `inpaint` 补掩码与提示词，完成局部重绘 | `ref_task_id`、`mask_url` | 4 张 |
| `edit` | 按提示词改写整张图 | `ref_task_id`、`index`、`prompt`、`image_urls` | 1–4 张 |
| `remix-strong` | 换提示词大幅重塑，仅 `v8.1` / `v8.2` | `ref_task_id`、`index` | 4 张 |
| `remix-subtle` | 换提示词小幅重塑，仅 `v8.1` / `v8.2` | `ref_task_id`、`index` | 4 张 |

出图张数以任务完成后 `result.images` 的实际条目数为准。

`imagine` 之外的动作都要 `ref_task_id`，传的是上一步任务的 `task_id`，串法见[使用示例](#使用示例)。

<CodeGroup>

```bash 文生图
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "imagine",
    "prompt": "a lighthouse on a cliff at dawn, painterly, no text",
    "aspect_ratio": "16:9",
    "version": "v7",
    "speed": "fast"
  }'
```

```bash 放大四宫格里的一张
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "upscale",
    "ref_task_id": "taski_example",
    "index": 2
  }'
```

```bash 做变体
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "variation",
    "ref_task_id": "taski_example",
    "index": 3,
    "speed": "fast"
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  固定为 `midjourney`。
</ParamField>

<ParamField body="action" type="string" default="imagine">
  这次调用做什么，取值见上表。
</ParamField>

<ParamField body="prompt" type="string">
  提示词。`imagine` 与 `edit` 必填；`modal`、`remix-strong`、`remix-subtle` 可选，留空时沿用来源任务的提示词。也可以直接在提示词里写 Midjourney 原生 flag（如 `--ar 16:9`），同名的结构化参数优先。
</ParamField>

<ParamField body="aspect_ratio" type="string">
  输出画幅：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`、`21:9` 或 `9:21`。
</ParamField>

<ParamField body="image_urls" type="string[]">
  参考图 URL。`imagine` 传入即为垫图生成；`edit` 必填，是要改写的原图。
</ParamField>

<ParamField body="seed" type="integer">
  随机种子，仅 `imagine` 生效。
</ParamField>

<ParamField body="negative_prompt" type="string">
  要排除的元素，仅 `imagine` 生效。
</ParamField>

<ParamField body="speed" type="string" default="relax">
  生成速度档：`relax`、`fast` 或 `turbo`，直接影响价格。全部动作可用。
</ParamField>

<ParamField body="version" type="string">
  Midjourney 模型版本：`v5.1`、`v5.2`、`v6.1`、`v7`、`v8.1`、`v8.2`、`niji6` 或 `niji7`。链式动作沿用来源任务的版本。
</ParamField>

<ParamField body="ref_task_id" type="string">
  来源任务的 `task_id`，即上一步任务的 ID。`imagine` 之外的动作必填。
</ParamField>

<ParamField body="index" type="integer">
  对来源四宫格里的第几张操作，取值 `1`–`4`（左上、右上、左下、右下）。`upscale`、`variation`、`high-variation`、`low-variation`、`zoom`、`pan`、`inpaint`、`edit`、`remix-strong`、`remix-subtle` 必填。
</ParamField>

<ParamField body="custom_id" type="string">
  直接指定来源任务上的操作按钮 ID，同时传了 `index` 时以 `custom_id` 为准。可用于 `upscale`、`variation`、`high-variation`、`low-variation`、`reroll`、`zoom`、`pan`、`inpaint`。
</ParamField>

<ParamField body="zoom_ratio" type="number">
  仅 `zoom`。外扩倍数：小于 `2` 按 1.5 倍外扩，大于等于 `2` 按 2 倍。
</ParamField>

<ParamField body="direction" type="string">
  仅 `pan`。平移扩展的方向：`left`、`right`、`up` 或 `down`。
</ParamField>

<ParamField body="mask_url" type="string">
  仅 `modal`。掩码图 URL，透明区域重绘、白色区域保留原图。局部重绘时必填，不传时按外扩处理。
</ParamField>

<ParamField body="metadata" type="object">
  自定义元数据对象，随请求原样带给上游。
</ParamField>

<ParamField body="style" type="string">
  仅 `imagine`。风格开关（`--style`），例如 `raw`。
</ParamField>

<ParamField body="stylize" type="integer">
  仅 `imagine`。风格化强度（`--s`），范围 `0`–`1000`。
</ParamField>

<ParamField body="chaos" type="integer">
  仅 `imagine`。四张结果之间的差异程度（`--c`），范围 `0`–`100`。
</ParamField>

<ParamField body="weird" type="integer">
  仅 `imagine`。怪异度（`--w`），范围 `0`–`3000`。
</ParamField>

<ParamField body="tile" type="boolean">
  仅 `imagine`。生成可无缝平铺的图案（`--tile`）。
</ParamField>

<ParamField body="iw" type="number">
  仅 `imagine`。垫图权重（`--iw`），范围 `0`–`3`，值越大越贴近 `image_urls`。
</ParamField>

<ParamField body="cref" type="string">
  仅 `imagine`。角色参考图 URL（`--cref`）。
</ParamField>

<ParamField body="cw" type="integer">
  仅 `imagine`。角色参考的贴合度（`--cw`），范围 `0`–`100`，配合 `cref` 使用。
</ParamField>

<ParamField body="sref" type="string">
  仅 `imagine`。风格参考图 URL（`--sref`）。
</ParamField>

<ParamField body="sw" type="integer">
  仅 `imagine`。风格参考的贴合度（`--sw`），范围 `0`–`1000`，配合 `sref` 使用。
</ParamField>

<ParamField body="dref" type="string">
  仅 `imagine`。深度参考图 URL（`--dref`）。
</ParamField>

<ParamField body="dw" type="number">
  仅 `imagine`。深度参考的贴合度（`--dw`），范围 `0`–`100`，配合 `dref` 使用。
</ParamField>

<ParamField body="raw" type="boolean">
  仅 `imagine`。原始风格（`--raw`），`v5.1` 起可用。
</ParamField>

<ParamField body="draft" type="boolean">
  仅 `imagine`。草图模式（`--draft`），`v7` 起可用。
</ParamField>

<ParamField body="hd" type="boolean">
  仅 `imagine`。高清输出（`--hd`），仅 `v8.1` 与 `v8.2`。
</ParamField>

<ParamField body="stop" type="integer">
  仅 `imagine`。提前停止（`--stop`），范围 `10`–`100`，仅 `v5.1`、`v5.2`、`v6.1`、`niji6`。
</ParamField>

<ParamField body="extra" type="string">
  仅 `imagine`。原样追加到提示词末尾的 Midjourney 原生 flag。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

本模型不接受 `n`、`resolution`、`quality`。以上之外的参数会返回 `400`，不计费。

## 限制

| 条件 | 限制 |
|---|---|
| 每次任务 | Midjourney 每次任务固定返回一组图，不支持用 `n` 批量出图 |
| `imagine` 以外的动作 | 必须传 `ref_task_id` |
| `ref_task_id` | 必须是你自己的、状态为 `completed` 的 Midjourney 任务，否则返回 `400` |
| `index` | 取值 `1`–`4` |
| `zoom`、`pan`、`inpaint` 的来源任务 | 必须是 `upscale` 得到的单图，四宫格要先 `upscale` |
| `pan` | 支持 `v6.1`、`v7`、`v8.1`、`v8.2`、`niji6` |
| `remix-strong`、`remix-subtle` | 来源任务必须是 `v8.1` 或 `v8.2` |
| `inpaint` | 本身不出图，要再调 `modal` 补掩码 |

## 计费

按次固定价，两个计费维度：**动作**与 **`speed` 档**。每个动作一个价，同一动作下 `relax`、`fast`、`turbo` 三档价格不同。`imagine` 一次返回 4 张图，按一次任务计费，不按张数。

单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。单次调用的实际花费见任务响应里的 `cost`——整数 quota，**500,000 quota = 1 USD**，不是美元。

`version`、画幅和提示词长度都不影响价格，参考图也不额外计费，提交前即可确定单次费用。请求的动作没有对应价格键时，按兜底价结算。

只有成功出图才计费。任务失败、取消，或没有返回可用图片时，全额退款。

## 使用示例

链式动作靠 `ref_task_id` 串起来，传的是你自己上一步任务的 `task_id`，不是图片 URL，也不是上游的 ID。

<Steps>
  <Step title="出一组四宫格">
    调 `imagine`，拿到响应里的 `task_id`。这一步的 `result.images` 有 4 项。
  </Step>
  <Step title="选一张继续">
    把上一步的 `task_id` 作为 `ref_task_id`，用 `index` 指定第几张。`upscale` 得到单图，`variation` 得到新的一组四宫格。
  </Step>
  <Step title="在单图上接着做">
    `upscale` 产生的任务 ID 又可以作为下一步的 `ref_task_id`：`zoom` 外扩、`pan` 平移、`inpaint` 加 `modal` 局部重绘，可以一直串下去。
  </Step>
</Steps>

<CodeGroup>

```bash 外扩画面
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "zoom",
    "ref_task_id": "taski_example_upscale",
    "index": 1,
    "zoom_ratio": 1.5
  }'
```

```bash 向右接图
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "pan",
    "ref_task_id": "taski_example_upscale",
    "index": 1,
    "direction": "right"
  }'
```

```bash 局部重绘（两步）
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "inpaint",
    "ref_task_id": "taski_example_upscale",
    "index": 1
  }'

curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "midjourney",
    "action": "modal",
    "ref_task_id": "taski_example_inpaint",
    "prompt": "把选中区域换成一张红色皮质沙发",
    "mask_url": "https://cdn.example.com/mask.png"
  }'
```

</CodeGroup>
