Z-Image Turbo 是通义实验室的 6B 参数文生图模型，采用蒸馏少步（S3-DiT）架构，出图速度接近实时，擅长写实人像，中英文文字渲染都能处理，适合批量草图、运营素材和快速预览。它只做文生图：不接受参考图，每次请求返回 1 张图；需要参考图编辑时用 [Seedream 系列](/cn/api-reference/image/seedream) 或 [Qwen Image 系列](/cn/api-reference/image/qwen-image)。

## 快速开始

<CodeGroup>

```bash 文生图
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: z-image-demo-001" \
  -d '{
    "model": "z-image-turbo",
    "action": "generate",
    "prompt": "清晨海边的观测台，写实摄影，柔和自然光",
    "aspect_ratio": "16:9",
    "resolution": "2k"
  }'
```

```bash 提示词改写
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "z-image-turbo",
    "action": "generate",
    "prompt": "国风茶馆海报",
    "aspect_ratio": "3:4",
    "resolution": "1k",
    "prompt_extend": true
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  固定为 `z-image-turbo`。
</ParamField>

<ParamField body="action" type="string" default="generate">
  取值 `generate`。本模型只支持文生图。
</ParamField>

<ParamField body="prompt" type="string" required>
  图片描述，中英文均可。
</ParamField>

<ParamField body="aspect_ratio" type="string">
  画面比例：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`。
</ParamField>

<ParamField body="resolution" type="string">
  输出分辨率，`1k` 或 `2k`。
</ParamField>

<ParamField body="prompt_extend" type="boolean" default="false">
  智能提示词改写：由模型先把提示词扩写得更具体，再生成图片。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

本模型不接受 `image_urls`、`n`、`seed`、`quality`、`negative_prompt` 和 `mask_url`。以上之外的参数会返回 `400`，不计费。

## 限制

| 条件 | 限制 |
|---|---|
| 每次请求 | 返回 1 张图 |
| 动作 | 只支持 `generate`，不接受参考图 |
| 分辨率 | `1k` / `2k` |

## 计费

按成功出图的**固定张价**结算，只有一个单价。

单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。单次调用的实际花费见任务响应里的 `cost`——整数 quota，**500,000 quota = 1 USD**，不是美元。

分辨率、画幅与提示词长度都不影响价格，提交前即可确定单次费用。

只有成功出图才计费。任务失败、取消，或没有返回可用图片时，全额退款。

  "status": "completed",

  "created_at": 1788766173,
  "completed_at": 1788766187,
  "result": {
    "images": [
      {
        "expires_at": 1789089508,
        "url": ["https://cdn.example.com/result.png"]
      }
    ]
  },
  "urls": {
    "get": "https://www.qingbo.dev/v1/tasks/taski_example",
