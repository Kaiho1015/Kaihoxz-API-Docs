xAI 的 Grok Imagine 图像线，当前有六个模型 ID，全部通过统一任务接口 `POST /v1/tasks` 提交，也全部按成功出图的固定张价结算——换档只改 `model`。官方线路的 `grok-imagine-image`、`grok-imagine-image-quality` 和 `grok-imagine-image-2.0` 支持参考图编辑、分辨率选择，参考图按张另计；经济版的 `grok-imagine-image-2.0-rev`、`grok-imagine-1.5-rev` 和 `grok-imagine-1.5-edit-rev` 参数更少、输出档位固定、单价更低。视频生成见 [Grok Imagine Video 系列](/cn/api-reference/video/grok-imagine-video)。

## 快速开始

<CodeGroup>

```bash 文生图
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: grok-image-001" \
  -d '{
    "model": "grok-imagine-image",
    "action": "generate",
    "prompt": "白色陶瓷杯放在原木桌面上，柔和棚拍光线，产品摄影",
    "aspect_ratio": "1:1",
    "resolution": "2k",
    "n": 1
  }'
```

```bash 参考图编辑
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: grok-image-edit-001" \
  -d '{
    "model": "grok-imagine-image",
    "action": "edit",
    "prompt": "保留主体，把背景换成日落时的海边",
    "image_urls": ["https://cdn.example.com/source.png"],
    "resolution": "1k",
    "n": 1
  }'
```

```bash 多图参考
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-image-quality",
    "action": "edit",
    "prompt": "用第一张图的产品，套用第二张图的海报风格",
    "image_urls": [
      "https://cdn.example.com/product.png",
      "https://cdn.example.com/style.webp"
    ],
    "aspect_ratio": "4:3",
    "resolution": "2k",
    "n": 1
  }'
```

```bash 选择画质
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-image-2.0",
    "action": "generate",
    "prompt": "雨后的城市街道，霓虹倒影，电影质感",
    "aspect_ratio": "16:9",
    "resolution": "2k",
    "quality": "medium",
    "n": 1
  }'
```

```bash 经济版文生图
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-1.5-rev",
    "action": "generate",
    "prompt": "一只柴犬戴着宇航头盔漂浮在太空，卡通风格",
    "aspect_ratio": "16:9",
    "n": 2
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  六选一，取值见[可用模型](#可用模型)。
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`：根据文字生成图片
  - `edit`：基于参考图改写；必须提供 `image_urls`

  单图编辑与多图参考融合都走 `edit`，区别只在 `image_urls` 传几张。`grok-imagine-image-2.0-rev` 和 `grok-imagine-1.5-rev` 只支持 `generate`。
</ParamField>

<ParamField body="prompt" type="string" required>
  图片描述或编辑指令，中英文均可。
</ParamField>

<ParamField body="n" type="integer" default="1">
  出图张数。`grok-imagine-image`、`grok-imagine-image-quality`、`grok-imagine-1.5-rev` 和 `grok-imagine-1.5-edit-rev` 取 `1`–`10`；`grok-imagine-image` 在 `edit` 下只出 1 张。`grok-imagine-image-2.0` 和 `grok-imagine-image-2.0-rev` 取值 `1`。
</ParamField>

<ParamField body="aspect_ratio" type="string" default="auto">
  画面比例，取值集合按模型不同，见[可用模型](#可用模型)。`grok-imagine-image`、`grok-imagine-image-quality` 和 `grok-imagine-image-2.0` 默认 `auto`，由模型决定构图；`grok-imagine-image-2.0-rev` 默认 `1:1`。`grok-imagine-1.5-edit-rev` 不接受这个参数。
</ParamField>

<ParamField body="resolution" type="string" default="1k">
  输出分辨率，`1k` 或 `2k`。只有 `grok-imagine-image`、`grok-imagine-image-quality` 和 `grok-imagine-image-2.0` 接受，其余三个模型输出档位固定。
</ParamField>

<ParamField body="quality" type="string">
  画质档位，`low` 或 `medium`。只有 `grok-imagine-image-2.0` 接受，且只在 `action: "generate"` 下有效；带参考图编辑时不要发送。不传时按分辨率档计价。
</ParamField>

<ParamField body="image_urls" type="string[]">
  参考图 URL 数组，需公网可访问。`action: "edit"` 时必填：`grok-imagine-image` 接受 1–5 张，`grok-imagine-image-quality` 和 `grok-imagine-image-2.0` 接受 1–3 张，`grok-imagine-1.5-edit-rev` 接受 1–5 张。`grok-imagine-1.5-rev` 在 `generate` 下也接受参考图，最多 5 张；`grok-imagine-image-2.0-rev` 不接受。

  多图参考时数组顺序保留，可在提示词里按顺序指代第一张、第二张。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

`seed` 和 `mask_url` 不支持。以上之外的参数会返回 `400`，不计费。

## 限制

| 模型 | 条件 | 限制 |
|---|---|---|
| `grok-imagine-image` | 每次请求 | 文生图每次请求可生成 1 至 10 张图片 |
| `grok-imagine-image` | `action: "generate"` | 文生图不接收参考图，请使用编辑动作 |
| `grok-imagine-image` | `action: "edit"` | 图片编辑需要 1 到 5 张参考图，且每次生成 1 张 |
| `grok-imagine-image-quality` | 每次请求 | 每次请求可生成 1 至 10 张图片 |
| `grok-imagine-image-quality` | `action: "generate"` | 文生图不接收参考图，请使用编辑动作 |
| `grok-imagine-image-quality` | `action: "edit"` | 编辑需要 1–3 张参考图（1 张为单图编辑，多张为多图参考） |
| `grok-imagine-image-2.0` | 每次请求 | 首发阶段每次生成 1 张 |
| `grok-imagine-image-2.0` | `action: "generate"` | 文生图不接收参考图，请使用编辑动作 |
| `grok-imagine-image-2.0` | `action: "edit"` | 编辑需要 1 到 3 张参考图 |
| `grok-imagine-image-2.0` | `action: "edit"` | 带参考图编辑时不能选择画质 |
| `grok-imagine-image-2.0-rev` | 每次请求 | 首发阶段每次生成 1 张 |
| `grok-imagine-image-2.0-rev` | `action: "generate"` | 该线路仅支持文生图 |
| `grok-imagine-1.5-rev` | 每次请求 | 一次最多出 10 张 |
| `grok-imagine-1.5-edit-rev` | 每次请求 | 一次最多出 10 张 |

## 计费

六个模型都按成功出图的**固定张价**结算，`generate` 与 `edit` 同价，画幅和提示词长度都不影响价格。计费维度按模型不同：

| 模型 | 计费维度 |
|---|---|
| `grok-imagine-image` | 单一张价，`1k` 与 `2k` 同价；参考图按张另计 |
| `grok-imagine-image-quality` | 按分辨率分档，`2k` 高于 `1k`；参考图按张另计 |
| `grok-imagine-image-2.0` | 按分辨率 × 画质分档（`1k` / `2k` × `low` / `medium`）；不传 `quality` 时按分辨率档计；参考图按张另计 |
| `grok-imagine-image-2.0-rev` | 单一张价 |
| `grok-imagine-1.5-rev` | 单一张价；参考图不加价 |
| `grok-imagine-1.5-edit-rev` | 单一张价；参考图不加价 |

带参考图时，单次费用 =（分辨率档价 + 每张参考图单价 × 参考图张数）× 出图张数。`resolution` 不在该模型支持的档位内时，按兜底价结算（等于 `1k` 档）。

单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。单次调用的实际花费见任务响应里的 `cost`——整数 quota，**500,000 quota = 1 USD**，不是美元。

只有成功出图才计费。任务失败、取消，或没有返回可用图片时，全额退款。

{
  "task_id": "task-wave1775290140a830128812",
  "model": "grok-imagine-image",
  "action": "edit",
  "status": "completed",
  "progress": "100%",
  "created_at": 1775290140,
  "completed_at": 1775290196,
  "billing_status": "settled",
  "cost": 9900,
  "result": {
    "images": [
      {
        "expires_at": 1775376540,
        "url": ["https://cdn.example.com/result.jpg"]
      }
    ]
  },
  "urls": {
    "get": "https://www.qingbo.dev/v1/tasks/task-wave1775290140a830128812",
    "cancel": "https://www.qingbo.dev/v1/tasks/task-wave1775290140a830128812/cancel"

`result.images` 返回生成的图片，`n` 大于 1 时数组里有多个条目。图片链接有有效期，取到后尽快转存。完整字段说明见[查询任务状态](/cn/api-reference/task/status)。

## 可用模型

| 模型 ID | 动作 | 画幅 | 分辨率 / 画质 | 参考图 |
|---|---|---|---|---|
| `grok-imagine-image` | `generate` / `edit` | 14 种 | `1k` `2k` | 1–5 张，按张另计 |
| `grok-imagine-image-quality` | `generate` / `edit` | 14 种 | `1k` `2k` | 1–3 张，按张另计 |
| `grok-imagine-image-2.0` | `generate` / `edit` | 14 种 | `1k` `2k` × `low` `medium` | 1–3 张，按张另计 |
| `grok-imagine-image-2.0-rev` | `generate` | 7 种 | 固定 | 不接收 |
| `grok-imagine-1.5-rev` | `generate` | 5 种 | 固定 | 最多 5 张，不加价 |
| `grok-imagine-1.5-edit-rev` | `generate` / `edit` | 不可选 | 固定 | 最多 5 张，不加价 |

画幅取值集合：

- **14 种**（`grok-imagine-image`、`grok-imagine-image-quality`、`grok-imagine-image-2.0`）：`auto`、`1:1`、`3:4`、`4:3`、`9:16`、`16:9`、`2:3`、`3:2`、`9:19.5`、`19.5:9`、`9:20`、`20:9`、`1:2`、`2:1`
- **7 种**（`grok-imagine-image-2.0-rev`）：`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`9:16`、`16:9`
- **5 种**（`grok-imagine-1.5-rev`）：`1:1`、`16:9`、`9:16`、`3:2`、`2:3`
