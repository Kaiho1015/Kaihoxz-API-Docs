xAI Grok Imagine 图像生成与编辑系列,分**官方线**与**经济线**两组:

**官方线**(xAI 官方 API,按张计费):

- **grok-imagine-image** — 标准档,1K / 2K 同价,最便宜的官方 Grok 出图档;文生图 + 参考图编辑
- **grok-imagine-image-quality** — 高质量档,1K / 2K 分档计价;文生图 + 参考图编辑
- **grok-imagine-image-2.0** — 2.0 代,1K / 2K × low / medium 分档;文生图 + 参考图编辑

**经济线**(备用渠道,更便宜,能力略少):

- **grok-imagine-image-2.0-rev** — 2.0 代固定质量,7 种比例,仅文生图
- **grok-imagine-1.0-rev** / **grok-imagine-1.5-rev** — 文生图(`generate`)
- **grok-imagine-1.0-edit-rev** / **grok-imagine-1.5-edit-rev** — 图像编辑(需传 `image_urls`)

  -H "Content-Type: application/json" \
  -d '{

    "aspect_ratio": "16:9",
    "n": 1
  }'

## 可用模型

| 模型 ID | 线路 | action | 说明 |
|---|---|---|---|
| `grok-imagine-image` | 官方 · 标准 | `generate` / `edit` | 1K / 2K 同价,最便宜的官方档,5 种比例 |
| `grok-imagine-image-quality` | 官方 · 高质量 | `generate` / `edit` | 画质更高,1K 与 2K 分档计价 |
| `grok-imagine-image-2.0` | 官方 · 2.0 | `generate` / `edit` | 1K / 2K × `quality` low / medium 分档,7 种比例 |
| `grok-imagine-image-2.0-rev` | 经济 · 2.0 | `generate` | 固定质量,7 种比例,仅文生图 |
| `grok-imagine-1.0-rev` / `grok-imagine-1.5-rev` | 经济 | `generate` | 纯文本提示生成图像,5 种比例 |
| `grok-imagine-1.0-edit-rev` / `grok-imagine-1.5-edit-rev` | 经济 | `edit` | 图像编辑,需传入参考图 `image_urls` |

## 通用参数

<ParamField body="model" type="string" required>
  从 [可用模型](#可用模型) 列表中选一个。官方线 `grok-imagine-image` / `-quality` / `grok-imagine-image-2.0` 同时支持 `generate` 与 `edit`;经济线里文生图用 `grok-imagine-1.0-rev` / `1.5-rev` / `grok-imagine-image-2.0-rev`,图像编辑用 `grok-imagine-1.0-edit-rev` / `1.5-edit-rev`
</ParamField>

<ParamField body="prompt" type="string" required>
  提示文本,支持中英文。文生图为画面描述;图像编辑为对参考图的修改指令
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成数量,取决于服务侧上限
</ParamField>

<ParamField body="callback_url" type="string">
  Webhook 回调地址,任务终态时调用。详见 [回调机制](/cn/docs/sync-async#异步任务-webhook)
</ParamField>

<ParamField body="callback_events" type="string[]">
  订阅的回调事件类型,详见 [回调机制](/cn/docs/sync-async#异步任务-webhook)
</ParamField>

## 模型特定参数

### 文生图(grok-imagine-1.0-rev / grok-imagine-1.5-rev)

<ParamField body="aspect_ratio" type="string" default="1:1">
  画面宽高比,共 5 种:
  - `1:1` — 正方形
  - `16:9` / `9:16` — 横/竖版宽屏
  - `3:2` / `2:3` — 横/竖版相机比
</ParamField>

### 图像编辑(grok-imagine-1.0-edit-rev / grok-imagine-1.5-edit-rev)

<ParamField body="image_urls" type="string[]" required>
  待编辑的参考图片 URL。图像编辑模型必须传入此字段
</ParamField>

<Note>
图像编辑模型(`*-edit`)不支持 `aspect_ratio` 参数,输出比例随参考图决定。
</Note>

## 资源限制

| 项目 | 限制 |
|---|---|
| 参考图片(`*-edit`) | 由 `image_urls` 提供 |
| 单张图片大小 | ≤ 30MB,支持 JPG/PNG/WEBP |
| 宽高比(文生图) | `1:1` / `16:9` / `9:16` / `3:2` / `2:3` |
| 输出文件 | 图片链接,24 小时有效 |
