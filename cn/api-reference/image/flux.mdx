FLUX 是 Black Forest Labs 的图像模型系列，本页覆盖当前可用的五个模型，分成两代：FLUX.2 可以选输出的百万像素档、最多带 8 张参考图，按 MP 档计价；FLUX.1 Kontext 专做上下文编辑，输出固定 1 MP、最多 4 张参考图，按张固定价。两代共用同一个任务接口和同一套动作，换模型只改 `model`。

## 快速开始

<CodeGroup>

```bash 文生图
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: flux-demo-001" \
  -d '{
    "model": "flux-2-pro",
    "action": "generate",
    "prompt": "雨后的城市街角，霓虹反射在积水里，电影感构图",
    "aspect_ratio": "16:9",
    "resolution": "2mp",
    "output_format": "png"
  }'
```

```bash 上下文编辑
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: flux-edit-001" \
  -d '{
    "model": "flux-kontext-pro",
    "action": "edit",
    "prompt": "保留人物和构图，把季节改成初雪",
    "image_urls": ["https://cdn.example.com/source.png"],
    "aspect_ratio": "1:1"
  }'
```

```bash 调节步数与引导强度
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "flux-2-flex",
    "action": "generate",
    "prompt": "手绘水彩风格的植物图鉴插页，白底",
    "aspect_ratio": "3:4",
    "resolution": "1mp",
    "steps": 28,
    "guidance": 3.5,
    "seed": 12345
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  五选一：`flux-2-pro`、`flux-2-max`、`flux-2-flex`、`flux-kontext-pro` 或 `flux-kontext-max`。
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`：根据文字生成图片
  - `edit`：基于参考图改写；必须提供 `image_urls`
</ParamField>

<ParamField body="prompt" type="string" required>
  图片描述或编辑指令。
</ParamField>

<ParamField body="image_urls" type="string[]">
  参考图片 URL 数组。`edit` 时必填，`generate` 不接受参考图。FLUX.2 最多 8 张，FLUX.1 Kontext 最多 4 张。
</ParamField>

<ParamField body="aspect_ratio" type="string" default="1:1">
  画面比例：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`21:9`、`9:21`、`auto`。`auto` 表示由模型决定比例。
</ParamField>

<ParamField body="resolution" type="string" default="2mp">
  输出图的百万像素档：`1mp`、`2mp`、`3mp`、`4mp`。只有 FLUX.2 三个模型接受这个参数；FLUX.1 Kontext 输出固定 1 MP。
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成数量，取值 `1`。每次请求返回一张图。
</ParamField>

<ParamField body="seed" type="integer">
  随机种子。同一组参数配同一个种子，结果保持一致。
</ParamField>

<ParamField body="output_format" type="string">
  输出图片格式：`jpeg`、`png` 或 `webp`。FLUX.2 默认 `jpeg`，FLUX.1 Kontext 默认 `png`。
</ParamField>

<ParamField body="prompt_upsampling" type="boolean" default="false">
  是否由上游先扩写提示词再生成。
</ParamField>

<ParamField body="safety_tolerance" type="integer" default="2">
  内容安全容忍级别，数值越大越宽松。FLUX.2 取 `0`–`5`，FLUX.1 Kontext 取 `0`–`6`。
</ParamField>

<ParamField body="steps" type="integer" default="50">
  推理步数，取 `1`–`50`。步数越多细节越足、耗时越长。只有 `flux-2-flex` 支持。
</ParamField>

<ParamField body="guidance" type="number" default="5">
  提示词引导强度，取 `1.5`–`10`。数值越大越贴合提示词。只有 `flux-2-flex` 支持。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

本系列不接受 `quality`、`negative_prompt`、`watermark` 和 `mask_url`。以上之外的参数会返回 `400`，不计费。

## 限制

| 条件 | 限制 |
|---|---|
| 每次请求 | 返回 1 张图，`prompt` 必填 |
| `action: "generate"` | 不接受参考图 |
| `action: "edit"` | 必须提供参考图 |
| 参考图张数 | FLUX.2 最多 8 张；FLUX.1 Kontext 最多 4 张 |
| 总像素 | 输出图与全部参考图合计不超过 9 MP（1 MP = 1024 × 1024 像素） |
| 参考图格式 | 必须是可直接下载的 PNG、JPEG、WebP、GIF 或 BMP；读不到尺寸会返回 `400`，不计费 |
| `resolution` | 只有 FLUX.2 接受；`steps` 与 `guidance` 只有 `flux-2-flex` 接受 |

## 计费

按成功出图的**固定张价**结算，两代的计费维度不同。

单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。单次调用的实际花费见任务响应里的 `cost`——整数 quota，**500,000 quota = 1 USD**，不是美元。

**FLUX.2**（`flux-2-pro` / `flux-2-max` / `flux-2-flex`）

- 输出图按 `resolution` 的百万像素档收费，`1mp`、`2mp`、`3mp`、`4mp` 各一档，档越高越贵；不传或传了档位之外的值时按兜底价结算，兜底价等于 `2mp` 档
- 参考图每张另计，加在输出图的价格上：只带 1 张时，按该图实际像素向上取整到的 MP 档收；带 2 张及以上时，每张按最低档收
- 三个模型各有一组 MP 档价，`flux-2-flex` 的 `steps` 与 `guidance` 不影响价格

**FLUX.1 Kontext**（`flux-kontext-pro` / `flux-kontext-max`）

- 单一固定张价，输出固定 1 MP，参考图不加价，画幅与 `output_format` 都不影响价格

只有成功出图才计费。任务失败、取消，或没有返回可用图片时，全额退款。

## 可用模型

| 模型 ID | 输出分辨率 | 参考图 | 专有参数 |
|---|---|---|---|
| `flux-2-pro` | `1mp` `2mp` `3mp` `4mp` | 最多 8 张，按张加价 | `output_format` `prompt_upsampling` `safety_tolerance` |
| `flux-2-max` | `1mp` `2mp` `3mp` `4mp` | 最多 8 张，按张加价 | `output_format` `prompt_upsampling` `safety_tolerance` |
| `flux-2-flex` | `1mp` `2mp` `3mp` `4mp` | 最多 8 张，按张加价 | 以上三个，另加 `steps` `guidance` |
| `flux-kontext-pro` | 固定 1 MP | 最多 4 张，不加价 | `output_format` `prompt_upsampling` `safety_tolerance` |
| `flux-kontext-max` | 固定 1 MP | 最多 4 张，不加价 | `output_format` `prompt_upsampling` `safety_tolerance` |

五个模型都支持 `generate` 与 `edit`，每次请求出 1 张图，都接受 `seed`，画幅集合相同：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`21:9`、`9:21`、`auto`。

- **FLUX.2 用 `resolution` 选百万像素档**：`1mp` 到 `4mp`，默认 `2mp`；档越高越贵
- **FLUX.1 Kontext 不接受 `resolution`**，输出固定 1 MP
- **`safety_tolerance` 的范围两代不同**：FLUX.2 是 `0`–`5`，Kontext 是 `0`–`6`，数值越大越宽松
- **`output_format` 默认值两代不同**：FLUX.2 默认 `jpeg`，Kontext 默认 `png`
