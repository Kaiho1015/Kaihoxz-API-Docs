Nano Banana 是 Google Gemini 的图像模型线，在这里有官方版和经济版两条线路，都走 `POST /v1/tasks`，请求地址不随线路变化。两条线路的动作和请求参数基本一致，差别在计费方式和各档可用的分辨率，按需要选一个模型 ID 即可。

## 如何选择

| 需求 | 推荐模型 | 原因 |
|---|---|---|
| 提交前确定单张费用 | 经济版任一档 | 分辨率是唯一计费维度，参考图不加价 |
| 费用随实际用量浮动 | 官方版任一档 | 按文本与图像 token 结算 |
| 复杂指令、精确文字渲染 | `gemini-3-pro-image` 或 `gemini-3-pro-image-rev` | 旗舰档，最高 4K |
| 极端长条画幅（`1:4` `8:1` 等） | `gemini-3.1-flash-image` 或 `gemini-3.1-flash-image-rev` | 只有快速档支持这 4 种画幅 |
| 联网检索辅助出图 | `gemini-3.1-flash-image` 或 `gemini-3.1-flash-image-rev` | 只有快速档接受 `google_search` |
| 低延迟、固定 1K 出图 | `gemini-3.1-flash-lite-image` 或 `gemini-3.1-flash-lite-image-rev` | 只输出 1K，不接受 `resolution` |

<Note>
两条线路不会自动互相切换：模型 ID 决定走哪条线路，参数以该线路的页面为准。
</Note>

## 两条线路的共同点

| 项目 | 取值 |
|---|---|
| 端点 | `POST /v1/tasks`（异步任务，见[任务系统](/cn/docs/task-system)） |
| 动作 | `generate` 文生图 · `edit` 参考图编辑（必须带 `image_urls`） |
| 每次输出 | 1 张 |
| 参考图 | 最多 14 张（`gemini-2.5-flash-image-preview-rev` 的张数上限由上游决定） |
| 画面比例 | 快速档 15 种，其余各档 11 种，默认 `1:1` |
| 不支持 | `mask_url`、`quality`、`seed` |

差异集中在**计费方式**和各档的**分辨率**上，见「如何选择」。

## 统一调用方式

```bash
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3-pro-image",
    "action": "generate",
    "prompt": "青瓷茶杯放在原木桌面上，窗边自然光，产品摄影",
    "aspect_ratio": "1:1",
    "resolution": "1k",
    "n": 1
  }'
```

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。
