Seedream 是字节跳动的图像生成与编辑模型系列。本页覆盖当前可用的四个模型，它们共用同一套请求参数、同一个任务接口和同一种计费方式（按成功出图的固定张价），差别在分辨率档、画幅数量和各自的专有参数——换模型只改 `model`。

## 快速开始

<CodeGroup>

```bash 文生图
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: seedream-demo-001" \
  -d '{
    "model": "seedream-4.0",
    "action": "generate",
    "prompt": "青瓷茶杯放在原木桌面上，窗边自然光，产品摄影",
    "aspect_ratio": "1:1",
    "resolution": "2k",
    "n": 1
  }'
```

```bash 参考图编辑
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: seedream-edit-001" \
  -d '{
    "model": "seedream-5.0-pro",
    "action": "edit",
    "prompt": "保留主体，把背景换成清晨的竹林",
    "image_urls": ["https://cdn.example.com/source.png"],
    "aspect_ratio": "auto",
    "resolution": "2k",
    "n": 1
  }'
```

```bash 指定输出格式
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedream-5.0-lite",
    "action": "generate",
    "prompt": "极简风格的产品海报，大面积留白，中央是一支钢笔",
    "aspect_ratio": "3:4",
    "resolution": "4k",
    "output_format": "png",
    "watermark": false
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  四选一：`seedream-4.0`、`seedream-4.5`、`seedream-5.0-lite` 或 `seedream-5.0-pro`。
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`：根据文字生成图片
  - `edit`：基于参考图改写；必须提供 `image_urls`
</ParamField>

<ParamField body="prompt" type="string" required>
  图片描述或编辑指令，中英文均可。
</ParamField>

<ParamField body="image_urls" type="string[]">
  参考图片 URL 数组。`edit` 时必填，最多 1 张；`generate` 不接受参考图。
</ParamField>

<ParamField body="aspect_ratio" type="string" default="1:1">
  画面比例。四个模型共通 10 种：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`2:1`、`1:2`、`21:9`。

  `seedream-4.0` 与 `seedream-4.5` 额外支持 `9:21`。

  `auto` 表示由模型决定比例。`seedream-5.0-pro` 的默认值是 `auto`，其余三个模型默认 `1:1`，且只在 `edit` 下接受 `auto`。
</ParamField>

<ParamField body="resolution" type="string" default="2k">
  输出分辨率，各模型档位不同：

  - `seedream-4.0`：`1k`、`2k`、`4k`
  - `seedream-4.5`：`2k`、`4k`
  - `seedream-5.0-lite`：`2k`、`3k`、`4k`
  - `seedream-5.0-pro`：`1k`、`1.5k`、`2k`，默认 `1.5k`
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成数量，取值 `1`。每次请求返回一张图。
</ParamField>

<ParamField body="watermark" type="boolean" default="false">
  是否在输出图片中添加水印。
</ParamField>

<ParamField body="optimize_prompt_options" type="string | object">
  提示词优化模式，只有 `seedream-4.0` 与 `seedream-4.5` 支持，默认 `standard`。

  - `standard`：质量优先，耗时更长
  - `fast`：速度优先

  `seedream-4.0` 直接传字符串（`"fast"`）；`seedream-4.5` 传对象（`{"mode": "fast"}`）。
</ParamField>

<ParamField body="output_format" type="string" default="jpeg">
  输出图片格式，`jpeg` 或 `png`。只有 `seedream-5.0-lite` 与 `seedream-5.0-pro` 支持。
</ParamField>

<ParamField body="background" type="string" default="opaque">
  背景：`opaque` 不透明 / `transparent` 透明。只有 `seedream-5.0-pro` 支持，且透明背景仅在单张带 alpha 通道的输入图做图生图、同时 `output_format` 为 `png` 时可用。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

本系列不接受 `seed`、`quality`、`negative_prompt` 和 `mask_url`。以上之外的参数会返回 `400`，不计费。

## 限制

| 条件 | 限制 |
|---|---|
| 每次请求 | 返回 1 张图，`prompt` 必填 |
| `action: "generate"` | 不接受参考图 |
| `action: "edit"` | 必须提供 1 张参考图 |
| 参考图张数 | 最多 1 张 |
| `aspect_ratio: "auto"` | `seedream-4.0`、`seedream-4.5`、`seedream-5.0-lite` 只在 `edit` 下可用 |
| `optimize_prompt_options` | 仅 `seedream-4.0`（字符串）与 `seedream-4.5`（对象） |
| `output_format` / `background` | `output_format` 仅 5.0 两档；`background` 仅 `seedream-5.0-pro` |

## 计费

按成功出图的**固定张价**结算。`seedream-4.0`、`seedream-4.5`、`seedream-5.0-lite` 三个模型的各档分辨率同价，`seedream-5.0-pro` 的 `2k` 比 `1k` / `1.5k` 贵一档。

单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。单次调用的实际花费见任务响应里的 `cost`——整数 quota，**500,000 quota = 1 USD**，不是美元。

`generate` 与 `edit` 同价，参考图不加价，画幅、输出格式与提示词长度都不影响价格——分辨率是唯一的计费维度，提交前即可确定单次费用。`resolution` 不在该模型支持的档位内时，按其兜底价结算（等于该模型的基础档价）。

只有成功出图才计费。任务失败、取消，或没有返回可用图片时，全额退款。

  "action": "generate",

    "images": [
      {
        "expires_at": 1789089508,
        "url": ["https://cdn.example.com/result.jpg"]
      }

## 可用模型

| 模型 ID | 分辨率 | 画幅 | 专有参数 |
|---|---|---|---|
| `seedream-4.0` | `1k` `2k` `4k`（同价） | 11 种 + `auto` | `optimize_prompt_options`（字符串） |
| `seedream-4.5` | `2k` `4k`（同价） | 11 种 + `auto` | `optimize_prompt_options`（对象） |
| `seedream-5.0-lite` | `2k` `3k` `4k`（同价） | 10 种 + `auto` | `output_format` |
| `seedream-5.0-pro` | `1k` `1.5k` `2k`（`2k` 更贵） | 10 种 + `auto` | `output_format`、`background` |

四个模型都支持文生图与单张参考图编辑，每次请求出 1 张图，都接受 `watermark`。

- **10 种共通画幅**：`1:1` `4:3` `3:4` `16:9` `9:16` `3:2` `2:3` `2:1` `1:2` `21:9`
- **`seedream-4.0` 与 `seedream-4.5` 额外支持 `9:21`**
- **`auto` 由模型按输入决定画幅**：`seedream-4.0`、`seedream-4.5`、`seedream-5.0-lite` 只在 `edit` 下接受它；`seedream-5.0-pro` 两个动作都接受，且它的默认画幅就是 `auto`
