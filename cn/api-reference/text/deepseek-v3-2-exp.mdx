DeepSeek V3.2 Exp 是 2025 年 9 月发布的实验版本，以明确版本号提供，适合日常问答、内容整理及工具调用。支持流式回答和函数调用参数生成。

使用 `deepseek-v3.2-exp` 调用 `POST /v1/chat/completions`。下列能力以此型号的验收记录为准。

官方发布日期：[2025-09-29](https://api-docs.deepseek.com/news/news250929)。本接入使用供应商声明的该版本 ID。

**与 `deepseek-v3.2` 的关系**：两者是 DeepSeek 官方分别标注日期的两次发布 —— 本页是 2025-09-29 的实验版本，[`deepseek-v3.2`](/cn/api-reference/text/deepseek-v3-2) 是 2025-12-01 的正式发布版本。在本目录中它们是两个独立型号，请按需选择。

## 价格与计费

以下是 WaveAPI 售价，单位 **USD / 100 万 token**。

| 计费项 | WaveAPI 单价 |
|---|---:|
| 输入总 token | 0.252 |
| 输出 token | 0.378 |

### 官方价格对照的说明

官方价格仅作为对照来源，不代表该渠道提供官方所有计费功能。**本型号的官方价格是历史价格，不是 DeepSeek 官方 API 当前提供的价格**：该版本在官方主 API 上服务期间，官方[价目页](https://api-docs.deepseek.com/quick_start/pricing)列出的价格为输入 0.28、输出 0.42（缓存命中 0.028）；官方价目页当前列出的是其他型号，不再包含本版本。

输入总 token 包括响应中报告的缓存统计，均按普通输入单价计费；缓存统计是输入的组成部分，不再重复相加。本接入仅提供输入、输出两项计价，不提供独立缓存折扣、缓存创建或存储能力。

显式 `cache_control` 请求会在额度预扣前拒绝。

`completion_tokens` 已包含其明细里的思考 token，不要再次相加。缺少 usage 不代表零费用。

```text
USD = (total_input_tokens * applicable_input_rate
     + completion_tokens * applicable_output_rate) / 1,000,000
```

上述公式以完整 usage 为前提。网关先换算基础 quota；启用单请求最小额度规则时，有正用量且计算结果不足 1 基础 quota 的请求先按 1 计，再应用账户分组倍率并取整数。当前验收使用的标准分组倍率为 1，因此正用量单次最低计费 1 quota。1 quota 对应的美元金额由网关换算配置决定，不是固定美元价格；极小请求的实际扣费可能高于公式中的未取整金额。

响应中的 `usage.cost` 是额度整数，不能当成美元；以控制台用量记录核对。

## 支持的功能

本接入支持以下文本能力：

- Chat 函数调用参数生成
- Chat 非流式文本与 usage
- Chat 流式文本与最终 usage

工具调用返回函数名和参数，由你的应用执行工具。

本接入未提供 Chat JSON Schema 严格输出：请求严格 schema 时返回的是普通 JSON 文本，不保证满足 schema 约束。需要严格 schema 的场景请选择声明了结构化输出的型号，例如 [`deepseek-v3.2`](/cn/api-reference/text/deepseek-v3-2)。

## 调用示例

将 `WAVE_API_KEY` 设为本人 Key。示例明确设置非流式和 256 token 请求预算，不额外设置推理参数。

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "deepseek-v3.2-exp",
  "messages": [
    {
      "role": "user",
      "content": "Reply with one short greeting."
    }
  ],
  "stream": false,
  "max_tokens": 256
}'
```

按实际部署替换网关地址。`max_tokens=256` 是示例请求参数，不是上下文/输出能力上限，也不是总费用保证。连接中断或缺少最终 usage 时，先检查已有用量记录，勿据此自动重发。
