## 接入示例

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-fable-5","messages":[{"role":"user","content":"Reply with the single word OK."}],"max_tokens":512,"stream":false}'
```

流式增加 `stream: true` 与 `stream_options: {"include_usage": true}`，读取 usage 尾帧和 `[DONE]`。工具使用 `tool_choice: "auto"`；生成函数参数后由客户端执行。
