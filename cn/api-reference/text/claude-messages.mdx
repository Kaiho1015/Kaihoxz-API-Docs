为已有 Anthropic Messages 客户端保留原生信封。当前已验证 Sonnet 5 / Opus 5 的非流式与流式文本；函数调用参数目前在 Chat 接口验证，原生多轮工具与图像输入不在已验收范围。

模型、价格和限制见 [Claude 5](/cn/api-reference/text/claude-5).

## 请求

```bash
curl http://localhost:40081/v1/messages \
  -H "x-api-key: $WAVE_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-sonnet-5","max_tokens":128,"stream":false,"messages":[{"role":"user","content":"Reply with the single word OK."}]}'
```

部署后替换域名。SDK 的 base URL 应设为网关根地址（本地为 `http://localhost:40081`），由 Anthropic SDK 添加 `/v1/messages`，不能重复添加 `/v1`。生态登录 token 不能代替模型 Key。

## 流式与用量

使用相同 URL 并设置 `stream: true`。读取 `message_start`、内容块事件，最后读取 `message_delta` 的实际 usage 和 `stop_reason`，再处理 `message_stop`。`message_start` 的初始用量不能当作最终账单。

原生 `input_tokens` 不包含缓存命中和缓存写入；总输入为三者相加。它与 Chat 的总 `prompt_tokens` 语义不同。`output_tokens` 包含思考 token；原生响应不额外插入 `usage.cost`，实际扣费查询本人账单。

当前结构化输出配置在预扣前拒绝，不承诺完整兼容所有 Claude 参数。缓存 TTL、极限上下文、原生工具流程和多模态能力仍按模型指南标明的范围逐项验证。
