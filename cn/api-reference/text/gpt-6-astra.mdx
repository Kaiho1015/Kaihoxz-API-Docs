模型 ID 为 `gpt-6-astra`，统一调用 `POST /v1/chat/completions`。已验证普通文本、流式和 JSON Schema，三笔共 768 quota（0.001536 USD），响应、钱包、Key、日志和最终账本一致。此为本地联调结果，未部署上线。

## 价格

2026-09-05 核对，单位 USD / 100 万 token，采用[官方标准价格](https://developers.openai.com/api/docs/models/gpt-6-astra)九折。

| 输入总量 | 普通输入 | 输出 | 缓存读取 | 缓存写入 |
|---|---:|---:|---:|---:|
| ≤272,000 | 9 | 45 | 0.9 | 11.25 |
| >272,000 | 18 | 67.5 | 1.8 | 22.5 |

输入总量包含缓存部分，超过阈值时整单切换高档。缓存读写替代对应普通输入费用，思考 token 已含在输出内。分项费用合计后换算整数 quota（500,000 quota = 1 USD）；`usage.cost` 为 quota。最终以账本 `settled` 为准，异常状态不表示免费，也不要重复提交来核对费用。

## 接入

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-6-astra","messages":[{"role":"user","content":"Reply with the single word OK."}],"reasoning_effort":"low","max_completion_tokens":128}'
```

流式增加 `stream: true` 与 `stream_options: {"include_usage": true}`；读取 usage 尾帧和 `[DONE]`。JSON Schema 用法见[通用 Chat 接口](/cn/api-reference/text/general-chat)。部署后将 localhost 替换为实际网关地址。

## 范围与限制

- 当前渠道声明输入上限 922,000、输出上限 12,800 tokens；未做极限测试，不承诺同时用满。
- 验收使用 `reasoning_effort: "low"`；不支持 `none`，不要传自定义 `temperature`、`top_p` 或 `logprobs`。
- Chat 工具调用关闭。[官方说明](https://developers.openai.com/api/docs/changelog)要求 Astra 工具使用 Responses；当前网关的该模型尚未验收 Responses，因此不展示工具能力。
- 缓存读写与长上下文已配置价格，但尚未实际验证缓存命中、写入或长档请求；图像输入与其他推理档位也未验收。
- 本页不开放内置搜索、托管工具或额外收费服务档位。
