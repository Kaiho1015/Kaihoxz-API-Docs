## 接入示例

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"kimi-k3","messages":[{"role":"user","content":"Reply with the single word OK."}],"max_tokens":512,"stream":false}'
```

流式增加 `stream: true` 与 `stream_options: {"include_usage": true}`，读取 usage 尾帧和 `[DONE]`。工具使用 `tool_choice: "auto"`；生成函数参数后由客户端执行。

## 限制

渠道声明输入 1,000,000、输出 104,857 tokens，未做极限测试。图像、原生协议、工具流式/多轮及托管工具未验收。不支持独立缓存写入。
