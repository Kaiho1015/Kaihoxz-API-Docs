## 示例

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-max","messages":[{"role":"user","content":"Reply with the single word OK."}],"stream":false,"max_tokens":512}'
```

流式设置 `stream: true`、`stream_options: {"include_usage": true}`，读取最终 usage 和 `[DONE]`。函数调用使用 `tool_choice: "auto"`；只生成参数，由客户端执行函数。

## 能力边界

当前仅开放普通文本和自动缓存。**显式缓存创建/读取未开放**，`cache_control` 在预扣前拒绝；显式读取与自动缓存有不同单价，不能混用。内置搜索和托管工具同样在预扣前拒绝。当前没有验收 Responses、图像/PDF、工具流式或多轮调用。

渠道声明输入上限 983,616、输出上限 131,072 tokens，未做极限测试。思考占用输出预算，不承诺关闭思考。当前为 localhost 联调结果，未部署上线。
