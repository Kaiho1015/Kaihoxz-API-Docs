---
title: "通用对话接口"
api: "POST https://www.qingbo.dev/v1/chat/completions"
---

- 统一的对话 API 接口，支持所有主流文本生成模型
- 完全兼容 OpenAI Chat Completions API 格式
- 通过 `model` 参数无缝切换不同 AI 模型
- 支持流式输出、函数调用等高级功能

<RequestExample>
```bash cURL
curl -X POST https://www.qingbo.dev/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-luna",
    "messages": [
      {
        "role": "system",
        "content": "你是一个专业的AI助手。"
      },
      {
        "role": "user",
        "content": "解释一下冒泡排序算法。"
      }
    ],
    "temperature": 0.7,
    "max_tokens": 1024
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="https://www.qingbo.dev/v1",
    api_key="YOUR_API_KEY"
)

response = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[
        {"role": "system", "content": "你是一个专业的AI助手。"},
        {"role": "user", "content": "解释一下冒泡排序算法。"}
    ],
    temperature=0.7,
    max_tokens=1024
)

print(response.choices[0].message.content)
```

package main

import (

    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()

    result, _ := io.ReadAll(resp.Body)
    fmt.Println(string(result))
}

```java Java
import java.net.http.*;
import java.net.URI;

public class Main {
    public static void main(String[] args) throws Exception {
        String payload = """
        {
          "model": "gpt-5.6-luna",
          "messages": [
            {"role": "system", "content": "你是一个专业的AI助手。"},
            {"role": "user", "content": "解释一下冒泡排序算法。"}
          ],
          "temperature": 0.7,
          "max_tokens": 1024
        }
        """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://www.qingbo.dev/v1/chat/completions"))
            .header("Authorization", "Bearer YOUR_API_KEY")
            .header("Content-Type", "application/json")
            .POST(HttpRequest.BodyPublishers.ofString(payload))
            .build();

        HttpResponse<String> response = client.send(request,
            HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}

## Body

<ParamField body="model" type="string" required>
  模型 ID

  完整的可用模型、价格与已验证能力见[文本模型总览](/cn/api-reference/text/overview)；实时可用性以 `GET /v1/models` 为准。

  切换模型只改这一个字段。参数是否可用以该模型的已验证能力为准，不是所有 OpenAI 参数在每个模型上都可用：GPT-5 及之后的型号用 `max_completion_tokens` 和 `reasoning_effort`，Claude 用 `max_tokens`；GPT Pro / Codex / o3-pro 只接受 [Responses 接口](/cn/api-reference/text/openai-multimodal)。
</ParamField>

<ParamField body="messages" type="array" required>
  对话消息列表

  <Expandable title="消息对象属性">
    <ParamField body="role" type="string" required>
      角色类型：`system`（系统提示）、`user`（用户输入）、`assistant`（模型回复）
    </ParamField>

    <ParamField body="content" type="string" required>
      消息内容，支持字符串或多模态内容数组
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="temperature" type="number">
  控制输出随机性，范围 0-2

  * 较低的值（如 0.2）使输出更确定
  * 较高的值（如 1.8）使输出更随机

  默认值：1.0
</ParamField>

<ParamField body="max_tokens" type="integer">
  生成的最大token数量

  不同模型有不同的最大值限制，请参考具体模型文档
</ParamField>

<ParamField body="stream" type="boolean">
  是否使用流式输出

  * `true`: 流式返回（SSE格式）
  * `false`: 一次性返回完整响应

  默认值：false
</ParamField>

<ParamField body="top_p" type="number">
  核采样参数，范围 0-1

  控制生成文本的多样性，建议与 temperature 二选一使用

  默认值：1.0
</ParamField>

<ParamField body="frequency_penalty" type="number">
  频率惩罚，范围 -2.0 到 2.0

  正值会降低重复使用相同词汇的可能性

  默认值：0
</ParamField>

<ParamField body="presence_penalty" type="number">
  存在惩罚，范围 -2.0 到 2.0

  正值会增加谈论新主题的可能性

  默认值：0
</ParamField>

<ParamField body="stop" type="string or array">
  停止序列

  最多4个序列，遇到这些序列时将停止生成
</ParamField>

<ParamField body="n" type="integer">
  生成的回复数量

  默认值：1
</ParamField>

<ParamField body="max_completion_tokens" type="integer">
  输出 token 上限（GPT-5 及之后的 OpenAI 型号）

  这些型号拒绝 `max_tokens`，必须用本字段。思考 token 也从这个预算里扣：`finish_reason: "length"` 表示输出可能没写完，不能当作完整回答。
</ParamField>

<ParamField body="reasoning_effort" type="string">
  推理档位（OpenAI 推理型号）

  取值 `none` / `low` / `medium` / `high`。GPT-5.6 与 GPT-5.4 / 5.5 已验证 `none`；GPT-6 Astra 只验证了 `low`，且不接受 `none`。非 OpenAI 型号不要传这个字段。
</ParamField>

<ParamField body="stream_options" type="object">
  流式附加选项

  设 `{"include_usage": true}` 时，SSE 会在 `[DONE]` 之前多发一帧只带 `usage` 的事件。**这一帧的 `choices` 可能是空数组**，读取时先取 usage 再判断文本增量，否则会因数组越界丢掉费用信息。详见[流式输出](/cn/docs/streaming)。
</ParamField>

<ParamField body="response_format" type="object">
  结构化输出

  `{"type": "json_schema", "json_schema": {...}}` 按 JSON Schema 约束返回，`{"type": "json_object"}` 只保证是合法 JSON。仅在总览表「已验证」列含 JSON 的模型上可用；**当前 Claude 全系拒绝**（预扣前返回 400），DeepSeek V3.2-Exp / V3.1-Terminus 不提供严格 schema。
</ParamField>

<ParamField body="tools" type="array">
  可调用的函数声明

  `[{"type": "function", "function": {"name": ..., "description": ..., "parameters": {JSON Schema}}}]`。模型只生成函数名和参数并放在响应的 `tool_calls` 里，**网关不执行任何工具**，执行与结果回传由你的应用负责。仅在总览表「已验证」列含工具的模型上可用。
</ParamField>

<ParamField body="tool_choice" type="string or object">
  工具选择方式

  `"auto"`（默认）、`"none"`，或 `{"type": "function", "function": {"name": "..."}}` 强制调用指定函数。**Claude Fable 系列只接受 `"auto"`**，`required` 或指定函数会被上游拒绝（400，预扣全额退回）。
</ParamField>

## 可用模型

模型 ID、价格、长上下文分档和各模型已验证的能力集中在[文本模型总览](/cn/api-reference/text/overview)，本页不再重复一份清单以免两处漂移。实时可用性与价格配置以目录接口为准：

curl https://www.qingbo.dev/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## 用量与计费

`usage.prompt_tokens` 是输入总量，已包含 `prompt_tokens_details.cached_tokens`；`usage.completion_tokens` 已包含 `completion_tokens_details.reasoning_tokens`。缓存部分按缓存价替代普通输入价，思考 token 按输出价计一次，两者都不叠加。

响应里的 `usage.cost` 是整数 **quota**，不是美元（500,000 quota = 1 USD）。最终扣款以本人账单的文本账务记录为准；`pricing_pending` 表示仍待核对，不是零费用。完整口径、状态含义和计算公式见[文本模型总览 · 计费口径](/cn/api-reference/text/overview#计费口径)。

<Warning>
没有收到完整 `usage`、连接中断或响应缺少费用字段，都不代表本次调用免费。先到控制台核对已有用量记录，不要自动重发。
</Warning>
