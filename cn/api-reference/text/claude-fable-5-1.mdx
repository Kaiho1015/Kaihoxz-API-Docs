使用官方模型 ID `claude-fable-5-1` 调用 `POST /v1/chat/completions`。APIMart 的上游名称差异由路由内部映射，不需要另一套用户 URL。官方 [2026-09-01 release and model details](https://platform.claude.com/docs/en/models/fable-5-1/overview)。

## 价格

2026-09-05 核对，USD / 100 万 token，各维度为官方标准价九折。

| 普通输入 | 输出（含思考） | 缓存命中 | 5 分钟写入 | 1 小时写入 |
|---:|---:|---:|---:|---:|
| 9.00 | 45.00 | 0.225 | 11.25 | 18.00 |

普通输入、缓存命中和写入不重叠计费；思考包含在输出内。缓存价格已配置，实际缓存命中与 TTL 写入尚未验收。

## 已验证能力

Chat 文本非流式、流式和自动函数调用已通过。函数声明使用 tools，tool_choice 使用 auto 或省略；返回工具名称与参数，由你的应用执行。不要使用 required 或强制选择具体函数：当前上游明确拒绝这种选择方式。一次强制调用测试返回 400，网关预扣已全额退回；不能把该错误解释为所有工具都不支持。

JSON Schema 实测返回了 Markdown 代码块而非严格 JSON，因此当前关闭结构化输出。json_schema / json_object 请求在预扣前拒绝。不要依赖提示词替代 schema 保证。

渠道声明输入 1,000,000、输出 128,000 tokens，未实测极限或同时用满。图像输入、原生 Messages、多轮工具和缓存 TTL 尚未验收。内置搜索、托管工具及额外收费服务档位不开放。

## 示例

```bash
curl http://localhost:40081/v1/chat/completions \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-fable-5-1","messages":[{"role":"user","content":"Reply with the single word OK."}],"max_tokens":256,"stream":false}'
```

部署后替换网关地址。流式使用相同 URL 并增加 stream=true、stream_options.include_usage=true。函数结构参见 [Chat API](/cn/api-reference/text/general-chat)，将模型改为本页 ID、移除 GPT 专用 reasoning_effort，将 max_completion_tokens 换成本页的 max_tokens，并将 tool_choice 改为 auto。
