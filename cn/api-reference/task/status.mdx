---
title: "查询任务状态"
description: "GET /v1/tasks/{task_id} — 查询异步任务的状态、进度和最终结果"
api: "GET https://www.qingbo.dev/v1/tasks/{task_id}"
---

异步任务的核心查询端点。提交任务后(`POST /v1/tasks`)返回 `task_id`,通过此端点轮询状态,直到 `status: completed` 取最终结果。

## 调用示例

<CodeGroup>

```bash 查询任务
curl https://www.qingbo.dev/v1/tasks/task-wave1775285160b950328499 \
  -H "Authorization: Bearer $WAVE_API_KEY"
```

</CodeGroup>

## 响应字段

<ResponseField name="task_id" type="string">
  任务唯一 ID(提交时返回)
</ResponseField>

<ResponseField name="status" type="string">
  任务状态:
  - `queued` — 已提交,等待处理
  - `processing` — 处理中,`progress` 字段表示进度(百分比字符串)
  - `completed` — 完成,`result` 含生成结果
  - `failed` — 失败,`error` 含错误信息
  - `cancelled` — 已取消(只能取消 queued 状态)
</ResponseField>

<ResponseField name="action" type="string">
  操作类型,跟提交时一致(generate / edit / image2video 等)
</ResponseField>

<ResponseField name="model" type="string">
  使用的模型 ID(group_name)
</ResponseField>

<ResponseField name="progress" type="string">
  进度,**百分比字符串**(如 `"30%"`、`"100%"`)。刚入队时可能为空字符串;终态(completed / failed)为 `"100%"`。
  注意提交响应里的 `progress` 是整数 `0`,查询响应里是字符串,请勿按数字解析。
</ResponseField>

<ResponseField name="created_at" type="integer">
  创建时间(Unix **秒**时间戳)
</ResponseField>

<ResponseField name="completed_at" type="integer">
  完成时间(Unix **秒**时间戳),**仅 completed / failed / cancelled 态有此字段**
</ResponseField>

<ResponseField name="cost" type="integer">
  任务实际扣费(quota),**仅终态(completed / failed / cancelled)有此字段**。
  成功 = 实际结算额度;失败 / 取消已自动退款时为 `0`。对账以此字段为准。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息,**仅 failed 态有此字段**:
  - `message` — 错误描述
  - `code` — 结构化错误码,常见:`upstream_unavailable`(上游不可用,可重试) /
    `upstream_bad_request`(参数被上游拒绝) / `upstream_rate_limited`(上游限流) /
    `task_failed`(其他失败)
</ResponseField>

<ResponseField name="result" type="object">
  生成结果,**仅 completed 态有此字段**。根据任务媒体类型,key 为 `images` / `videos` / `audios`(数组),每项含:
  - `url` — `string[]` 数组(单元素也用数组形式)
  - `expires_at` — Unix 秒时间戳,建议下载期限。该值在**每次查询时**按「当前时间 + 3 天」重新计算,不是存储侧的保留期承诺
</ResponseField>

<ResponseField name="urls" type="object">
  快捷操作链接,方便客户端不必拼接 URL:
  - `get` — 当前查询地址
  - `cancel` — 取消任务地址
</ResponseField>

## 轮询建议

- **轮询间隔**:2-5 秒一次
- **最大等待时间**:建议 5 分钟超时(视频可能更久)
- **检查 progress** 显示给用户实时进度
- **优先用 Webhook**:提交时设 `callback_url`,完成时主动推送,免轮询

详见 [任务系统](/cn/docs/task-system) 完整流程说明。

<Warning>
**生成结果链接请及时下载保存到自己的存储。** `expires_at` 是查询时刻起 3 天的建议下载期限,每次查询都会重新计算;它不代表文件一定保留到那一刻,也不代表之后一定失效。不要依赖结果链接做长期存储。
</Warning>

## 错误码

| 状态码 | 错误 | 说明 |
|---|---|---|
| 404 | `task_not_found` | task_id 不存在或不属于当前 user |
| 401 | 认证失败 | API Key 无效 |
