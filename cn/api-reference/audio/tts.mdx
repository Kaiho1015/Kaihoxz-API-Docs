同步接口 — 请求完成后直接返回音频流。

按**输入文本字符数**计费,不收输出费用;单价见 `GET /v1/models` 的 `price_config`。

<RequestExample>
```bash cURL
curl https://www.qingbo.dev/v1/audio/speech \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini-tts",
    "voice": "nova",
    "input": "欢迎使用 清波 API 文字转语音服务。"
  }' \
  --output output.mp3
```

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="https://www.qingbo.dev/v1",
    api_key="YOUR_API_KEY"
)

response = client.audio.speech.create(
    model="gpt-4o-mini-tts",
    voice="nova",
    input="欢迎使用 清波 API 文字转语音服务。"
)

response.stream_to_file("output.mp3")
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({

```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "io"
    "net/http"
    "os"
)

func main() {
    payload := map[string]string{
        "model": "gpt-4o-mini-tts",
        "voice": "nova",
        "input": "欢迎使用 清波 API 文字转语音服务。",
    }

    body, _ := json.Marshal(payload)
    req, _ := http.NewRequest("POST", "https://www.qingbo.dev/v1/audio/speech", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer YOUR_API_KEY")
    req.Header.Set("Content-Type", "application/json")

    resp, _ := http.DefaultClient.Do(req)
    defer resp.Body.Close()

    out, _ := os.Create("output.mp3")
    defer out.Close()
    io.Copy(out, resp.Body)
}
```

```java Java
import java.net.http.*;
import java.net.URI;
import java.nio.file.*;

public class Main {
    public static void main(String[] args) throws Exception {
        String payload = """
        {
          "model": "gpt-4o-mini-tts",
          "voice": "nova",
          "input": "欢迎使用 清波 API 文字转语音服务。"
        }
        """;

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://www.qingbo.dev/v1/audio/speech"))
            .header("Authorization", "Bearer YOUR_API_KEY")
            .header("Content-Type", "application/json")
            .POST(HttpRequest.BodyPublishers.ofString(payload))
            .build();

        HttpResponse<byte[]> response = client.send(request,
            HttpResponse.BodyHandlers.ofByteArray());
        Files.write(Path.of("output.mp3"), response.body());
    }
}
```
</RequestExample>

## 可用模型

| 模型 ID | 说明 |
|---------|------|
| `gpt-4o-mini-tts` | OpenAI 当代文字转语音,11 种音色,支持用 `instructions` 自然语言指定语气 / 语速 / 情绪 |

## 请求参数

<ParamField body="model" type="string" required>
  模型 ID:`gpt-4o-mini-tts`
</ParamField>

<ParamField body="input" type="string" required>
  要转换的文本内容
</ParamField>

<ParamField body="voice" type="string" default="alloy">
  音色,13 种可选:`alloy`、`echo`、`fable`、`onyx`、`nova`、`shimmer`、`coral`、`verse`、`ballad`、`ash`、`sage`、`marin`、`cedar`
</ParamField>

<ParamField body="instructions" type="string">
  用自然语言指定语气 / 语速 / 情绪,例如「用温柔缓慢的语气」。可选,不传按模型默认朗读
</ParamField>

## 响应

返回音频文件流（MP3 格式），直接保存为文件即可。
