<Note>
价格调整仅对**调整生效后**的调用计费，历史调用不受影响。各模型实时单价以 [模型总览](/cn/docs/models) 与控制台「模型市场」为准；每次费用以接口返回的 `cost` / `usage.cost` 为准。
</Note>

<Update label="2026-09-02" description="价格调整">
**存量模型价格对齐厂商官方刊例(含上调与下调)**

本批接入新模型时,对存量模型逐一与厂商官网刊例交叉核对,以下模型单价已同步:

| 模型 | 变化 |
|---|---|
| `kimi-k3` | 输出单价按 Moonshot 官方价**下调** |
| `gpt-image-2` | 不传 `quality` 时按 `high` 档计费(此前按低档计,现与 OpenAI 缺省一致) |
| `seedream-5.0` / `seedream-5.0-lite` | 各档单价同步火山引擎刊例;5.0-lite 补 `1.5K` 档 |
| `seedance-2.0` / `2.0-fast` / `2.0-face` / `2.0-fast-face` / `2.0-mini` / `2.5` / `1.5-pro` | 图生视频与文生视频**同价**(下调);参考视频按 2× 单价(上调);此前按促销价定的档回到刊例 |
| `wan2.6` / `wan2.7` / `wan2.7-r2v` / `wan2.7-videoedit` / `wan2.5-preview` | 各档同步阿里云百炼刊例;视频编辑 / 参考生视频按 2× 单价 |
| `minimax-h3` | 各档同步 MiniMax 官方价目 |

调整**即日生效**,仅对生效后的调用计费。实时单价以 [模型总览](/cn/docs/models) 与控制台「模型市场」为准。
</Update>
